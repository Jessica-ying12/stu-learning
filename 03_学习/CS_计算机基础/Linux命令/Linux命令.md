**1. 文件与目录操作**

这是最基础的模块，用于在文件系统中导航和管理文件。 [1, 2]
- **ls** **(List)**：列出目录内容。
- `ls -l`：显示详细信息（权限、大小、修改时间）。
- `ls -a`：显示所有文件，包括隐藏文件（以 `.` 开头）。

- **cd** **(Change Directory)**：切换目录。
- cd ~：跳转到家目录。
- cd ..：返回上一级目录。
- **pwd** **(Print Working Directory)**：显示当前所在路径。
- **mkdir** **/** **rmdir**：创建目录 / 删除空目录。
- **touch**：创建一个空文件或更新文件的时间戳。
- **cp** **/** **mv** **/** **rm**：
- `cp [源] [目的]`：复制。
- `mv [源] [目的]`：移动或重命名。
- `rm -rf [文件名]`：递归强制删除（**慎用**，尤其是 `-rf /`）。 [1, 2, 3, 4]

**2. 查看与编辑文件**

处理文本内容的核心工具。 [1]

- **cat**：一次性查看文件所有内容。
- **less** **/** **more**：分页查看文件，适合查看大文件。
- **head** **/** **tail**：查看文件的开头或末尾。
- `tail -f [文件名]`：**动态**查看文件新增内容，常用于监控日志。
- **grep**：文本搜索工具，常结合管道符使用，如 `ls | grep "test"`。
- **vim**：最常用的终端文本编辑器。 [1]

**3. 系统状态监控**

用于查看服务器资源、进程和磁盘情况。 [5, 6]

- **top**：实时显示系统负载、内存和 CPU 占用率。
- **ps** **(Process Status)**：查看当前运行的进程。常用 `ps -ef`。
- **df -h**：以易读格式查看磁盘空间使用情况。
- **free -m**：查看内存（RAM）使用情况。
- **kill -9 [PID]**：强制终止指定进程。

**4. 权限与用户管理**

Linux 是多用户系统，权限控制至关重要。 [1, 6]

- **chmod**：修改文件权限（如 `chmod 755 file`）。
- **chown**：修改文件的所有者（Owner）。
- **sudo**：以管理员（root）权限执行命令。
- **whoami**：显示当前登录的用户。 [1]

**5. 网络工具**

诊断和管理网络连接。 [5]

- **ping**：测试与主机的网络连通性。
- **ifconfig** **/** **ip addr**：查看本地 IP 地址和网络配置。
- **netstat** **/** **ss**：查看网络连接、端口占用情况（常用 `netstat -tunlp`）。
