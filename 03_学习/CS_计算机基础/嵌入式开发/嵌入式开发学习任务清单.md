## 总体思路与目标

- 先打好编程语言基础（C 为主，C++ 的面向对象思维在嵌入式中逐步引入）。
- 逐步了解硬件基础、单片机架构、外设驱动、调试方法。
- 再进入实时性、RTOS、系统设计、低功耗与功耗优化、简单的硬件设计思维。
- 以“小型端到端项目”为驱动的学习方式：LED、串口、传感器、通讯、简单驱动累积成完整应用。

---

## 阶段1：基础打底（0–2 个月）

目标

- 掌握 C 语言基础，理解编译、链接、烧写流程
- 了解计算机与数字逻辑的基本概念
- 熟悉常用开发工具链与开发环境

需要掌握的知识点

- C 语言入门
    - 数据类型、运算符、控制流、函数、数组、指针、结构体、对齐
    - 指针和内存管理、字符串处理、文件包含与头文件组织
- 计算机组成基础概念
    - 二进制、十六进制、位运算、字节序
    - 流程控制与基础算法思想（简单排序、查找等）
- 嵌入式开发基础
    - 各类开发板及常见 MCU 的工作模式
    - 编译工具链基础（GCC、ARM-GCC）和调试器（OpenOCD、J-Link）
    - 简单的 I/O 概念：GPIO、时钟、中断概念的初步理解
- 版本控制
    - Git 的基本使用：初始化、提交、分支、合并、远程仓库

推荐书籍

- C 语言入门
    - 《C Primer Plus》（简体中文版，系统性强，适合零基础） or 《C 程序设计语言》（K&R，经典但较紧凑，适合坚持者）
- 计算机基础
    - 《深入理解计算机系统》（CS: 系统底层原理，打好底子）
- 嵌入式入门与概念
    - 《嵌入式系统设计：Raspberry Pi/ARM Cortex-M 实战》（入门友好）
    - 《ARM Cortex-M3/M4F 实战指南》（若将来走 Cortex-M 路线，作为后续参考）

推荐学习平台与资源

- 在线课程
    - Coursera、edX、Udemy、慕课网、网易云课堂等的 C 语言入门、计算机组成原理、嵌入式基础课程
- 公开课与讲义
    - MIT OpenCourseWare、Stanford CS 课程相关资源（计算机组成原理、C 语言相关讲座）
- 实践平台
    - LeetCode/HackerRank 练习 C 语言相关题目（提升思维与语法熟练度也有帮助）
    - 具体嵌入式环境的练习：官方示例工程、开发板厂商提供的入门案例

常见入门练习

- 使用 LED 闪烁、按钮输入
- 简单的 USART 回显程序（串口通信）
- 通过定时器实现简单的延时和 PWM
- 简单的内存读写演练（避免越界与错误内存访问）

## 阶段2：硬件与嵌入式编程基础（2–4 个月）

目标

- 掌握单片机编程核心思想：中断、寄存器操作、外设驱动
- 能独立完成简单外设驱动（GPIO、USART、ADC、DAC、定时器、PWM）

需要掌握的知识点

- 微控制器架构
    - ARM Cortex-M0/M3/M4 的基本结构、寄存器、时钟系统、向量表
- 中断与嵌套
    - 中断向量表、优先级、从中断到主程序的协作
- 外设驱动基础
    - GPIO、USART/UART、SPI、I2C、ADC、DAC、PWM/定时器
- 调试与测试
    - 设置断点、查看寄存器与内存、简单的单元测试思路
- 软件工程基本功
    - 模块化、代码组织、版本控制（Git）、注释与文档

推荐书籍

- 《ARM Cortex-M3/M4F 实战指南》系列
- 《STM32F4 Cortex-M4 实战指南》（若你选 STM32 平台）
- 《嵌入式系统设计（详解版本）》
- 《FreeRTOS 实战》（若开始接触 RTOS，先看入门版）

推荐平台与资源

- 官方文档与参考手册
    - ST 官方（STM32）、NXP、TI 等 MCU 的硬件参考手册、寄存器说明
- 实践板与开发环境
    - 继续使用你选择的 MCU 开发板（如 STM32 系列、ESP32、RP2040 等）
    - 安装并熟悉 STM32CubeIDE、Keil、PlatformIO 等开发环境
- 模块化驱动示例
    - HAL/LL 驱动示例、I2C 传感器接入、SPI OLED 显示等

常见练习

- GPIO 点亮多种闪烁模式
- USART 回显、简单协议通讯
- I2C/SPI 外设演示（温度传感器、RTC、显示屏等）
- 简单 ADC 采样并输出到串口

## 阶段3：实时性与系统设计（4–6 个月）

目标

- 理解实时性约束、任务调度、简单 RTOS 的使用
- 能设计一个小型嵌入式应用的架构：任务、资源管理、异常处理

需要掌握的知识点

- 实时操作系统（RTOS）的基础
    - 任务/线程、调度、时钟、事件、队列、互斥、信号量、消息机制
    - FreeRTOS、ChibiOS/RT、Zephyr 的核心概念与简单应用
- 系统设计原则
    - 模块化设计、状态机、事件驱动 vs 轮询
    - 电源管理与低功耗设计基础
- 深入的外设与 DMA
    - DMA 的使用、DMA 与外设的协同工作
- 调试与优化
    - 性能分析、内存与功耗优化、代码可维护性

推荐书籍

- 《FreeRTOS 实战》及官方教程
- 《Zephyr Project 入门与实践》或相应 RTOS 的入门书
- 《嵌入式系统设计与实践（面向工程师的完整教程）》
- 《ARM 系列 MCU 实战指南》（适合作为进阶参考）

推荐学习平台与资源

- RTOS 官方文档与示例
    - FreeRTOS 官方网站、Zephyr 官方文档
- 开源示例与模板
    - GitHub 上的 FreeRTOS、Zephyr 的基础工程模板
- 在线课程
    - 嵌入式 RTOS 基础课程、嵌入式系统架构设计课程

常见练习

- 设计一个任务驱动的传感器轮询与数据打包发送的小系统
- 使用 RTOS 的队列/信号量实现简单的生产者-消费者模型
- 简单的“温湿度数据采集 + 串口上传”或“按键事件驱动的菜单系统”

## 阶段4：综合应用与硬件实践（6 个月及以上，持续迭代）

目标

- 能独立完成端到端的小型嵌入式产品
- 理解并应用硬件设计原则、信号完整性、低功耗与安全更新等概念
- 掌握版本控制、团队协作、项目文档

需要掌握的知识点

- 软硬件协同设计
    - 原理图、PCB 布局、信号完整性基础
    - 外设选择与接口匹配
- 高级课题（可选深入）
    - 无线通信基础（BLE、Wi-Fi、Zigbee 等）
    - OTA 更新与固件安全
    - 低功耗设计与睡眠模式优化
- 软件开发流程
    - 需求分析、风险评估、测试计划、持续集成/持续交付思想

推荐资源

- 书籍
    - 《嵌入式系统设计与实践：面向工程师的完整教程》
    - 《嵌入式系统开发指南：从零到高手》系列
- 在线资源
    - The Embedded Rust Book（若对 Rust 有兴趣）
    - 各平台官方论坛、社区问答
- 实践项目
    - 温湿度传感、数据存储、简单 OTA 更新的端到端原型
    - 参与开源嵌入式项目，积累代码风格与协作经验

---

## 学习节奏与方法建议

- 以“动手为主”的学习方式为主线：每学一个知识点就做一个小练习
- 每周设定明确目标（如本周完成一个 LED 闪烁的中断驱动；下周实现一个简单的串口回显并记录数据）
- 记录学习笔记与代码版本（用 Git 管理）
- 多看优秀的开源代码，学习风格、架构与注释习惯
- 避免仅追求“高大上”的技术，先把基础打牢再逐步引入复杂主题
