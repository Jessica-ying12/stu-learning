## 一、情感化微交互设计

### 1.1 启动页 - 情绪觉醒

#### 开屏动画
| 阶段 | 视觉 | 动效 | 时长 |
|------|------|------|------|
| 1 | 深色背景渐变出现 | 透明度0→1，持续0.3s | 0.3s |
| 2 | 中心出现一个白色圆点 | 弹性放大(scale 0→1.2→1)，带弹簧曲线 | 0.5s |
| 3 | 圆点分裂成8个彩色小点 | 放射性扩散，每个小点飞向对应位置 | 0.6s |
| 4 | 小点变成情绪Chip | 淡入+轻微上浮 | 0.4s |
| 5 | Logo文字出现 | 从下往上滑动，带模糊效果 | 0.3s |

**技术实现**：使用`AnimatedContainer` + `AnimationController`，或Lottie动画

### 1.2 情绪选择 - 触感与视觉的共鸣

#### 8种情绪的专属微动效
| 情绪 | 选中动效 | 声音反馈（可选） | 触感 |
|------|----------|------------------|------|
| 😊 快乐 | 放大1.1倍 + 旋转5° + 淡黄色光晕 | 轻快的"叮" | 轻触 |
| 😌 平静 | 缓慢呼吸效果（大小微变化） | 水滴声 | 无震动 |
| 🤩 兴奋 | 快速跳动2次 + 星光粒子 | 清脆的"叮叮" | 连续轻触2次 |
| 😢 悲伤 | 轻微下沉 + 蓝色涟漪 | 低沉的"咚" | 长震30ms |
| 😰 焦虑 | 抖动 + 红色闪烁 | 急促的"嘀嘀" | 连续震动 |
| 😴 疲惫 | 软绵绵的塌陷效果 | 呵欠声 | 无震动 |
| 😤 愤怒 | 火焰燃烧效果 + 变红 | 低吼 | 强震50ms |
| 🙏 感恩 | 柔和光芒 + 上升粒子 | 风铃声 | 轻触 |

**代码示例 - 快乐情绪的选中效果**：
```dart
AnimatedContainer(
  duration: Duration(milliseconds: 200),
  curve: Curves.elasticOut,
  transform: isSelected 
    ? Matrix4.identity()..rotateZ(0.08)..scale(1.1)
    : Matrix4.identity(),
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(24),
    color: isSelected ? Colors.purple[50] : Colors.grey[100],
    boxShadow: isSelected ? [
      BoxShadow(
        color: moodColor.withOpacity(0.5),
        blurRadius: 12,
        spreadRadius: 2,
      )
    ] : null,
  ),
  child: ...
)
```

## 二、沉浸式视觉设计系统

### 2.1 动态渐变背景

根据当前选中情绪，背景实时变化

| 情绪 | 背景渐变 |
|------|----------|
| 快乐 | 浅紫 → 淡粉 (从#F8F0FF到#FFE9F5) |
| 平静 | 浅绿 → 淡蓝 (#E8F5E9 → #E3F2FD) |
| 兴奋 | 橙黄 → 珊瑚橙 (#FFF3E0 → #FFE0B2) |
| 悲伤 | 浅蓝 → 灰蓝 (#E1F5FE → #B3E5FC) |
| 焦虑 | 浅红 → 淡橙 (#FFEBEE → #FFF3E0) |
| 疲惫 | 米色 → 灰褐 (#F5F5DC → #E0D6C6) |
| 愤怒 | 深红渐变 (#FFCDD2 → #EF9A9A) |
| 感恩 | 金色渐变 (#FFF8E1 → #FFECB3) |

**实现方式**：
```dart
AnimatedContainer(
  duration: Duration(milliseconds: 500),
  decoration: BoxDecoration(
    gradient: LinearGradient(
      begin: Alignment.topLeft,
      end: Alignment.bottomRight,
      colors: _getGradientForMood(selectedMood),
    ),
  ),
  child: ...
)
```

## 五、趋势页的数据诗意化

### 5.1 情绪云图（替代饼图）

**创新设计**：用云朵大小表示情绪频率

```
      😊 快乐
    (最大云朵)
    
   😌      😰
  平静     焦虑
(中等)   (中等)
  
😢    🤩    😤
悲伤  兴奋   愤怒
(小)   (小)   (小)
```

**交互**：
- 点击云朵：放大并显示具体数据
- 双指缩放：调整云朵密度
- 长按云朵：显示该情绪的所有记录列表

### 5.2 情绪河流（替代折线图）

**设计理念**：将折线图变成流动的彩色河流

```
情绪强度高 ↗
    🌈🌈🌈🌈
    🌈🌈🌈
    🌈🌈
    🌈
低       时间 →

周一 周二 周三 周四 周五 周六 周日
```

**河流颜色**：根据当天主导情绪变化
- 如果当天快乐多：河流偏紫色
- 如果当天焦虑多：河流偏红色
- 混合情绪：渐变色
