## 一、产品概述

### 1.1 产品背景
心理健康类应用在2026年持续升温，用户需要低门槛的情绪记录工具，帮助自我觉察。现有产品要么太复杂（需要写长篇日记），要么太简单（只有记录无分析）。

### 1.2 产品定位
一款**轻量级、可视化、非评判性**的情绪日记工具，通过情绪-颜色编码降低记录门槛，通过趋势分析帮助用户理解自己的情绪模式。

### 1.3 目标用户画像
| 用户类型 | 特征 | 需求 |
|----------|------|------|
| 大学生/职场新人 | 18-25岁，面临学业/工作压力 | 快速发泄情绪，看到变化趋势 |
| 关注心理健康者 | 25-35岁，有自我觉察意识 | 长期追踪，发现情绪规律 |
| 轻度抑郁/焦虑人群 | 寻求自助工具，不愿就医 | 温和引导，不贴标签 |

### 1.4 核心价值主张
**"3秒记录，一眼看懂你的情绪"**
- 3秒：选择情绪→可选备注→完成记录
- 一眼：通过颜色快速识别历史情绪
- 看懂：图表展示情绪分布与趋势

## 五、数据模型

```dart

  "intensity": 4,                       // 1-5，默认3
```

## 六、业务逻辑

### 6.1 记录保存流程
```
1. 用户选择情绪 → 启用提交按钮
2. 用户输入备注（可选）
3. 点击提交 → 触感反馈
4. 生成MoodEntry对象
   - id: Uuid().v4()
   - moodName: 选中情绪名称
   - moodIndex: 对应索引
   - colorValue: 情绪颜色值
   - note: 输入内容（空字符串处理）
   - timestamp: DateTime.now()
   - intensity: 3（默认）
5. 保存到数据库（Isar/Hive）
6. 刷新首页最新记录预览（可选）
7. 显示SnackBar提示"记录已保存"
8. 清空选择状态，返回首页
```

### 6.2 智能时间格式化规则
```dart
输入：DateTime对象
输出：String

规则：
- 如果是今天：返回 "今天 HH:mm"
- 如果是昨天：返回 "昨天 HH:mm"
- 如果是今年内：返回 "MM月dd日 HH:mm"
- 如果是更早：返回 "yyyy年MM月dd日 HH:mm"

示例：
- 2026-02-28 14:30（假设今天是02-28）→ "今天 14:30"
- 2026-02-27 22:15 → "昨天 22:15"
- 2026-01-15 09:00 → "1月15日 09:00"
- 2025-12-10 18:30 → "2025年12月10日 18:30"
```

### 6.3 连续天数计算逻辑
```dart
计算连续记录天数（从今天往前推）：

1. 获取所有记录，按日期去重（一天多条只算1天）
2. 从今天开始向前检查：
   - 如果有今天的记录 → count + 1，检查昨天
   - 如果有昨天的记录 → count + 1，检查前天
   - 直到某天没有记录停止
3. 返回连续天数

示例：
- 今天有记录，昨天有，前天有 → 3天
- 今天有，昨天有，前天无 → 2天
- 今天无，昨天有 → 0天（连续从今天算，今天没记就不连续）
```

### 6.4 图表数据聚合
#### 周视图（7天）
```dart
时间范围：今天往前推6天，共7天
数据点：每天的平均情绪强度（当天所有记录强度的平均值）
X轴标签：周一、周二...（根据实际日期）
```

#### 月视图（30天）
```dart
时间范围：今天往前推29天，共30天
数据点：每天的平均情绪强度
X轴标签：1日、2日...（每5天显示一个）
```

### 6.5 通知调度逻辑
```
1. 用户开启提醒开关
2. 检查通知权限：
   - 有权限 → 继续
   - 无权限 → 弹窗引导开启
3. 取消现有通知（如有）
4. 根据设置的时间创建每日周期性通知
5. 通知内容固定文案，点击打开App首页

用户关闭开关：
- 取消所有通知
- 保存设置状态
```

## 七、异常处理

### 7.1 数据存储异常
| 场景 | 处理方式 |
|------|----------|
| 数据库打开失败 | 重试3次，失败后提示"存储服务异常，请重启App" |
| 保存记录失败 | 提示"保存失败，请重试"，数据暂存内存 |
| 查询数据为空 | 正常显示空状态，非异常 |
| 导出文件失败 | 提示"导出失败，请检查存储空间" |

### 7.2 权限异常
| 权限 | 拒绝处理 |
|------|----------|
| 通知权限 | 提示"开启通知才能收到每日提醒"，提供"去设置"按钮 |
| 存储权限 | 导出时申请，拒绝则提示"无法导出文件" |

### 7.3 输入异常
| 场景 | 处理 |
|------|------|
| 备注超200字 | 截断并提示"最多200字" |
| 空白备注 | 允许保存，存储为空字符串 |
| 特殊字符 | 不限制，但显示时做安全处理 |

### 7.4 界面异常
| 场景 | 处理 |
|------|------|
| 图表无数据 | 显示"暂无数据"占位图 |
| 列表加载中 | 显示Shimmer加载效果 |
| 网络错误 | 不涉及网络，无需处理 |
