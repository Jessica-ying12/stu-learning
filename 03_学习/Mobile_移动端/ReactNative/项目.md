**操作**：依次执行以下命令：


**操作**：打开 `tsconfig.json` 文件，在 `compilerOptions` 中添加 `baseUrl` 和 `paths`：

```json
{
  "extends": "expo/tsconfig.base",

    "strict": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

**解释**：配置后，你可以使用 `@/components/Button` 代替 `../../components/Button`，让导入更清晰。需要重启 TypeScript 服务（在 VS Code 中有时需要重启编辑器）。

```tsx
// 首页的堆栈导航 (包含列表页和详情页)
function HomeStackScreen() {
  return (
    <HomeStack.Navigator>
      <HomeStack.Screen name="HomeMain" component={HomeScreen} options={{ title: '美食探索' }} />
      <HomeStack.Screen name="Detail" component={DetailScreen} options={{ title: '详情' }} />

// 主底部导航

  return (
    <NavigationContainer>
      <Tab.Navigator screenOptions={{ headerShown: false }}>
```

### 步骤 10：创建 API 服务层

**操作**：创建 `src/services/api.ts` 文件，写入：

```ts
// src/services/api.ts
import { Meal } from '@/types';

const BASE_URL = 'https://www.themealdb.com/api/json/v1/1';

// 根据首字母搜索菜品
export const fetchMealsByFirstLetter = async (letter: string = 'a'): Promise<Meal[]> => {
  try {
    const response = await fetch(`${BASE_URL}/search.php?f=${letter}`);
    const data = await response.json();
    // API 返回 { meals: [...] }，如果没有则返回空数组
    return data.meals || [];
  } catch (error) {
    console.error('API 请求失败:', error);
    return [];
  }
};

// 根据 ID 获取单个菜品详情
export const fetchMealById = async (id: string): Promise<Meal | null> => {
  try {
    const response = await fetch(`${BASE_URL}/lookup.php?i=${id}`);
    const data = await response.json();
    return data.meals ? data.meals[0] : null;
  } catch (error) {
    console.error('API 请求失败:', error);
    return null;
  }
};
```

**解释**：这里封装了两个网络请求函数，分别用于获取菜品列表和详情。使用了 `fetch`，并做了基本的错误处理。后面会在组件中调用它们。

## 第四阶段：实现全局状态管理 (收藏夹)

### 步骤 11：创建 Zustand store 并集成持久化

**操作**：创建 `src/store/favoriteStore.ts` 文件，写入：

```ts
// src/store/favoriteStore.ts
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { FavoriteStore, Meal } from '@/types';

export const useFavoriteStore = create<FavoriteStore>()(
  persist(
    (set) => ({
      favorites: [],
      addFavorite: (meal) =>
        set((state) => ({
          favorites: [...state.favorites, meal],
        })),
      removeFavorite: (id) =>
        set((state) => ({
          favorites: state.favorites.filter((item) => item.idMeal !== id),
        })),
    }),
    {
      name: 'food-favorites', // 存储的 key
      storage: createJSONStorage(() => AsyncStorage), // 使用 AsyncStorage
    }
  )
);
```

**解释**：
- `useFavoriteStore` 是一个自定义 Hook，可以在任何组件中调用获取状态和操作。
- `persist` 中间件会自动将 `favorites` 数组保存到 AsyncStorage 中，应用重启后数据依然存在。
- `addFavorite` 和 `removeFavorite` 是更新收藏夹的方法。

```tsx
// src/screens/DetailScreen.tsx
import React, { useEffect, useState } from 'react';
import { View, Text, Image, ScrollView, StyleSheet, Button, Alert } from 'react-native';
import { RouteProp, useRoute } from '@react-navigation/native';
import { fetchMealById } from '@/services/api';
import { Meal, RootStackParamList } from '@/types';
import { useFavoriteStore } from '@/store/favoriteStore';

type DetailScreenRouteProp = RouteProp<RootStackParamList, 'Detail'>;

export default function DetailScreen() {
  const route = useRoute<DetailScreenRouteProp>();
  const { mealId } = route.params;
  const [meal, setMeal] = useState<Meal | null>(null);
  const { favorites, addFavorite, removeFavorite } = useFavoriteStore();

  // 判断是否已收藏

        <Text>加载中...</Text>

  return (
    <ScrollView style={styles.container}>
      <Image source={{ uri: meal.strMealThumb }} style={styles.image} />
      <View style={styles.content}>
        <Text style={styles.title}>{meal.strMeal}</Text>
```

```tsx
// src/screens/ScanScreen.tsx
import React, { useState, useEffect } from 'react';
import { View, Text, Button, StyleSheet, Alert } from 'react-native';
import { BarCodeScanner } from 'expo-barcode-scanner';

export default function ScanScreen({ navigation }) {
  const [hasPermission, setHasPermission] = useState<boolean | null>(null);
  const [scanned, setScanned] = useState(false);

  useEffect(() => {
    (async () => {
      const { status } = await BarCodeScanner.requestPermissionsAsync();
      setHasPermission(status === 'granted');
    })();
  }, []);

  const handleBarCodeScanned = ({ type, data }) => {
    setScanned(true);
    Alert.alert('扫描成功', `条形码类型: ${type}\n数据: ${data}`, [
      { text: '确定', onPress: () => navigation.goBack() }
    ]);
    // 实际应用中可以拿着 data 去查询商品信息，然后跳转到新的页面
  };

  if (hasPermission === null) {
    return <Text>请求相机权限...</Text>;
  }
  if (hasPermission === false) {
    return <Text>没有相机权限</Text>;
  }

  return (
    <View style={styles.container}>
      <BarCodeScanner
        onBarCodeScanned={scanned ? undefined : handleBarCodeScanned}
        style={StyleSheet.absoluteFillObject}
      />
      {scanned && (
        <View style={styles.overlay}>
          <Button title="点击再次扫描" onPress={() => setScanned(false)} />
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    flexDirection: 'column',
    justifyContent: 'center',
  },
  overlay: {
    position: 'absolute',
    bottom: 30,
    left: 0,
    right: 0,
    alignItems: 'center',
  },
});
```

**解释**：
- 使用 `expo-barcode-scanner` 请求权限并显示相机视图。
- 扫描成功后弹出提示，并可以再次扫描。
