#### 一、算术运算符

##### 概念
- **是什么**：算术运算符是执行基本数学运算的符号，包括加法`+`、减法`-`、乘法`*`、除法`/`、取余`%`、幂`**`、自增`++`、自减`--`。
- **为什么需要**：程序需要处理数值计算，如计数、统计、数学公式计算等场景。
- **解决什么问题**：实现对数值类型数据的数学运算，是编程中最基础的操作。

##### 原理
- **底层实现**：JavaScript引擎将算术表达式解析为抽象语法树，按照运算符优先级和结合性进行计算。除法运算`/`总是返回浮点数结果。
- **工作流程**：先计算操作数表达式，再应用运算符规则。自增`++`和自减`--`遵循前置（先运算后返回）和后置（先返回后运算）的规则。
- **关键技术点**：取余`%`常用于判断整除（如`a % b === 0`），幂运算`**`用于指数计算。

##### 使用方法
- **基本用法**：`let sum = 5 + 3; // 8`、`let remainder = 10 % 3; // 1`
- **常见场景**：计数器（`count++`）、奇偶判断（`num % 2 === 0`）、数学计算。
- **最佳实践**：优先使用整数运算，避免浮点数直接计算。

##### 注意事项
- **常见错误**：浮点数精度问题，如`0.1 + 0.2`不等于`0.3`，而是`0.30000000000000004`。
- **性能问题**：基本算术运算性能差异极小，可忽略。
- **兼容性**：幂运算符`**`是ES2016引入，旧环境需用`Math.pow()`替代。

##### 代码示例
```javascript
// 基本算术运算
console.log(5 + 3);   // 8
console.log(10 - 4);  // 6
console.log(6 * 7);   // 42
console.log(15 / 4);  // 3.75
console.log(17 % 5);  // 2（判断整除）
console.log(2 ** 3);  // 8

// 自增自减
let a = 5;
console.log(a++);     // 5（后置，先返回后自增）
console.log(a);       // 6
console.log(++a);     // 7（前置，先自增后返回）

// 浮点数精度问题
console.log(0.1 + 0.2);               // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3);       // false
// 解决方案：设置误差范围
const eps = 1e-10;
console.log(Math.abs(0.1 + 0.2 - 0.3) < eps); // true
```

#### 二、赋值运算符

##### 概念
- **是什么**：赋值运算符用于将右侧的值赋给左侧的变量，包括基础赋值`=`和复合赋值（`+=`、`-=`、`*=`等）。
- **为什么需要**：变量需要存储和更新值，赋值是数据流动的基础。
- **解决什么问题**：实现变量值的更新和累积计算。

##### 原理
- **底层实现**：根据ECMAScript规范，赋值运算先计算左侧表达式得到引用（`lref`），再计算右侧得到值（`rval`），最后调用`PutValue(lref, rval)`存储值。
- **工作流程**：复合赋值`x += y`等价于`x = x + y`，但左侧表达式只计算一次。
- **关键技术点**：赋值运算符的**结合性是从右到左**，如`a = b = 5`先执行`b=5`再赋值给`a`。

##### 使用方法
- **基本用法**：`let x = 10;`、`x += 5; // x = 15`
- **常见场景**：累加器（`total += price`）、字符串拼接（`str += "hello"`）、简化代码。
- **最佳实践**：复合赋值使代码更简洁，可读性更好。

##### 注意事项
- **常见错误**：混淆`=`（赋值）和`==`（相等），如`if (x = 5)`会始终为真。
- **性能问题**：复合赋值不会提升性能，仅为语法糖。
- **兼容性**：所有赋值运算符在所有JavaScript环境中都支持。

##### 代码示例
```javascript
// 基础赋值
let a = 10;
let b = a;        // b = 10

// 复合赋值
let x = 5;
x += 3;           // x = 8（等价于 x = x + 3）
x -= 2;           // x = 6
x *= 4;           // x = 24
x /= 3;           // x = 8
x %= 5;           // x = 3
x **= 2;          // x = 9

// 链式赋值（右结合性）
let p, q, r;
p = q = r = 10;   // 先 r=10，再 q=10，最后 p=10
console.log(p, q, r); // 10 10 10
```

#### 三、比较运算符

##### 概念
- **是什么**：比较运算符用于比较两个值，返回布尔结果，包括相等`==`、严格相等`===`、不等`!=`、严格不等`!==`、大小比较`> < >= <=`。
- **为什么需要**：程序需要做条件判断和逻辑分支。
- **解决什么问题**：判断变量间的关系，控制程序流程。

##### 原理
- **底层实现**：`==`允许类型转换，先将操作数转为相同类型再比较；`===`禁止类型转换，类型不同直接返回`false`。
- **工作流程**：字符串比较按Unicode编码逐字符比较；不同类型比较时先转数字。
- **关键技术点**：`null`和`undefined`在`==`下相等且不等于其他值；`NaN`不等于自身。

##### 使用方法
- **基本用法**：`5 > 3 // true`、`"5" == 5 // true`、`"5" === 5 // false`
- **常见场景**：条件判断（`if (age >= 18)`）、数据验证、排序算法。
- **最佳实践**：除非明确需要类型转换，否则始终使用`===`和`!==`。

##### 注意事项
- **常见错误**：误用`==`导致意外结果，如`0 == false // true`、`"" == false // true`。
- **特殊情况**：`null >= 0`为`true`，但`null > 0`和`null == 0`均为`false`；`undefined`与任何值比较（除`null`）都返回`false`。
- **兼容性**：所有环境都支持。

##### 代码示例
```javascript
// == 与 === 对比
console.log(5 == "5");      // true（类型转换后相等）
console.log(5 === "5");     // false（类型不同）
console.log(0 == false);    // true（false转0）
console.log(0 === false);   // false

// null/undefined 特殊规则
console.log(null == undefined); // true
console.log(null === undefined);// false
console.log(null == 0);         // false
console.log(null >= 0);         // true
console.log(undefined > 0);     // false
console.log(undefined < 0);     // false

// 字符串比较（Unicode顺序）
console.log("apple" > "banana");    // false（a < b）
console.log("2" > "12");            // true（'2' > '1'）
console.log("a" > "A");             // true（小写字母编码更大）

// 最佳实践：使用严格相等
function isAdult(age) {
    return age === undefined ? false : age >= 18;
}
```

#### 四、逻辑运算符

##### 概念
- **是什么**：逻辑运算符用于布尔逻辑运算，包括逻辑与`&&`、逻辑或`||`、逻辑非`!`。
- **为什么需要**：组合多个条件，实现复杂逻辑判断。
- **解决什么问题**：实现条件组合、短路求值、默认值设置。

##### 原理
- **底层实现**：`&&`和`||`不总是返回布尔值，而是返回其中一个操作数的值。
- **工作流程**：
  - `&&`：从左到右求值，遇到假值则返回该值并停止，否则返回最后一个值。
  - `||`：从左到右求值，遇到真值则返回该值并停止，否则返回最后一个值。
  - `!`：将操作数转为布尔值后取反。
- **关键技术点**：**短路求值**机制可避免不必要的计算或错误。

##### 使用方法
- **基本用法**：`true && false // false`、`true || false // true`、`!true // false`
- **常见场景**：
  - 条件组合：`if (isLogin && hasPermission)`
  - 默认值：`let name = inputName || "访客"`
  - 安全调用：`obj && obj.method && obj.method()`
- **最佳实践**：注意假值包括`false`、`0`、`""`、`null`、`undefined`、`NaN`。若只需过滤`null/undefined`，考虑使用空值合并运算符`??`。

##### 注意事项
- **常见错误**：误用`||`设置默认值时，若有效值可能是`0`或`""`，会被错误覆盖。
- **性能问题**：短路求值可提升性能，避免不必要的函数调用。
- **优先级**：`&&`优先级高于`||`。

##### 代码示例
```javascript
// 短路求值示例
function A() { console.log("A执行"); return false; }
function B() { console.log("B执行"); return true; }

console.log(A() && B()); // 输出"A执行"后停止，返回false
console.log(B() || A()); // 输出"B执行"后停止，返回true

// 默认值设置
function greet(name) {
    name = name || "访客";  // 若name是假值，用"访客"
    console.log(`你好，${name}`);
}
greet("张三");  // 你好，张三
greet("");      // 你好，访客（注意：空字符串被覆盖）
greet(0);       // 你好，访客（0也被覆盖）

// 改进：只处理null/undefined
function greetBetter(name) {
    name = name ?? "访客";  // 空值合并运算符，只处理null/undefined
    console.log(`你好，${name}`);
}
greetBetter("");  // 你好，（保留空字符串）

// 链式判断
const user = { profile: { name: "李四" } };
console.log(user && user.profile && user.profile.name); // "李四"
```

#### 五、位运算符

##### 概念
- **是什么**：位运算符直接操作整数的二进制位，包括与`&`、或`|`、异或`^`、非`~`、左移`<<`、右移`>>`、无符号右移`>>>`。
- **为什么需要**：实现底层二进制操作，提高特定运算的性能。
- **解决什么问题**：权限控制、颜色值处理、加密算法、性能优化。

##### 原理
- **底层实现**：操作数先转为32位有符号整数，进行位运算后再转回JavaScript数字。
- **工作流程**：每个二进制位独立运算，如`5 & 1`（101 & 001 = 001）结果为1。
- **关键技术点**：位运算仅对整数有效，小数部分会被舍弃。

##### 使用方法
- **基本用法**：`5 & 3 // 1`（101 & 011 = 001）、`5 | 3 // 7`（101 | 011 = 111）
- **常见场景**：
  - 奇偶判断：`n & 1`比`n % 2`更快
  - 取整：`~~3.14`或`3.14 | 0`得到3
  - 交换变量：`a ^= b; b ^= a; a ^= b;`
  - RGB颜色转换：`(r << 16) | (g << 8) | b`
- **最佳实践**：只在性能关键或需要位操作的场景使用，普通代码应注重可读性。

##### 注意事项
- **常见错误**：超出32位整数范围（-2^31 到 2^31-1）时结果可能异常。
- **性能问题**：位运算是所有运算符中速度最快的之一。
- **兼容性**：`>>>`（无符号右移）在所有环境中支持，注意负数结果会变为正数。

##### 代码示例
```javascript
// 位运算基本示例
console.log(5 & 3);   // 1 (0101 & 0011 = 0001)
console.log(5 | 3);   // 7 (0101 | 0011 = 0111)
console.log(5 ^ 3);   // 6 (0101 ^ 0011 = 0110)
console.log(~5);      // -6 (取反规则：~x = -x-1)

// 取整技巧
console.log(~~3.14);      // 3
console.log(3.99 | 0);    // 3
console.log(-3.14 | 0);   // -3
console.log(2147483649 | 0); // -2147483647（溢出）

// 奇偶判断
function isOdd(n) {
    return (n & 1) === 1;
}
console.log(isOdd(5));  // true
console.log(isOdd(6));  // false

// 颜色转换：RGB转HEX
function rgbToHex(r, g, b) {
    return "#" + ((1 << 24) + (r << 16) + (g << 8) + b).toString(16).slice(1);
}
console.log(rgbToHex(186, 218, 85)); // "#bada55"
```

#### 六、三元运算符

##### 概念
- **是什么**：三元运算符是JavaScript中唯一需要三个操作数的运算符，格式为`条件 ? 表达式1 : 表达式2`。
- **为什么需要**：简化简单的if-else语句，使代码更简洁。
- **解决什么问题**：在一行内完成条件判断和值返回，常用于赋值。

##### 原理
- **底层实现**：先计算条件表达式，将其结果转为布尔值，根据真伪选择执行对应的分支表达式并返回结果。
- **工作流程**：条件为真时执行并返回表达式1，否则执行并返回表达式2。未执行的分支不会被计算。
- **关键技术点**：三元运算符是**表达式**而非语句，因此可以返回值。

##### 使用方法
- **基本用法**：`let status = age >= 18 ? "成年" : "未成年";`
- **常见场景**：
  - 条件赋值：`let max = a > b ? a : b;`
  - 内联条件渲染：`<div>{isLogin ? "欢迎" : "请登录"}</div>`
  - 链式使用：处理多条件分支
- **最佳实践**：保持简洁，避免嵌套过深影响可读性。复杂条件应使用if-else。

##### 注意事项
- **常见错误**：过度嵌套导致代码难以理解，如`a ? b ? c : d : e`。
- **性能问题**：与if-else性能相近，无显著差异。
- **可读性**：链式三元运算符虽可行，但超过两层应考虑改用if-else或switch。

##### 代码示例
```javascript
// 基础用法
let age = 20;
let type = age >= 18 ? "成年人" : "未成年人";
console.log(type); // "成年人"

// 取最大值
let a = 15, b = 20;
let max = a > b ? a : b;
console.log(max); // 20

// 链式使用（多条件）
let score = 85;
let grade = score >= 90 ? "A" 
          : score >= 80 ? "B" 
          : score >= 70 ? "C" 
          : score >= 60 ? "D" 
          : "F";
console.log(grade); // "B"

// 内联使用（React/JSX风格）
function Greeting({ isLogin, name }) {
    return (
        <div>
            {isLogin ? `你好，${name}` : "请先登录"}
        </div>
    );
}

// 避免过度嵌套
// ❌ 不推荐：难以理解
let result = condition1 ? (condition2 ? val1 : val2) : (condition3 ? val3 : val4);

// ✅ 推荐：改用if-else
let result;
if (condition1) {
    result = condition2 ? val1 : val2;
} else {
    result = condition3 ? val3 : val4;
}
```

#### 运算符优先级总结
同一单元格内优先级相同，从上到下优先级降低：

| 优先级 | 运算符类型 | 运算符 | 结合性 |
|-------|-----------|--------|--------|
| 最高 | 成员访问 | `() . []` | 左到右 |
| | 一元运算符 | `++ -- - ~ !` | 右到左 |
| | 乘除/取余 | `* / %` | 左到右 |
| | 加减 | `+ -` | 左到右 |
| | 位移 | `<< >> >>>` | 左到右 |
| | 比较 | `< <= > >=` | 左到右 |
| | 相等 | `== != === !==` | 左到右 |
| | 按位与 | `&` | 左到右 |
| | 按位异或 | `^` | 左到右 |
| | 按位或 | `|` | 左到右 |
| | 逻辑与 | `&&` | 左到右 |
| | 逻辑或 | `||` | 左到右 |
| 最低 | 三元 | `? :` | 右到左 |
| | 赋值 | `= += -=`等 | 右到左 |

**核心建议**：当不确定优先级时，使用括号`()`明确指定运算顺序，提高代码可读性。
