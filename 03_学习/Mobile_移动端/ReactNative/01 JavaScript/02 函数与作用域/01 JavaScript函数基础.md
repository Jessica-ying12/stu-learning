# JavaScript 函数基础学习笔记

## 一、函数声明

### 概念
- **是什么**：函数声明是使用 `function` 关键字定义命名函数的一种方式，形式为 `function 函数名(参数) { ... }`。
- **为什么需要**：它是JavaScript中最基础的函数定义方式，用于封装可复用的代码块，实现模块化和代码复用。
- **解决什么问题**：将特定功能的代码组织在一起，提高代码可读性、可维护性，并避免重复编写相同逻辑。

### 原理
- **底层实现**：JavaScript引擎在编译阶段会进行**函数声明提升**。它会将函数声明整个（包括函数体）提前到当前作用域的顶部，因此在代码执行前，函数就已经存在于内存中。
- **工作流程**：
  1. 解析阶段：引擎扫描代码，遇到函数声明时，在内存中创建函数对象，并将标识符（函数名）绑定到该对象。
  2. 执行阶段：无论函数声明在代码中的位置如何，都可以在声明之前调用该函数。
- **关键技术点**：提升（Hoisting）、作用域绑定（函数声明创建的函数绑定到当前作用域）。

### 使用方法
- **基本用法**：
  ```javascript
  function greet(name) {
      return `Hello, ${name}!`;
  }
  ```
- **常见场景**：定义独立、通用的工具函数，或作为模块的主要接口。
- **最佳实践**：
  - 使用清晰的函数名，体现函数功能。
  - 保持函数单一职责，一个函数只做一件事。
  - 利用提升特性，可以将主要的执行逻辑放在文件顶部，具体实现放在后面，使代码结构更清晰。

### 注意事项
- **常见错误**：
  - 在条件语句中声明函数：不同浏览器对条件函数声明的处理可能不一致，应避免使用，改用函数表达式。
  - 忘记函数名：函数声明必须带有函数名。
- **性能问题**：无显著性能问题，但滥用提升可能导致代码阅读困难。
- **兼容性**：所有JavaScript环境都支持。

### 代码示例
```javascript
// 利用提升，可以在声明前调用
sayHi('张三'); // 输出：Hello, 张三

function sayHi(name) {
    console.log('Hello, ' + name);
}
```

## 二、函数表达式

### 概念
- **是什么**：函数表达式是将函数赋值给变量的方式，形式为 `const 变量 = function(参数) { ... }` 或命名函数表达式 `const 变量 = function 函数名(参数) { ... }`。
- **为什么需要**：函数表达式允许将函数作为值使用，可以动态创建、作为参数传递或赋值给对象属性。
- **解决什么问题**：解决了函数声明必须独立命名的限制，使函数能够像普通值一样参与各种操作（如回调、闭包）。

### 原理
- **底层实现**：函数表达式在运行时才被创建。变量声明（使用 `var`、`let`、`const`）会被提升，但赋值部分（函数定义）不会被提升，因此只能在赋值后才能调用。
- **工作流程**：
  1. 解析阶段：变量声明被提升，但初始值为 `undefined`（`var`）或处于暂存死区（`let`/`const`）。
  2. 执行阶段：执行到赋值语句时，创建函数对象并赋给变量。
- **关键技术点**：不提升、作用域、匿名函数与命名函数。

### 使用方法
- **基本用法**：
  ```javascript
  const add = function(a, b) {
      return a + b;
  };
  ```
- **常见场景**：
  - 作为回调函数：`setTimeout(function() { ... }, 1000);`
  - 创建闭包：函数内部返回另一个函数表达式。
  - 立即执行函数表达式（IIFE）：`(function() { ... })();`
- **最佳实践**：
  - 优先使用 `const` 声明函数表达式，避免变量被重新赋值。
  - 使用命名函数表达式便于调试（堆栈跟踪显示函数名）。
  - 当需要递归时，使用命名函数表达式。

### 注意事项
- **常见错误**：
  - 在赋值前调用函数导致 `TypeError`。
  - 匿名函数在堆栈跟踪中显示为 `anonymous`，不利于调试。
- **性能问题**：无显著性能问题。
- **兼容性**：所有JavaScript环境都支持。

### 代码示例
```javascript
// 错误示例：在赋值前调用
// console.log(double(5)); // TypeError: double is not a function

const double = function(x) {
    return x * 2;
};
console.log(double(5)); // 10

// 命名函数表达式用于递归
const factorial = function fact(n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
};
console.log(factorial(5)); // 120
// fact 在外部不可见
// console.log(fact(5)); // ReferenceError
```

## 三、箭头函数

### 概念
- **是什么**：箭头函数是ES6引入的一种更简洁的函数书写方式，使用 `=>` 定义，形式为 `(参数) => { ... }`。
- **为什么需要**：为了简化函数书写，并解决传统函数中 `this` 指向动态变化带来的问题。
- **解决什么问题**：
  - 语法简洁，特别适合作为回调函数。
  - 词法作用域绑定 `this`，避免了在回调中需要 `var self = this` 或 `.bind(this)` 的繁琐。

### 原理
- **底层实现**：箭头函数不是传统函数的语法糖，它有自己的行为规则：
  - 没有独立的 `this`、`arguments`、`super`、`new.target`。
  - 不能用作构造函数，因此没有 `prototype` 属性。
  - `this` 从外围作用域捕获（词法绑定）。
- **工作流程**：当箭头函数被调用时，它不会创建自己的执行上下文，而是从定义时的外层函数继承 `this`。
- **关键技术点**：词法 `this`、隐式返回、不能绑定 `arguments`。

### 使用方法
- **基本用法**：
  ```javascript
  // 标准形式
  const sum = (a, b) => a + b;

  // 多行函数体需要大括号和 return
  const sum2 = (a, b) => {
      const result = a + b;
      return result;
  };

  // 单个参数可省略括号
  const double = x => x * 2;

  // 返回对象字面量需加括号
  const getPerson = name => ({ name: name, age: 18 });
  ```
- **常见场景**：
  - 数组迭代方法：`arr.map(x => x * 2)`
  - 事件监听：`button.addEventListener('click', () => { ... })`（此时 `this` 指向外层）
  - 保证 `this` 指向固定的场景（如类中的方法）。
- **最佳实践**：
  - 当函数体简单且只有一条返回语句时，使用隐式返回。
  - 在需要动态 `this` 的场景（如对象方法、事件处理中需要访问当前元素）使用传统函数。
  - 避免在箭头函数中使用 `arguments`，改用剩余参数。

### 注意事项
- **常见错误**：
  - 在对象方法中使用箭头函数导致 `this` 指向错误（指向全局或外层作用域）。
  - 尝试使用 `new` 调用箭头函数。
  - 试图访问 `arguments` 对象导致 `ReferenceError`。
- **性能问题**：无显著性能问题，但大量使用箭头函数不会影响性能。
- **兼容性**：ES6及以后环境支持，旧环境需转译。

### 代码示例
```javascript
// 词法 this 示例
function Person() {
    this.age = 0;
    setInterval(() => {
        this.age++; // 这里的 this 指向 Person 实例
    }, 1000);
}
const p = new Person();

// 错误用法：对象方法
const obj = {
    name: 'Alice',
    greet: () => {
        console.log(this.name); // this 指向全局，输出 undefined
    }
};
obj.greet();

// 剩余参数替代 arguments
const logArgs = (...args) => {
    console.log(args); // 真正的数组
};
logArgs(1, 2, 3);
```

## 四、形参与实参

### 概念
- **是什么**：
  - **形参（Parameter）**：定义函数时括号内声明的变量，用于接收传入的值。
  - **实参（Argument）**：调用函数时实际传递给函数的值。
- **为什么需要**：实现函数的参数化，使函数能够处理不同的输入，提高通用性。
- **解决什么问题**：将函数内部逻辑与外部数据解耦，函数通过形参接收数据，外部通过实参传递数据。

### 原理
- **底层实现**：当函数被调用时，JavaScript引擎会创建一个新的执行上下文，并将实参的值按顺序赋给形参变量（类似于变量赋值）。如果实参少于形参，未赋值的形参为 `undefined`；如果实参多于形参，多余的实参可通过 `arguments` 或剩余参数访问。
- **工作流程**：
  1. 调用函数时，计算实参表达式得到值。
  2. 将实参与形参一一对应（按位置匹配）。
  3. 将实参的值赋给形参（对于对象类型，传递的是引用，即“按共享传递”）。
- **关键技术点**：参数传递方式（原始类型按值传递，对象类型按引用传递）、参数匹配规则。

### 使用方法
- **基本用法**：
  ```javascript
  function greet(greeting, name) { // greeting, name 是形参
      console.log(greeting + ', ' + name);
  }
  greet('Hello', '张三'); // 'Hello', '张三' 是实参
  ```
- **常见场景**：所有函数都需要参数化。
- **最佳实践**：
  - 形参命名应有意义，体现预期数据的含义。
  - 避免过多参数（超过3个），可考虑使用对象参数。
  - 对于可选参数，通常放在参数列表末尾。

### 注意事项
- **常见错误**：
  - 混淆形参与实参，忘记实参数量可能少于形参导致 `undefined` 引发错误。
  - 修改对象类型的形参属性影响外部对象，可能导致意外副作用。
- **性能问题**：无显著性能问题，但大量参数传递可能会略微增加开销。
- **兼容性**：所有JavaScript环境都支持。

### 代码示例
```javascript
// 实参少于形参
function test(a, b) {
    console.log(a, b);
}
test(1); // 输出 1 undefined

// 实参多于形参
test(1, 2, 3); // 输出 1 2，多余实参可通过 arguments 访问

// 对象类型按引用传递
function modifyObj(obj) {
    obj.value = 100; // 修改属性会影响外部
    obj = { value: 200 }; // 重新赋值不会影响外部
}
const myObj = { value: 1 };
modifyObj(myObj);
console.log(myObj.value); // 100（属性被修改）
```

## 五、默认参数

### 概念
- **是什么**：默认参数允许在函数定义时为形参指定默认值，当实参为 `undefined` 或未传入时，使用该默认值。
- **为什么需要**：简化对缺失参数的处理，避免在函数体内手动检查并赋值。
- **解决什么问题**：解决传统做法中需要编写 `param = param || defaultValue` 的繁琐，且更安全（避免虚假值问题）。

### 原理
- **底层实现**：默认参数在函数调用时进行求值。每次调用函数，如果对应实参为 `undefined`，则计算默认值表达式并将结果赋给形参。默认值可以是表达式，甚至可以引用前面已赋值的形参。
- **工作流程**：
  1. 函数调用，创建执行上下文。
  2. 从左到右依次将实参赋给形参。
  3. 如果某个实参为 `undefined`，则使用对应的默认值表达式求值后赋值。
- **关键技术点**：默认值表达式在调用时求值、可引用前面形参、默认参数会创建一个新的作用域。

### 使用方法
- **基本用法**：
  ```javascript
  function multiply(a, b = 1) {
      return a * b;
  }
  console.log(multiply(5)); // 5
  console.log(multiply(5, 2)); // 10
  ```
- **常见场景**：
  - 可选参数，例如配置项中提供默认值。
  - 在函数重载模拟中简化逻辑。
- **最佳实践**：
  - 将带默认值的参数放在参数列表末尾。
  - 避免使用复杂的表达式作为默认值，以免影响可读性。
  - 默认值可以引用前面的参数，但要注意顺序依赖。

### 注意事项
- **常见错误**：
  - 默认值只在实参为 `undefined` 时生效，传入 `null` 不会触发默认值。
  - 默认值表达式可能引用尚未初始化的形参（顺序错误）。
- **性能问题**：默认值表达式每次调用都会重新计算，如果表达式开销大，可能影响性能。
- **兼容性**：ES6及以后环境支持。

### 代码示例
```javascript
// 默认值引用前面参数
function greet(name, greeting = 'Hello', message = `${greeting}, ${name}!`) {
    console.log(message);
}
greet('张三'); // Hello, 张三!
greet('李四', 'Hi'); // Hi, 李四!

// null 不会触发默认值
function test(a = 1) {
    console.log(a);
}
test(null); // 输出 null（不触发默认值）
test(undefined); // 输出 1
```

## 六、剩余参数

### 概念
- **是什么**：剩余参数语法允许我们将一个不定数量的参数表示为一个数组，形式为 `...变量名`。
- **为什么需要**：处理可变数量参数，替代传统的 `arguments` 对象，并提供真正的数组功能。
- **解决什么问题**：`arguments` 是类数组对象，不能直接使用数组方法，剩余参数解决了这个问题，并且语义更清晰。

### 原理
- **底层实现**：剩余参数在函数内部创建一个真正的数组，包含所有未被形参捕获的实参。剩余参数必须是最后一个形参。
- **工作流程**：
  1. 将实参按照形参列表从左到右匹配。
  2. 剩余的实参被收集到一个新数组中，赋值给剩余参数变量。
- **关键技术点**：真正的数组实例、只能出现在参数列表末尾、不包含已命名的参数。

### 使用方法
- **基本用法**：
  ```javascript
  function sum(...numbers) {
      return numbers.reduce((acc, cur) => acc + cur, 0);
  }
  console.log(sum(1, 2, 3, 4)); // 10

  function log(first, ...rest) {
      console.log(first, rest);
  }
  log('a', 'b', 'c'); // a ['b', 'c']
  ```
- **常见场景**：
  - 求和、平均值等需要处理任意数量参数的工具函数。
  - 与解构赋值结合，例如 `function foo([first, ...rest]) { ... }`。
  - 替代 `arguments` 在箭头函数中。
- **最佳实践**：
  - 剩余参数应该用于真正需要处理任意数量参数的场景。
  - 避免与 `arguments` 混用。

### 注意事项
- **常见错误**：
  - 将剩余参数放在非最后位置，导致语法错误。
  - 认为剩余参数是 `arguments` 的别名，它们不是同一个对象。
- **性能问题**：剩余参数创建新数组，若参数数量极大，可能影响性能，但通常可忽略。
- **兼容性**：ES6及以后环境支持。

### 代码示例
```javascript
// 剩余参数与解构结合
function process([first, ...rest]) {
    console.log(first, rest);
}
process([1, 2, 3]); // 1 [2, 3]

// 剩余参数使 arguments 不再需要
function test(...args) {
    args.forEach(arg => console.log(arg)); // 可以直接用数组方法
}
```

## 七、arguments 对象

### 概念
- **是什么**：`arguments` 是一个类数组对象，包含传递给函数的所有实参（箭头函数除外）。
- **为什么需要**：在ES6之前，用于访问所有传入的参数，尤其是当函数可以接受任意数量参数时。
- **解决什么问题**：提供了一种在函数内部获取所有实参的方法，而不依赖于形参定义。

### 原理
- **底层实现**：每个非箭头函数在调用时都会自动创建一个 `arguments` 对象，它是一个类数组（具有 `length` 属性和索引元素，但没有数组方法）。在非严格模式下，`arguments` 对象与命名形参存在联动关系（修改 `arguments` 会影响形参，反之亦然），但严格模式及使用默认参数、剩余参数时，这种联动被切断。
- **工作流程**：
  1. 函数调用时，`arguments` 对象被创建，包含所有传入的实参。
  2. 可以通过索引访问参数，如 `arguments[0]`。
- **关键技术点**：类数组、与形参的联动、callee属性（指向当前函数，严格模式下禁用）。

### 使用方法
- **基本用法**：
  ```javascript
  function sumAll() {
      let total = 0;
      for (let i = 0; i < arguments.length; i++) {
          total += arguments[i];
      }
      return total;
  }
  console.log(sumAll(1, 2, 3, 4)); // 10
  ```
- **常见场景**：
  - 创建可接受任意数量参数的函数（在ES6之前）。
  - 在递归中通过 `arguments.callee` 引用自身（已废弃）。
- **最佳实践**：
  - **现代开发中推荐使用剩余参数替代 `arguments`**。
  - 如果必须使用 `arguments`，建议先转换为数组：`const args = Array.from(arguments);` 或 `[...arguments]`。

### 注意事项
- **常见错误**：
  - 在箭头函数中使用 `arguments` 导致 `ReferenceError`。
  - 误以为 `arguments` 是数组，直接调用数组方法。
  - 在非严格模式下修改 `arguments` 可能意外影响形参。
- **性能问题**：`arguments` 对象在现代引擎中经过优化，但仍有轻微开销。使用剩余参数通常更优。
- **兼容性**：所有JavaScript环境都支持（除了箭头函数）。

### 代码示例
```javascript
// 转换 arguments 为数组
function test() {
    const args = Array.from(arguments);
    console.log(args.map(x => x * 2));
}
test(1, 2, 3); // [2, 4, 6]

// 严格模式下联动被切断
function strictTest(a) {
    'use strict';
    arguments[0] = 100;
    console.log(a); // 输出传入的原始值，不会变成100
}
strictTest(5); // 5
```

## 八、返回值

### 概念
- **是什么**：函数可以通过 `return` 语句将值返回给调用者。如果没有 `return` 语句或 `return` 后没有值，函数返回 `undefined`。
- **为什么需要**：函数通常需要将计算结果输出给调用方，实现函数与外部环境的通信。
- **解决什么问题**：使得函数不仅仅是执行代码，还能产生可被程序其他部分使用的值。

### 原理
- **底层实现**：当执行 `return` 语句时，JavaScript引擎会计算表达式值，将该值作为函数执行的结果，并立即退出当前函数，将控制权返回给调用方。同时，函数执行上下文被销毁（闭包除外）。
- **工作流程**：
  1. 执行函数体中的语句。
  2. 遇到 `return` 时，计算返回值。
  3. 返回值被传递给调用表达式。
  4. 函数执行结束。
- **关键技术点**：`return` 的立即退出、默认返回 `undefined`、返回值可以是任何类型（包括函数）。

### 使用方法
- **基本用法**：
  ```javascript
  function square(x) {
      return x * x;
  }
  const result = square(5); // result = 25

  function noReturn() {
      let a = 1;
      // 没有 return
  }
  console.log(noReturn()); // undefined
  ```
- **常见场景**：
  - 计算并返回结果。
  - 提前退出函数（例如验证失败时 `return false` 或 `return`）。
  - 返回函数（闭包）。
- **最佳实践**：
  - 确保函数要么始终返回一个值，要么始终无返回值（返回 `undefined`），保持一致性。
  - 避免在 `return` 后编写不可达代码。

### 注意事项
- **常见错误**：
  - 忘记写 `return` 导致函数返回 `undefined`。
  - 在箭头函数中，使用 `{}` 却忘记写 `return`，导致返回 `undefined`。
  - 在构造函数中忘记返回值，默认返回新创建的对象。
- **性能问题**：无显著性能问题。
- **兼容性**：所有JavaScript环境都支持。

### 代码示例
```javascript
// 箭头函数隐式返回
const double = x => x * 2;
console.log(double(5)); // 10

// 如果使用 {} 必须显式 return
const double2 = x => { x * 2 }; // 错误，返回 undefined
console.log(double2(5)); // undefined

// 提前返回
function divide(a, b) {
    if (b === 0) {
        return '除数不能为0';
    }
    return a / b;
}
console.log(divide(6, 0)); // 除数不能为0
```
