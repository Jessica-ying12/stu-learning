## 📚 第一阶段：数据结构与算法（6周）

> **重要提示：** 这是整个学习路线的基础，务必打牢！数据结构和算法是编程的内功，越早掌握越好。

### 为什么先学数据结构？

1. **编程基础**：数据结构是所有编程语言的基础
2. **算法思维**：培养解决问题的思维方式
3. **面试必备**：技术面试的核心考察点
4. **实际应用**：Flutter开发中处处用到（列表、树形结构、缓存等）
5. **立即实践**：可以在LeetCode上刷题，边学边练

### 学习目标

- ✅ 掌握常见数据结构的原理和实现
- ✅ 能手写链表、栈、队列、树等数据结构
- ✅ 掌握常见排序和查找算法
- ✅ 理解时间复杂度和空间复杂度
- ✅ 掌握常见算法思想（递归、回溯、分治、贪心、动态规划）
- ✅ LeetCode刷题100道以上

**学习方法：**

1. **理解概念**（30%时间）
   - 先理解数据结构的定义和特点
   - 理解为什么需要这种数据结构
   - 理解它解决什么问题

2. **手写实现**（30%时间）
   - 用Dart手写每种数据结构
   - 不看答案，自己实现
   - 实现增删改查等基本操作

3. **刷题巩固**（30%时间）
   - 在LeetCode上刷相关题目
   - 从简单到中等到困难
   - 每道题至少做两遍

4. **总结对比**（10%时间）
   - 对比不同数据结构的优劣
   - 总结使用场景
   - 整理思维导图

**排序算法对比表格：**

| 排序算法 | 平均时间 | 最坏时间 | 空间复杂度 | 稳定性 | 适用场景 |
|---------|---------|---------|-----------|--------|---------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 | 小数据、教学 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 | 小数据 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 | 小数据、基本有序 |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | 不稳定 | 中等数据 |
| 快速排序 | O(nlogn) | O(n²) | O(logn) | 不稳定 | 大数据、通用 |
| 归并排序 | O(nlogn) | O(nlogn) | O(n) | 稳定 | 大数据、需要稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(1) | 不稳定 | 大数据、内存受限 |
| 计数排序 | O(n+k) | O(n+k) | O(k) | 稳定 | 整数、范围小 |
| 桶排序 | O(n+k) | O(n²) | O(n+k) | 稳定 | 均匀分布 |
| 基数排序 | O(n*k) | O(n*k) | O(n+k) | 稳定 | 整数、字符串 |

**布局原则速记：**

- **约束向下传递**：父Widget给子Widget约束
- **尺寸向上传递**：子Widget告诉父Widget大小
- **父Widget决定位置**：父Widget安放子Widget
- **tight约束**：min=max，确定大小
- **loose约束**：min=0，最大不超过max
- **unbounded约束**：无限大小

### 4.7 Flutter原理深入（1周）

| 模块 | 详细知识点 | 需要理解的核心 |
|------|-----------|----------------|
| **三棵树** | Widget树、Element树、RenderObject树 | 为什么要有三棵树 |
| | Widget是配置、不可变 | 频繁创建对象没问题吗 |
| | Element是实例化、可变 | 桥梁作用 |
| | RenderObject负责布局和绘制 | 真正的渲染对象 |
| | 三棵树的创建和更新流程 | 渲染流水线 |
| **渲染流水线** | Build阶段 | 构建Widget树 |
| | Layout阶段 | 计算大小和位置 |
| | Paint阶段 | 绘制到Layer |
| | Compositing阶段 | 合成提交GPU |
| | Rasterization阶段 | 光栅化显示 |
| | vsync信号、帧率 | 60fps/120fps |
| **Key的作用** | Key的类型：ValueKey、ObjectKey、UniqueKey | 不同Key类型 |
| | GlobalKey | 跨Widget访问State |
| | Key的使用场景 | 列表重排、动画 |
| | canUpdate方法 | 判断能否复用Element |
| **BuildContext** | BuildContext是什么 | Element的抽象 |
| | context的作用 | 访问祖先Widget |
| | context.findAncestorWidgetOfExactType | 查找祖先 |
| | context.dependOnInheritedWidgetOfExactType | 依赖祖先 |
| **手势系统** | 命中测试HitTest | 找谁被点中 |
| | 手势识别GestureRecognizer | 识别手势类型 |
| | 手势竞技场GestureArena | 手势竞争 |
| | 手势冲突解决 | 嵌套手势处理 |
| **性能优化** | 避免不必要的build | const构造、拆分Widget |
| | RepaintBoundary | 隔离重绘 |
| | ListView.builder | 懒加载 |
| | 图片优化 | 缓存、压缩、占位 |
| | 内存泄漏 | 及时释放资源 |

### 6.2 性能优化（1周）

| 模块 | 详细知识点 | 需要理解的核心 | 优化方案 |
|------|-----------|----------------|----------|
| **渲染优化** | 避免不必要的build | Widget拆分、const构造 | 减少重建范围 |
| | RepaintBoundary | 隔离重绘区域 | 局部重绘 |
| | 避免saveLayer | 昂贵的图层操作 | 减少透明度叠加 |
| | Opacity vs AnimatedOpacity | 选择合适的透明度Widget | 性能差异 |
| | ClipPath优化 | 裁剪性能影响 | 避免复杂裁剪 |
| **列表优化** | ListView.builder | 懒加载 | 只构建可见项 |
| | itemExtent | 固定高度 | 跳过测量 |
| | cacheExtent | 缓存范围 | 预加载 |
| | addAutomaticKeepAlives | 保持状态 | 避免重建 |
| | 分页加载 | 按需加载 | 减少初始数据 |
| **图片优化** | 图片缓存 | 避免重复解码 | cached_network_image |
| | 图片压缩 | 减小文件大小 | 服务端压缩 |
| | 占位图 | 加载过程优化 | 骨架屏 |
| | 图片格式 | WebP vs PNG/JPEG | 选择合适格式 |
| | 图片尺寸 | 按需加载尺寸 | 避免加载大图 |
| **内存优化** | 及时释放资源 | dispose方法 | 取消监听、关闭流 |
| | 避免内存泄漏 | 弱引用、取消订阅 | 检查循环引用 |
| | 图片内存管理 | 及时释放大图 | 控制缓存大小 |
| | 大数据处理 | 分批处理 | 避免一次性加载 |
| **包体积优化** | 代码混淆 | --obfuscate | 减小体积+保护代码 |
| | 资源压缩 | 图片压缩、去除无用资源 | 减小资源大小 |
| | 分包加载 | 动态下载 | 按需加载功能 |
| | 移除无用代码 | Tree Shaking | 自动移除 |
| | 字体子集化 | 只包含使用的字符 | 减小字体文件 |
| **启动优化** | 延迟初始化 | 非必需功能延后 | 加快启动速度 |
| | 启动页优化 | 原生启动页 | 减少白屏时间 |
| | 预加载 | 提前加载资源 | 优化首屏 |
| **网络优化** | 请求合并 | 减少请求次数 | 批量接口 |
| | 数据缓存 | 本地缓存 | 减少网络请求 |
| | 图片懒加载 | 滚动加载 | 按需加载 |
| | 请求优先级 | 重要请求优先 | 优化体验 |

## 📊 学习效果检验标准

### 1. 费曼学习法

**四个步骤：**
1. **选择概念**：选一个要学习的概念
2. **教授他人**：用自己的话讲给别人听（或写下来）
3. **发现不足**：发现不懂的地方，回去重新学习
4. **简化类比**：用简单的语言和类比解释

**实践方法：**
- 每学完一个知识点，写一篇博客
- 给同学或朋友讲解你学到的内容
- 在社区回答别人的问题
- 录制教学视频

### 2. 刻意练习

**四个原则：**
1. **走出舒适区**：做有挑战的练习
2. **大量重复**：重复练习直到熟练
3. **持续反馈**：及时获得反馈
4. **高度专注**：全神贯注地练习

**实践方法：**
- LeetCode从简单到困难逐步提升
- 每个项目都比上一个复杂一点
- 代码review，获取反馈
- 专注学习，避免分心（番茄工作法）

### 3. 主动学习

**五种方法：**
1. **提出问题**：为什么这样设计？
2. **动手实践**：不要只看不做
3. **教授他人**：分享你的知识
4. **应用知识**：做项目、解决实际问题
5. **反思总结**：定期回顾和总结

**实践方法：**
- 每学一个知识点，问自己3个为什么
- 每看一段代码，自己敲一遍
- 写技术博客，分享学习心得
- 用学到的知识做实际项目
- 每周写学习总结

### 4. 间隔重复

**复习时间表：**
- 学习后立即复习（当天）
- 第2天复习
- 第7天复习
- 第30天复习
- 第90天复习

**实践方法：**
- 使用Anki制作记忆卡片
- 定期回顾之前的笔记
- 重做之前做过的题目
- 定期重构之前的项目

### 5. 构建知识体系

**方法：**
- 使用思维导图整理知识
- 建立知识之间的联系
- 从整体到细节学习
- 定期梳理知识结构

**实践方法：**
- 每周画一张思维导图
- 建立个人知识库（Notion/Obsidian）
- 写学习总结，梳理知识脉络
- 定期回顾整体学习路线
