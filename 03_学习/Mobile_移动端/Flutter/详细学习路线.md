| **Framework层** | Foundation库 | 基础类、动画、绘画 |
| | Rendering库 | 布局和渲染 |
| | Widgets库 | 组件库 |
| | Material/Cupertino库 | 设计语言实现 |

### 3.2 Widget系统深度解析

| 概念 | 详细知识点 | 需要理解的核心 |
|------|-----------|----------------|
| **Widget本质** | Widget是配置 | 不是最终渲染的东西 |
| | Widget不可变（immutable） | 创建后不能改 |
| | 每次build都新建Widget树 | 频繁创建对象没问题吗 |
| | Widget.canUpdate方法 | 判断能不能复用Element |
| **Widget分类** | StatelessWidget | 无状态组件 |
| | StatefulWidget | 有状态组件 |
| | InheritedWidget | 数据共享组件 |
| | RenderObjectWidget | 真正渲染的组件 |
| | ProxyWidget | 代理组件 |
| **Element** | Element是Widget实例化 | 挂在树上的节点 |
| | Element持有Widget和RenderObject | 桥梁作用 |
| | Element生命周期：创建、挂载、更新、卸载 | Element怎么活 |
| | Element树复用机制 | 更新时尽量复用Element |
| **RenderObject** | RenderObject负责布局和绘制 | 真正的渲染对象 |
| | RenderBox是常用RenderObject | 二维笛卡尔坐标系 |
| | RenderObject的parent/child关系 | 渲染树结构 |
| | attach/detach生命周期 | 进出渲染树 |
| **三棵树关系** | Widget树→Element树→RenderObject树 | 为什么要有三棵 |
| | 创建：Widget.createElement→Element | 第一棵变第二棵 |
| | mount过程：Element创建RenderObject | 第二棵变第三棵 |
| | update过程：Widget变化怎么传播 | 更新链路 |

### 3.3 渲染流水线

| 阶段 | 详细过程 | 需要理解的核心 |
|------|---------|----------------|
| **Build** | Widget.build被调用 | 创建子Widget |
| | 构建Element树 | 更新Element引用 |
| | 标记dirty Element | 需要重建的Element |
| | BuildOwner管理重建队列 | 批量处理重建 |
| **Layout** | 约束向下传递（BoxConstraints） | 父给子设限 |
| | 子Widget计算大小 | 根据约束决定大小 |
| | 尺寸向上传递 | 子告诉父我多大 |
| | RenderObject.performLayout | 具体布局逻辑 |
| | 父Widget确定子位置 | 安放子组件 |
| | 标记需要paint | 布局完成准备绘制 |
| **Paint** | PaintContext、Canvas | 画板和画笔 |
| | 绘制指令记录到Layer | 不是直接画屏幕 |
| | 绘制顺序：后序遍历 | 先画子再画父 |
| | 重绘边界（RepaintBoundary） | 局部重绘优化 |
| **Compositing** | Layer树构建 | 绘制结果分层 |
| | SceneBuilder构建场景 | 准备提交给引擎 |
| | 提交Scene给GPU线程 | 渲染数据移交 |
| **Rasterization** | GPU线程光栅化 | 把向量图变成像素 |
| | Skia执行绘制指令 | 实际画出来 |
| | 显示到屏幕 | 最终呈现 |
| **同步机制** | vsync信号 | 垂直同步脉冲 |
| | 16ms（60fps）或8ms（120fps） | 一帧有时间 |
| | 三缓冲机制 | 解决画面撕裂 |

### 3.4 布局原理

| 概念 | 详细知识点 | 需要理解的核心 |
|------|-----------|----------------|
| **BoxConstraints** | minWidth、maxWidth、minHeight、maxHeight | 约束的四个边界 |
| | tight约束（min=max） | 确定的大小 |
| | loose约束（min=0， max=固定） | 不能超过多少 |
| | 无限约束（double.infinity） | 想要多大就多大 |
| **布局协议** | 父给子约束 | 传递限制 |
| | 子返回大小 | 报大小 |
| | 父决定位置 | 安放子 |
| **常用RenderObject** | RenderPadding、RenderAlign、RenderFlex等 | 各种布局实现 |
| | performLayout具体实现 | 每种布局怎么算位置 |
| **自定义布局** | MultiChildLayoutDelegate | 多子自定义 |
| | SingleChildLayoutDelegate | 单子自定义 |
| | 自己实现performLayout | 手写布局算法 |
