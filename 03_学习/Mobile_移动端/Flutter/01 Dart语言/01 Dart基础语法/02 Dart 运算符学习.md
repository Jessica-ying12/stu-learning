## 1. 算术运算符

### 概念
- **是什么**：算术运算符用于执行基本的数学运算，包括加法（`+`）、减法（`-`）、乘法（`*`）、除法（`/`）、整除（`~/`）、取余（`%`）以及一元负号（`-expr`）和自增自减（`++`、`--`）。
- **为什么需要**：编程中几乎所有的数值计算都需要算术运算符，它们是构建表达式的基础。
- **解决什么问题**：实现对整数、浮点数的数学运算，以及变量的递增/递减操作。

### 原理
- **底层实现**：在 Dart 中，算术运算符可以被重载（通过定义类中的 `+`、`-` 等方法）。对于内置数值类型，它们直接映射到 CPU 的算术指令（或虚拟机中的对应实现）。
- **工作流程**：
  - 对于二元运算符（如 `a + b`），先计算左操作数 `a`，再计算右操作数 `b`，然后执行运算。
  - 自增/自减运算符分为前缀和后缀两种形式，前缀先修改变量再返回新值，后缀先返回原值再修改变量。
- **关键技术点**：运算符优先级（乘法类高于加法类）、结合性（左结合）。

### 使用方法
#### 基本用法
```dart
int a = 10, b = 3;
print(a + b);  // 13
print(a - b);  // 7
print(a * b);  // 30
print(a / b);  // 3.3333333333333335 (double)
print(a ~/ b); // 3 (int)
print(a % b);  // 1
print(-a);     // -10

// 自增自减
int x = 5;
print(++x); // 6 (前缀，先增后返回)
print(x++); // 6 (后缀，返回原值，然后 x 变为 7)
print(x);   // 7
```

#### 常见场景
- 计算总分、平均值、差值。
- 循环计数器递增/递减。
- 实现分页（取余判断边界）。
- 自定义类型（如向量、复数）的算术运算重载。

#### 最佳实践
- 注意整数除法用 `~/` 获取整数结果，浮点除法用 `/`。
- 避免在复杂表达式中过度依赖自增自减的副作用，优先使用清晰的语句。
- 使用括号明确运算顺序，提高可读性。

### 注意事项
- **常见错误**：
  - 误用 `/` 得到浮点数却赋值给 `int` 类型（需显式转换或使用 `~/`）。
  - 后缀自增的返回值是原值，容易导致逻辑错误。
- **性能问题**：算术运算本身很快，但在大量循环中注意避免不必要的类型转换。
- **兼容性**：所有 Dart 平台（原生、Web）均支持，但浮点数精度可能因平台略有差异。

### 代码示例
```dart
void main() {
  // 基本算术
  assert(2 + 3 == 5);
  assert(5 - 2 == 3);
  assert(3 * 4 == 12);
  assert(5 / 2 == 2.5);
  assert(5 ~/ 2 == 2);
  assert(5 % 2 == 1);

  // 自增自减
  int i = 0;
  int j = i++; // j = 0, i = 1
  int k = ++i; // k = 2, i = 2
  print('i=$i, j=$j, k=$k'); // i=2, j=0, k=2
}
```

## 2. 关系运算符

### 概念
- **是什么**：关系运算符用于比较两个值的大小或相等性，包括 `==`（相等）、`!=`（不等）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）。
- **为什么需要**：程序需要根据条件分支执行不同逻辑，关系运算符是构建条件表达式的基础。
- **解决什么问题**：判断两个值之间的关系，返回布尔值 `true` 或 `false`。

### 原理
- **底层实现**：
  - `==` 运算符可以被子类重写，用于自定义相等逻辑。默认情况下，`==` 判断两个对象是否相等（对于内置类型通常是值比较，对于普通对象默认是比较引用，除非重写）。
  - 其他关系运算符（`<`、`>` 等）也可以被重写，通常用于自定义排序。
  - 对于 `null` 的处理：`==` 会首先检查任一操作数是否为 `null`，如果两者都为 `null` 返回 `true`，仅一个为 `null` 返回 `false`；否则调用左操作数的 `==` 方法。
- **工作流程**：
  - 计算左右操作数，然后进行对应比较。
  - 对于 `==`，如果左操作数重写了 `==`，则调用其方法；否则执行默认引用比较。
- **关键技术点**：运算符优先级（关系运算符低于加法类，但高于逻辑与/或）。

### 使用方法
#### 基本用法
```dart
int x = 5, y = 10;
print(x == y);  // false
print(x != y);  // true
print(x > y);   // false
print(x < y);   // true
print(x >= 5);  // true
print(y <= 10); // true

// 字符串比较（按字典序）
print('abc' < 'abd'); // true
```

#### 常见场景
- 条件判断（`if`、`while`、三目运算符）。
- 排序算法中比较元素大小。
- 检查对象是否为 `null`（`obj == null` 或 `obj != null`）。

#### 最佳实践
- 对于自定义类，如果需要支持相等比较，应重写 `==` 和 `hashCode`。
- 使用 `identical()` 判断两个对象是否为同一个引用，避免与 `==` 混淆。
- 在可空类型检查时，优先使用 `??` 或 `?.` 而不是显式 `== null` 判断。

### 注意事项
- **常见错误**：
  - 误用 `=`（赋值）代替 `==`（相等）。
  - 重写 `==` 时未同时重写 `hashCode`，导致对象在哈希集合中行为异常。
- **性能问题**：关系运算符通常开销很小，但重写的 `==` 可能包含复杂逻辑。
- **兼容性**：所有平台一致。

### 代码示例
```dart
class Person {
  final String name;
  Person(this.name);

  @override
  bool operator ==(Object other) =>
      identical(this, other) ||
      other is Person && runtimeType == other.runtimeType && name == other.name;

  @override
  int get hashCode => name.hashCode;
}

void main() {
  var p1 = Person('Alice');
  var p2 = Person('Alice');
  print(p1 == p2); // true (因为重写了 ==)
  print(identical(p1, p2)); // false (不同实例)
}
```

## 3. 逻辑运算符

### 概念
- **是什么**：逻辑运算符用于组合布尔表达式，包括 `&&`（逻辑与）、`||`（逻辑或）、`!`（逻辑非）。
- **为什么需要**：程序中常需要多个条件同时成立或至少一个成立，逻辑运算符允许构建复合条件。
- **解决什么问题**：对布尔值进行逻辑运算，支持短路求值，提高效率并避免无效计算。

### 原理
- **底层实现**：
  - `&&` 和 `||` 是短路运算符：`&&` 左边为 `false` 则不再计算右边；`||` 左边为 `true` 则不再计算右边。
  - `!` 是取反，将 `true` 变为 `false`，反之亦然。
- **工作流程**：先计算左操作数，根据结果决定是否计算右操作数，然后返回布尔值。
- **关键技术点**：运算符优先级（`!` > `&&` > `||`），结合性均为左结合。

### 使用方法
#### 基本用法
```dart
bool a = true, b = false;
print(a && b); // false
print(a || b); // true
print(!a);     // false

// 短路特性
bool isEven(int n) {
  print('checking $n');
  return n % 2 == 0;
}

void main() {
  print(isEven(4) && isEven(6)); // 先检查4，再检查6
  print(isEven(3) && isEven(6)); // 检查3为false，停止，不检查6
}
```

#### 常见场景
- 条件判断中的复合条件。
- 安全检查：`obj != null && obj.isValid()`。
- 在赋值或返回时简化布尔表达式。

#### 最佳实践
- 将计算成本低的条件放在左边，利用短路特性优化性能。
- 避免在 `&&` 或 `||` 的右边放置有副作用（如修改状态）的表达式，以免因短路导致副作用未执行。
- 复杂条件适当使用括号分组，提高可读性。

### 注意事项
- **常见错误**：
  - 混淆位运算符 `&` 和 `|` 与逻辑运算符 `&&` 和 `||`（位运算符不短路）。
  - 在逻辑表达式中使用非布尔值（Dart 是强类型，必须显式为布尔值）。
- **性能问题**：短路特性有助于避免不必要的计算。
- **兼容性**：所有平台一致。

### 代码示例
```dart
void main() {
  String? userInput;
  // 安全调用与逻辑结合
  if (userInput != null && userInput.isNotEmpty) {
    print('输入有效: $userInput');
  } else {
    print('输入为空或null');
  }

  // 逻辑或提供默认值
  bool isLoggedIn = false;
  bool hasAccess = isLoggedIn || isGuest; // 假设 isGuest 已定义
}
```

## 4. 位运算符

### 概念
- **是什么**：位运算符直接操作整数的二进制位，包括 `&`（按位与）、`|`（按位或）、`^`（按位异或）、`~expr`（按位取反）、`<<`（左移）、`>>`（右移）、`>>>`（无符号右移）。
- **为什么需要**：底层系统编程、图形处理、加密算法、状态标志管理等场景需要高效地操作比特位。
- **解决什么问题**：提供对整数的位级操作，比算术运算更精细且通常更快。

### 原理
- **底层实现**：
  - 对于 `int` 类型，Dart 将其表示为64位二进制补码形式（但 Web 平台中整数是 JavaScript 的浮点数表示，位运算会先将操作数转为32位有符号整数）。
  - `<<` 左移低位补0；`>>` 右移保留符号位（算术右移）；`>>>` 无符号右移高位补0。
- **工作流程**：将操作数转为二进制，逐位运算，再转回整数。
- **关键技术点**：运算符优先级（移位低于加减，高于关系；按位与/或低于移位）。

### 使用方法
#### 基本用法
```dart
final a = 0b0011; // 3
final b = 0b0101; // 5

print(a & b); // 0b0001 = 1
print(a | b); // 0b0111 = 7
print(a ^ b); // 0b0110 = 6
print(~a);    // 按位取反（注意结果取决于整数位数，通常为 -4）
print(a << 1); // 0b0110 = 6
print(a >> 1); // 0b0001 = 1
print(a >>> 1); // 0b0001 = 1（同右移，但负数时不同）
```

#### 常见场景
- 权限管理（使用位掩码）。
- 快速乘除2的幂（移位代替乘除）。
- 颜色分量提取（例如从ARGB中提取R、G、B）。
- 网络协议解析。

#### 最佳实践
- 使用可读性更好的二进制字面量（如 `0b0011`）或十六进制（`0x0F`）。
- 注意移位操作的位数不应超过操作数的位宽（否则可能得到未定义结果）。
- 对于无符号右移，确认 Dart 版本 >= 2.14。

### 注意事项
- **常见错误**：
  - 混淆逻辑运算符 `&&` 和 `||` 与位运算符。
  - 在 Web 平台上，位运算操作数被截断为32位，可能导致与原生平台不同的结果（特别是大数或负数）。
- **性能问题**：位运算非常快，常用于性能敏感代码。
- **兼容性**：
  - `>>>` 需要 Dart 2.14+。
  - Web 平台的位运算行为与原生平台有差异（详见 [Bitwise operations platform differences](https://dart.dev/guides/language/numbers#bitwise-operations)）。

### 代码示例
```dart
void main() {
  // 权限标志示例
  const read = 0b100;
  const write = 0b010;
  const execute = 0b001;

  int userPerm = read | write; // 6 (110)

  bool canRead = (userPerm & read) != 0; // true
  bool canExecute = (userPerm & execute) != 0; // false

  // 颜色提取
  int color = 0xAARRGGBB; // 假设 0xFF336699
  int red = (color >> 16) & 0xFF;
  int green = (color >> 8) & 0xFF;
  int blue = color & 0xFF;
}
```

## 5. 条件运算符（`?:` 和 `??`）

### 概念
- **是什么**：条件运算符包括三目运算符 `condition ? expr1 : expr2` 和空值合并运算符 `expr1 ?? expr2`。
- **为什么需要**：提供简洁的表达式形式替代简单的 `if-else` 语句，提高代码紧凑度。
- **解决什么问题**：
  - `?:` 根据布尔条件选择两个值之一。
  - `??` 在表达式可能为 `null` 时提供默认值，简化空值处理。

### 原理
- **底层实现**：
  - `?:` 先计算条件，根据结果选择计算其中一个分支，另一个分支不会被求值（短路）。
  - `??` 先计算左操作数，如果非 `null` 则返回，否则计算右操作数并返回（同样短路）。
- **工作流程**：基于条件的短路选择。
- **关键技术点**：运算符优先级（`?:` 优先级较低，低于赋值；`??` 优先级高于条件但低于逻辑或）。

### 使用方法
#### 基本用法
```dart
// 三目运算符
bool isPublic = true;
var visibility = isPublic ? 'public' : 'private'; // 'public'

// 空值合并
String? name;
var displayName = name ?? 'Guest'; // 'Guest'
```

#### 常见场景
- 根据条件初始化变量。
- 在表达式内部进行简单分支，例如 `Text(isLogin ? 'Welcome' : 'Please login')`。
- 提供默认值，尤其是从可能为 `null` 的配置、函数返回值中取值。

#### 最佳实践
- 避免嵌套过深的条件运算符，以免降低可读性。
- `??` 可以与 `?.` 结合使用：`final length = obj?.length ?? 0;`
- 在 Dart 中，`??` 也可以用于赋值：`a ??= b;` 表示如果 `a` 为 `null` 则赋值 `b`。

### 注意事项
- **常见错误**：
  - 三目运算符的分支类型不一致（需满足类型兼容）。
  - 误用 `?:` 执行复杂逻辑而不是返回表达式（应使用 `if-else`）。
- **性能问题**：短路特性避免不必要的计算。
- **兼容性**：所有 Dart 版本支持。

### 代码示例
```dart
void main() {
  // 三目运算符
  int score = 85;
  String grade = score >= 60 ? 'Pass' : 'Fail';

  // 空值合并
  String? nickname;
  String display = nickname ?? 'Anonymous';

  // 链式使用
  int? maybeInt;
  int result = maybeInt ?? calculateDefault(); // 仅当 maybeInt 为 null 时调用函数
}

int calculateDefault() {
  print('Calculating default...');
  return 42;
}
```

## 6. 级联运算符（`..` 和 `?..`）

### 概念
- **是什么**：级联运算符允许在同一个对象上连续执行多个操作，而无需重复引用该对象。`..` 用于非空对象，`?..` 用于可能为 `null` 的对象（如果对象为 `null`，则整个级联被跳过）。
- **为什么需要**：减少重复代码，使对象初始化或操作链更流畅，类似建造者模式。
- **解决什么问题**：对同一对象进行一系列方法调用或属性赋值时，避免创建临时变量或重复写对象名。

### 原理
- **底层实现**：级联不是一个运算符，而是 Dart 语法的一部分。它实际上是对左侧对象依次执行右侧的操作，并返回原对象（忽略中间结果）。
- **工作流程**：
  - 对于 `..`，先求值左侧表达式得到对象，然后对对象依次执行每个级联操作，最后整个级联表达式的值就是该对象。
  - `?..` 类似，但如果左侧为 `null`，则跳过级联，整个表达式值为 `null`。
- **关键技术点**：级联可以嵌套，并且可以调用方法或访问属性（包括赋值）。

### 使用方法
#### 基本用法
```dart
var paint = Paint()
  ..color = Colors.black
  ..strokeCap = StrokeCap.round
  ..strokeWidth = 5.0;

// 等价于：
var paint = Paint();
paint.color = Colors.black;
paint.strokeCap = StrokeCap.round;
paint.strokeWidth = 5.0;
```

#### 常见场景
- 对象初始化（尤其是 Flutter 的样式配置）。
- 构建复杂数据结构，例如建造者模式。
- 对 DOM 元素进行多个操作（在 Dart HTML 库中）。

#### 最佳实践
- 当链式调用可能因中间方法返回 `void` 而中断时，注意不要错误使用级联。
- 使用 `?..` 处理可能为 `null` 的对象，避免空异常。
- 可以嵌套级联构建嵌套对象，但注意可读性。

### 注意事项
- **常见错误**：
  - 对返回 `void` 的方法使用级联，导致编译错误（因为 `void` 不是对象）。
  - 混淆级联和成员访问：`obj..method()` 返回 `obj`，而 `obj.method()` 返回 `method` 的返回值。
- **性能问题**：无显著性能影响，只是语法糖。
- **兼容性**：所有 Dart 版本支持 `..`，`?..` 需要 Dart 2.12+（空安全）。

### 代码示例
```dart
class Person {
  String name = '';
  int age = 0;
  void greet() => print('Hi, I\'m $name');
}

void main() {
  // 级联初始化
  var p = Person()
    ..name = 'Alice'
    ..age = 30
    ..greet(); // 输出 "Hi, I'm Alice"

  // 空安全级联
  Person? maybePerson;
  maybePerson?..name = 'Bob'..age = 40; // 因为 maybePerson 为 null，什么也不做
}
```

## 7. 展开运算符（`...` 和 `...?`）

### 概念
- **是什么**：展开运算符用于在集合字面量（列表、集合、映射）中插入另一个集合的所有元素。`...` 用于非空集合，`...?` 用于可能为 `null` 的集合。
- **为什么需要**：方便地组合集合，避免手动添加元素或使用循环。
- **解决什么问题**：在声明集合时，将现有集合的元素“展开”并入新集合，简化集合构建。

### 原理
- **底层实现**：展开运算符是集合字面量语法的一部分，在编译时或运行时将源集合的元素逐个添加到新集合中。
- **工作流程**：
  - 当解析集合字面量时，遇到 `...expr` 会先计算 `expr`，若结果为集合，则遍历其所有元素并添加到当前集合中。
  - 如果使用 `...?` 且表达式为 `null`，则跳过，不添加任何元素。
- **关键技术点**：不是独立的运算符，没有优先级概念；在集合字面量中展开的表达式可以是任何表达式，但必须产生可迭代对象。

### 使用方法
#### 基本用法
```dart
var list = [1, 2, 3];
var list2 = [0, ...list];        // [0, 1, 2, 3]

var maybeList;
var list3 = [0, ...?maybeList];   // [0] (因为 maybeList 为 null)
```

#### 常见场景
- 合并列表。
- 在 Flutter 中构建子组件列表时使用 `...` 插入多个组件。
- 从函数返回集合时，在集合字面量中展开参数。

#### 最佳实践
- 注意展开顺序：展开的位置决定了元素插入顺序。
- 在可能为 `null` 的集合前使用 `...?` 避免运行时错误。
- 展开运算符可以多次使用，也可以与普通元素混合。

### 注意事项
- **常见错误**：
  - 对非集合类型使用展开（编译错误）。
  - 忘记使用 `...?` 导致空异常。
- **性能问题**：展开会复制元素，对于大集合可能有性能开销，但通常可接受。
- **兼容性**：需要 Dart 2.3+ 支持展开，空安全展开需要 Dart 2.12+。

### 代码示例
```dart
void main() {
  var numbers = [4, 5, 6];
  var allNumbers = [1, 2, 3, ...numbers, 7, 8]; // [1,2,3,4,5,6,7,8]

  var nullableList;
  var safeList = [0, ...?nullableList]; // [0]

  // 在 Flutter 中常见
  // children: [
  //   Text('Header'),
  //   ...buildItems(),
  //   Text('Footer'),
  // ],
}
```

## 8. 赋值运算符

### 概念
- **是什么**：赋值运算符用于给变量赋值，包括基本赋值 `=`、空值赋值 `??=` 和复合赋值（如 `+=`、`-=`、`*=` 等）。
- **为什么需要**：变量存储需要赋值操作；复合赋值简化了“变量自身运算后再赋值”的常见模式。
- **解决什么问题**：
  - `=` 将右侧值存入左侧变量。
  - `??=` 仅在变量为 `null` 时赋值，避免覆盖已有非空值。
  - 复合赋值将运算和赋值合并，代码更简洁。

### 原理
- **底层实现**：赋值运算符是右结合的，即 `a = b = c` 等价于 `a = (b = c)`。复合赋值 `a op= b` 完全等价于 `a = a op b`（但 `a` 只计算一次）。
- **工作流程**：
  - 对于 `=`，计算右侧表达式，然后将值赋给左侧变量（左侧必须是可赋值的表达式，如变量、属性）。
  - 对于 `??=`，先判断左侧变量是否为 `null`，若是则赋值，否则保持不变。
  - 复合赋值先计算 `a op b`，再将结果赋给 `a`。
- **关键技术点**：优先级很低（仅高于条件运算符），因此赋值通常最后执行。

### 使用方法
#### 基本用法
```dart
int a = 5;          // 基本赋值
a += 3;             // a = a + 3 → 8
a *= 2;             // a = a * 2 → 16

int? b;
b ??= 10;           // b 为 null，赋值为 10
b ??= 5;            // b 非 null，保持不变（仍为 10）
```

#### 常见场景
- 变量初始化。
- 累加、累乘等循环计算。
- 安全地给可空变量赋默认值。

#### 最佳实践
- 使用 `??=` 避免覆盖已有值，特别在延迟初始化或配置场景。
- 复合赋值能减少重复输入，但注意类型兼容（`a += b` 要求 `a` 支持 `+` 运算且结果可赋给 `a`）。

### 注意事项
- **常见错误**：
  - 在条件表达式中误用 `=` 而不是 `==`。
  - 对不可赋值的表达式使用赋值（如常量、字面量）。
- **性能问题**：无特殊性能问题。
- **兼容性**：所有版本支持 `=` 和复合赋值；`??=` 需要 Dart 2.12+（空安全）。

### 代码示例
```dart
void main() {
  var list = [1, 2, 3];
  list[1] = 5;          // 赋值给列表元素
  print(list);          // [1,5,3]

  int total = 0;
  for (int i = 1; i <= 10; i++) {
    total += i;         // 复合赋值累加
  }
  print(total);         // 55

  String? name;
  name ??= 'Default';
  print(name);          // Default
}
```

## 9. 类型测试运算符

### 概念
- **是什么**：类型测试运算符包括 `is`、`is!` 和 `as`，用于在运行时检查或转换对象类型。
- **为什么需要**：Dart 是类型安全的，但有时需要处理多态或动态类型，需要类型检查确保安全操作。
- **解决什么问题**：
  - `is` 判断对象是否属于某类型，安全地进入相应分支。
  - `as` 强制类型转换，在确信类型时使用。
  - `is!` 是 `is` 的否定形式。

### 原理
- **底层实现**：基于对象的运行时类型信息（RTTI）。`is` 检查对象的类型是否是指定类型或其子类型。`as` 类似强制转换，如果类型不匹配则抛出 `CastError`。
- **工作流程**：
  - `obj is T`：检查 `obj` 的运行时类型是否兼容 `T`。
  - `obj as T`：如果 `obj` 是 `T` 类型或其子类型，则返回 `obj`（但类型被视为 `T`），否则抛出异常。
- **关键技术点**：优先级低于关系运算符，高于相等。

### 使用方法
#### 基本用法
```dart
Object obj = 'hello';
if (obj is String) {
  print(obj.length); // 自动转为 String
}

String str = obj as String; // 转换，如果 obj 不是 String 则抛出异常
```

#### 常见场景
- 处理集合中不同类型的元素。
- 在泛型或动态类型上下文中向下转型。
- 使用 `as` 指定库前缀（如 `import 'lib.dart' as lib;`）。

#### 最佳实践
- 优先使用 `is` 检查后再使用，避免 `as` 异常。
- 在 Dart 中，`is` 检查后变量会自动提升（类型收窄），无需显式转换。
- 使用 `is!` 表示否定，比 `!(obj is T)` 更简洁。

### 注意事项
- **常见错误**：
  - 使用 `as` 转换失败未捕获异常。
  - 对 `null` 使用 `as`：`null as String` 返回 `null`（因为 `null` 可以赋值给任何可空类型）。
- **性能问题**：类型检查有一定开销，但通常可忽略。
- **兼容性**：所有版本支持。

### 代码示例
```dart
void printLength(Object obj) {
  if (obj is String) {
    print('String length: ${obj.length}');
  } else if (obj is List) {
    print('List length: ${obj.length}');
  } else {
    print('Not a string or list');
  }
}

void main() {
  printLength('hello');        // String length: 5
  printLength([1, 2, 3]);      // List length: 3
  printLength(42);             // Not a string or list
}
```

## 10. 其他运算符（成员访问、下标、非空断言）

### 概念
- **是什么**：这些运算符包括：
  - `.` 成员访问
  - `?.` 条件成员访问
  - `[]` 下标访问
  - `?[]` 条件下标访问
  - `!` 非空断言
- **为什么需要**：它们提供了访问对象属性和方法的语法，并处理空安全场景。
- **解决什么问题**：
  - `.` 和 `[]` 是基本访问方式。
  - `?.` 和 `?[]` 允许在可能为 `null` 的对象上安全访问，避免抛出异常。
  - `!` 用于向编译器断言某个值非 `null`，当开发者确信非空但类型系统无法推断时使用。

### 原理
- **底层实现**：
  - `.` 和 `[]` 是语言内置的访问语法，可被子类重写（如定义 `[]` 操作符）。
  - `?.` 和 `?[]` 是空安全语法糖：如果接收者为 `null`，则表达式结果为 `null`，不会调用成员。
  - `!` 是一个类型断言，将可空类型转为非空类型，如果值为 `null` 则抛出 `TypeError`。
- **工作流程**：
  - `obj?.property`：先判断 `obj` 是否为 `null`，是则返回 `null`，否则返回 `obj.property`。
  - `obj!`：检查 `obj`，若为 `null` 则抛出异常，否则返回 `obj`（类型变为非空）。
- **关键技术点**：优先级（`.` 和 `[]` 很高，几乎最高）。

### 使用方法
#### 基本用法
```dart
class Person {
  String name;
  Person(this.name);
}

void main() {
  Person? p;
  print(p?.name); // null (不会抛出异常)

  // p!.name;     // 抛出异常，因为 p 为 null

  var list = [1, 2, 3];
  print(list[1]); // 2

  List<int>? maybeList;
  print(maybeList?[1]); // null
}
```

#### 常见场景
- 链式调用中处理可能为 `null` 的对象。
- 从集合中安全取值。
- 当从函数返回值或经过复杂逻辑后确信非空时，使用 `!` 消除编译错误。

#### 最佳实践
- 优先使用 `?.` 和 `??` 组合，而不是滥用 `!`。
- 仅当无法通过其他方式证明非空且确信不会为 `null` 时，才使用 `!`。
- 重写 `[]` 时应注意遵循集合语义。

### 注意事项
- **常见错误**：
  - 滥用 `!` 导致运行时异常。
  - 对 `null` 使用 `?.` 后继续级联，但忘记使用 `?..`。
- **性能问题**：`?.` 和 `?[]` 增加了一次 null 检查，开销极小。
- **兼容性**：`?.`、`?[]`、`!` 需要 Dart 2.12+（空安全）。

### 代码示例
```dart
void main() {
  String? getPrefixedName(String? name, String prefix) {
    // 使用 ?. 和 ?? 提供默认值
    return name?.toLowerCase()?.prefixed(prefix) ?? 'default';
  }

  // 非空断言场景
  List<int> parseNumbers(String input) {
    var maybeList = tryParse(input); // 返回 List<int>?
    // 假设根据上下文肯定不为 null
    return maybeList!;
  }
}
```
