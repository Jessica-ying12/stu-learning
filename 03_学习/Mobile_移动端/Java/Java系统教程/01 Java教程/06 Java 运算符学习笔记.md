Java 提供了一套丰富的运算符来操纵变量，可以分为以下几组：

1. **算术运算符**
2. **关系运算符**
3. **位运算符**
4. **逻辑运算符**

## 二、算术运算符

### 2.1 算术运算符列表

假设整数变量 A = 10，B = 20：

|操作符|描述|例子|
|---|---|---|
|`+`|加法|A + B = 30|
|`-`|减法|A - B = -10|
|`*`|乘法|A * B = 200|
|`/`|除法|B / A = 2|
|`%`|取模（余数）|B % A = 0|
|`++`|自增（值增加1）|B++ 或 ++B = 21|
|`--`|自减（值减少1）|B-- 或 --B = 19|

### 2.2 自增自减运算符的区别

#### ++B（前置自增）

- 左值，直接原地操作
- 先自增，再使用

#### B++（后置自增）

- 右值，使用临时变量
- 先使用，再自增

### 2.3 示例代码

```java
public class Test {
    public static void main(String args[]) {
        int a = 10;
        int b = 20;
        int c = 25;
        int d = 25;
        
        System.out.println("a + b = " + (a + b));    // 30
        System.out.println("a - b = " + (a - b));    // -10
        System.out.println("a * b = " + (a * b));    // 200
        System.out.println("b / a = " + (b / a));    // 2
        System.out.println("b % a = " + (b % a));    // 0
        System.out.println("c % a = " + (c % a));    // 5
        
        System.out.println("a++   = " + (a++));      // 10（先使用再自增）
        System.out.println("a--   = " + (a--));      // 11（先使用再自减）
        
        // 查看 d++ 与 ++d 的不同
        System.out.println("d++   = " + (d++));      // 25（先使用）
        System.out.println("d     = " + d);          // 26（已自增）
        System.out.println("++d   = " + (++d));      // 27（先自增再使用）
    }
}
```

**输出**：

```
a + b = 30
a - b = -10
a * b = 200
b / a = 2
b % a = 0
c % a = 5
a++   = 10
a--   = 11
d++   = 25
d     = 26
++d   = 27
```

## 三、关系运算符

### 3.1 关系运算符列表

假设 A = 10，B = 20：

|运算符|描述|例子|
|---|---|---|
|`==`|检查两个操作数是否相等|(A == B) 为 false|
|`!=`|检查两个操作数是否不相等|(A != B) 为 true|
|`>`|检查左操作数是否大于右操作数|(A > B) 为 false|
|`<`|检查左操作数是否小于右操作数|(A < B) 为 true|
|`>=`|检查左操作数是否大于或等于右操作数|(A >= B) 为 false|
|`<=`|检查左操作数是否小于或等于右操作数|(A <= B) 为 true|

### 3.2 示例代码

```java
public class Test {
    public static void main(String args[]) {
        int a = 10;
        int b = 20;
        
        System.out.println("a == b = " + (a == b));  // false
        System.out.println("a != b = " + (a != b));  // true
        System.out.println("a > b = " + (a > b));    // false
        System.out.println("a < b = " + (a < b));    // true
        System.out.println("b >= a = " + (b >= a));  // true
        System.out.println("b <= a = " + (b <= a));  // false
    }
}
```

## 四、位运算符

### 4.1 位运算基础

假设 a = 60，b = 13：

```
A = 0011 1100
B = 0000 1101
-----------------
A & B  = 0000 1100  (12)
A | B  = 0011 1101  (61)
A ^ B  = 0011 0001  (49)
~A     = 1100 0011  (-61)
```

### 4.2 位运算符列表

| 操作符   | 描述               | 例子            |
| ----- | ---------------- | ------------- |
| `&`   | 按位与（两位都为1时结果为1）  | (A & B) = 12  |
| `\|`  | 按位或（任一位为1时结果为1）  | (A \| B) = 61 |
| `^`   | 按位异或（两位不同时结果为1）  | (A ^ B) = 49  |
| `~`   | 按位补（翻转每一位）       | (~A) = -61    |
| `<<`  | 左移（左移n位相当于乘以2^n） | A << 2 = 240  |
| `>>`  | 右移（右移n位相当于除以2^n） | A >> 2 = 15   |
| `>>>` | 无符号右移（空位以0填充）    | A >>> 2 = 15  |

## 补充：位运算基础解释

### 1. 二进制表示

首先理解二进制：

- 十进制 60 = 二进制 0011 1100
- 十进制 13 = 二进制 0000 1101

### 2. 各个位运算符详解

#### `&` 按位与（AND）

**规则**：两个位都是 1 时，结果才是 1

```
  0011 1100  (60)
& 0000 1101  (13)
-----------
  0000 1100  (12)
```

**用途**：常用于提取特定位、判断奇偶数

```dart
// 判断是否为偶数
if (number & 1 == 0) { /* 偶数 */ }
```

#### `|` 按位或（OR）

**规则**：任意一个位是 1，结果就是 1

```
  0011 1100  (60)
| 0000 1101  (13)
-----------
  0011 1101  (61)
```

**用途**：常用于设置特定位

```dart
// 设置权限标志
int permissions = READ | WRITE | EXECUTE;
```

#### `^` 按位异或（XOR）

**规则**：两个位不同时，结果是 1；相同时是 0

```
  0011 1100  (60)
^ 0000 1101  (13)
-----------
  0011 0001  (49)
```

**用途**：常用于加密、交换变量

```dart
// 不用临时变量交换两个数
a = a ^ b;
b = a ^ b;
a = a ^ b;
```

#### `~` 按位补（NOT）

**规则**：翻转每一位（0变1，1变0）

```
~0011 1100 = 1100 0011
```

**注意**：由于补码表示，~60 = -61（不是简单的翻转）

#### `<<` 左移

**规则**：所有位向左移动 n 位，右边补 0

```
  0011 1100  (60)
<< 2
-----------
  1111 0000  (240)
```

**效果**：左移 n 位 = 乘以 2^n

- 60 << 2 = 60 × 4 = 240

#### `>>` 右移

**规则**：所有位向右移动 n 位，左边补符号位

```
  0011 1100  (60)
>> 2
-----------
  0000 1111  (15)
```

**效果**：右移 n 位 = 除以 2^n（向下取整）

- 60 >> 2 = 60 ÷ 4 = 15

#### `>>>` 无符号右移

**规则**：所有位向右移动 n 位，左边补 0（忽略符号）

```
  0011 1100  (60)
>>> 2
-----------
  0000 1111  (15)
```

**区别**：对于负数，`>>` 和 `>>>` 结果不同

#### 记忆技巧

- **&（与）**：都是 1 才是 1，像"严格的筛选"
- **|（或）**：有 1 就是 1，像"宽松的合并"
- **^（异或）**：不同才是 1，像"找不同"
- **<<（左移）**：向左移 = 变大 = 乘法
- **>>（右移）**：向右移 = 变小 = 除法


### 4.3 示例代码

```java
public class Test {
    public static void main(String args[]) {
        int a = 60;  /* 60 = 0011 1100 */
        int b = 13;  /* 13 = 0000 1101 */
        int c = 0;
        
        c = a & b;   /* 12 = 0000 1100 */
        System.out.println("a & b = " + c);
        
        c = a | b;   /* 61 = 0011 1101 */
        System.out.println("a | b = " + c);
        
        c = a ^ b;   /* 49 = 0011 0001 */
        System.out.println("a ^ b = " + c);
        
        c = ~a;      /* -61 = 1100 0011 */
        System.out.println("~a = " + c);
        
        c = a << 2;  /* 240 = 1111 0000 */
        System.out.println("a << 2 = " + c);
        
        c = a >> 2;  /* 15 = 1111 */
        System.out.println("a >> 2 = " + c);
        
        c = a >>> 2; /* 15 = 0000 1111 */
        System.out.println("a >>> 2 = " + c);
    }
}
```

**输出**：

```
a & b = 12
a | b = 61
a ^ b = 49
~a = -61
a << 2 = 240
a >> 2 = 15
a >>> 2 = 15
```

## 五、逻辑运算符

### 5.1 逻辑运算符列表

假设布尔变量 A = true，B = false：

| 操作符  | 描述                 | 例子               |
| ---- | ------------------ | ---------------- |
| `&&` | 逻辑与（两个操作数都为真时结果为真） | (A && B) 为 false |
| `\|` | 逻辑或（任一操作数为真时结果为真）  | (A \| B) 为 true  |
| `!`  | 逻辑非（反转逻辑状态）        | !(A && B) 为 true |

### 5.2 短路特性

- `&&`：如果左侧为 false，右侧不会执行
- `||`：如果左侧为 true，右侧不会执行

### 5.3 示例代码

```java
public class Test {
    public static void main(String args[]) {
        boolean a = true;
        boolean b = false;
        
        System.out.println("a && b = " + (a && b));      // false
        System.out.println("a || b = " + (a || b));      // true
        System.out.println("!(a && b) = " + !(a && b));  // true
    }
}
```

## 六、赋值运算符

### 6.1 赋值运算符列表

|操作符|描述|例子|
|---|---|---|
|`=`|简单赋值|C = A + B|
|`+=`|加后赋值|C += A 等价于 C = C + A|
|`-=`|减后赋值|C -= A 等价于 C = C - A|
|`*=`|乘后赋值|C *= A 等价于 C = C * A|
|`/=`|除后赋值|C /= A 等价于 C = C / A|
|`%=`|取模后赋值|C %= A 等价于 C = C % A|
|`<<=`|左移后赋值|C <<= 2 等价于 C = C << 2|
|`>>=`|右移后赋值|C >>= 2 等价于 C = C >> 2|
|`&=`|按位与后赋值|C &= 2 等价于 C = C & 2|
|`^=`|按位异或后赋值|C ^= 2 等价于 C = C ^ 2|
|`\|=`|按位或后赋值|C \|= 2 等价于 C = C \| 2|

### 6.2 示例代码

```java
public class Test {
    public static void main(String args[]) {
        int a = 10;
        int b = 20;
        int c = 0;
        
        c = a + b;
        System.out.println("c = a + b = " + c);    // 30
        
        c += a;
        System.out.println("c += a = " + c);       // 40
        
        c -= a;
        System.out.println("c -= a = " + c);       // 30
        
        c *= a;
        System.out.println("c *= a = " + c);       // 300
        
        a = 10;
        c = 15;
        c /= a;
        System.out.println("c /= a = " + c);       // 1
        
        a = 10;
        c = 15;
        c %= a;
        System.out.println("c %= a = " + c);       // 5
        
        c <<= 2;
        System.out.println("c <<= 2 = " + c);      // 20
        
        c >>= 2;
        System.out.println("c >>= 2 = " + c);      // 5
    }
}
```

## 七、条件运算符（三元运算符）

### 7.1 语法格式

```java
variable = (expression) ? value_if_true : value_if_false;
```

### 7.2 示例代码

```java
public class Test {
    public static void main(String args[]) {
        int a, b;
        a = 10;
        
        b = (a == 1) ? 20 : 30;
        System.out.println("Value of b is : " + b);  // 30
        
        b = (a == 10) ? 20 : 30;
        System.out.println("Value of b is : " + b);  // 20
    }
}
```

**输出**：

```
Value of b is : 30
Value of b is : 20
```

## 八、instanceof 运算符

### 8.1 用途

检查对象是否是特定类型（类或接口）的实例。

### 8.2 语法格式

```java
(Object reference variable) instanceof (class/interface type)
```

这个格式可以拆解为：

```java
对象变量 instanceof 类型名称
```

**返回值**：`true` 或 `false`（布尔值）
**核心作用**：在运行时检查对象的实际类型，避免类型转换错误。

### 8.3 示例代码

```java
// 示例 1
String name = "James";
boolean result = name instanceof String;  // true

// 示例 2
class Vehicle {}

public class Car extends Vehicle {
    public static void main(String args[]) {
        Vehicle a = new Car();
        boolean result = a instanceof Car;
        System.out.println(result);  // true
    }
}
```

**说明**：如果被比较的对象兼容于右侧类型，运算符返回 true。

## 九、运算符优先级

### 9.1 优先级表（从高到低）

| 类别   | 操作符                                | 关联性 |
| ---- | ---------------------------------- | --- |
| 后缀   | `() [] .`                          | 左到右 |
| 一元   | `++ -- ! ~`                        | 右到左 |
| 乘性   | `* / %`                            | 左到右 |
| 加性   | `+ -`                              | 左到右 |
| 移位   | `<< >> >>>`                        | 左到右 |
| 关系   | `< <= > >=`                        | 左到右 |
| 相等   | `== !=`                            | 左到右 |
| 按位与  | `&`                                | 左到右 |
| 按位异或 | `^`                                | 左到右 |
| 按位或  | \|                                 | 左到右 |
| 逻辑与  | `&&`                               | 左到右 |
| 逻辑或  | `\|`                               | 左到右 |
| 条件   | `? :`                              | 右到左 |
| 赋值   | = += -= *= /= %= >>= <<= &= ^= \|= | 右到左 |
| 逗号   | `,`                                | 左到右 |
|      |                                    |     |

### 9.2 优先级示例

```java
// 示例 1
int x = 7 + 3 * 2;  // x = 13（先乘后加）

// 示例 2
int result = (1 + 3) + (3 + 2) * 2;  // 14（括号优先）

// 示例 3
boolean flag = 5 > 3 && 10 < 20;  // true（先关系后逻辑）
```

## 十、重要知识点总结

### 10.1 算术运算符

- `++` 和 `--` 的前置和后置区别
- 整数除法会截断小数部分
- `%` 取模运算可用于判断奇偶性

### 10.2 位运算符

- 位运算效率高，常用于底层优化
- 左移 `<<` 相当于乘以 2 的幂次
- 右移 `>>` 相当于除以 2 的幂次
- `>>>` 无符号右移，高位补 0

### 10.3 逻辑运算符

- `&&` 和 `||` 具有短路特性
- 短路可以提高效率并避免空指针异常

### 10.4 运算符优先级记忆

1. **括号最优先**
2. **一元运算符**（`++`、`--`、`!`、`~`）
3. **算术运算符**（`*`、`/`、`%` > `+`、`-`）
4. **移位运算符**
5. **关系运算符**
6. **相等运算符**
7. **位运算符**（`&` > `^` > `|`）
8. **逻辑运算符**（`&&` > `||`）
9. **条件运算符**（`? :`）
10. **赋值运算符**

### 10.5 最佳实践

```java
// ✅ 使用括号明确优先级
int result = (a + b) * c;

// ✅ 复合赋值运算符更简洁
count += 1;  // 而不是 count = count + 1;

// ✅ 使用三元运算符简化条件赋值
int max = (a > b) ? a : b;

// ✅ 利用短路特性避免空指针
if (obj != null && obj.method()) { }

// ❌ 避免过于复杂的表达式
// 不好：int x = a++ + ++b * c-- / --d;
// 好：分步计算，提高可读性
```

### 10.6 常见错误

```java
// ❌ 整数除法精度丢失
int result = 5 / 2;  // 2，不是 2.5

// ✅ 使用浮点数
double result = 5.0 / 2;  // 2.5

// ❌ 混淆 == 和 =
if (x = 5) { }  // 编译错误

// ✅ 正确使用
if (x == 5) { }

// ❌ 位运算符和逻辑运算符混淆
if (a & b) { }  // 位与，不是逻辑与

// ✅ 正确使用
if (a && b) { }  // 逻辑与
```
