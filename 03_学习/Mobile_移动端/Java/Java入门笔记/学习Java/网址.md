## 📌 第一阶段：Java 基础语法

### 学习内容（按顺序）

1. 环境搭建（JDK安装 + IDEA/VSCode）
2. 基本语法：变量、数据类型、运算符、流程控制（if/switch/for/while）
3. 面向对象：类与对象、封装/继承/多态、super/this/final/static
4. 抽象类与接口：abstract、interface（重点）、匿名内部类
5. 常用类：Object（equals/hashCode/toString）、String 不可变性、StringBuilder
6. 异常处理：try-catch-finally、throws/throw、自定义异常
7. **集合框架（重点）**：Collection/Map 体系、ArrayList vs LinkedList、HashSet、**HashMap 底层（数组+链表+红黑树）**
8. 泛型：泛型类/方法、类型擦除、通配符
9. I/O 流：字节流/字符流、缓冲流、序列化
10. **多线程入门**：Thread/Runnable、synchronized、线程 6 种状态
11. 反射与注解：Class 对象、反射操作、自定义注解
12. Lambda 与 Stream：函数式接口、stream().map/filter/collect

## 📌 第五阶段：并发编程底层（预计 2-3 周）

### 学习内容

|模块|要点|
|---|---|
|**JMM（Java内存模型）**|可见性（volatile）、原子性、有序性（happens-before 8大规则）|
|**synchronized 底层**|对象头 Mark Word、Monitor 机制、**锁升级过程**（无锁→偏向锁→轻量级锁→重量级锁）|
|**volatile 原理**|内存屏障（LoadLoad/StoreStore/LoadStore/StoreStore）、禁止指令重排序、缓存一致性协议 MESI|
|**★ AQS**|AbstractQueuedSynchronizer → ReentrantLock/CountDownLatch/Semaphore 的基石，理解 state + CLH 队列 + 线程阻塞|
|**CAS**|compareAndSwapInt、ABA 问题（AtomicStampedReference加版本号）|
|**线程池**|ThreadPoolExecutor 7大参数 + 工作流程 + 拒绝策略（AbortPolicy/CallerRunsPolicy/DiscardPolicy/DiscardOldestPolicy）|
|**并发容器**|ConcurrentHashMap（JDK7分段锁 vs JDK8 CAS+synchronized）、CopyOnWriteArrayList（写时复制）|
