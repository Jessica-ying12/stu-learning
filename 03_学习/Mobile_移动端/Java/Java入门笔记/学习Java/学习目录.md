### 5.1 JVM 虚拟机（2-3周）

|周次|模块|具体掌握|
|---|---|---|
|**第1周**|内存区域 & 对象|堆（新生代Eden/S0/S1/老年代）、栈（栈帧：局部变量表/操作数栈/动态链接/方法出口）、方法区（元空间）、程序计数器；**对象创建过程（类加载→分配内存→初始化→设置对象头）**、对象在内存中的布局（对象头/实例数据/对齐填充）|
|**第2周**|垃圾回收 & 调优|**GC 算法**（标记-复制用在新生代、标记-清除用在老年代、标记-整理）、**G1收集器**（Region划分、停顿预测模型）、常用JVM参数（-Xms/-Xmx/-Xmn/-XX:+PrintGCDetails）、OOM 分析（MAT工具、VisualVM）|
|**第3周**|类加载 & 字节码|双亲委派模型（启动类加载器→扩展类加载器→应用类加载器）、**破坏双亲委派的3种场景**（SPI/Tomcat/热部署）、javap 反汇编、字节码文件结构|

**为什么要学 JVM？**

- 面试必问（几乎所有大厂）
- 写代码遇到 OOM 能独立排查
- 理解内存模型才能写出高性能代码

### 5.2 并发编程（2-3周）

|周次|模块|具体掌握|

|**第1周**|线程基础|创建线程的4种方式（Thread/Runnable/Callable+FutureTask/线程池）、线程 6 种状态（NEW/RUNNABLE/BLOCKED/WAITING/TIMED_WAITING/TERMINATED）、wait/notify/notifyAll（必须在 synchronized 块中调用）、sleep/yield/join 区别|

## 📌 学习技巧总结

**1. 不要死磕视频**

- 视频看懂了不等于会写。每节课后必须动手把代码敲一遍。
- 遇到看不懂的地方，**先跳过去**，过两周回来看可能就懂了。

**2. 费曼学习法**

- 学完一个知识点，试着用大白话给别人讲一遍。讲不出来就是没真懂。

**3. 一定要做笔记**

- 推荐用 **Typora**（免费版）写 Markdown 笔记，或者开个 GitHub 仓库，把笔记和代码一起 push。

**4. 遇到问题怎么搜**

- 错误信息复制到 Google 或百度
- 加 "stackoverflow" 关键词
- CSDN、博客园 的 Java 文章很多
- **ChatGPT/Copilot** 也可以用来解释代码报错

**5. 去 GitHub 看别人的项目**

- Star 高的项目，看人家的代码怎么组织的（包结构、命名规范、异常处理）
- 推荐关注：`macrozheng/mall`（万人 Star 电商项目）
