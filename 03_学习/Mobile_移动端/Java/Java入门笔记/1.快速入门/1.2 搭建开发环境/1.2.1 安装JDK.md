## 1. 为什么要安装 JDK

Java 程序必须运行在 JVM 之上，而 JDK 包含了 JVM + 编译器 + 调试器等开发工具，因此开发 Java 程序的第一步就是安装 JDK。

---

## 2. 下载 JDK

- **下载地址：** Oracle 官网，搜索 "JDK 25"
- **当前推荐版本：** Java SE Development Kit 25

### 安装包选择

| 操作系统 | 推荐安装包 | 选择依据 |
|----------|-----------|----------|
| Windows | x64 MSI Installer | 优先选择，自动配置 |
| macOS | DMG Installer | 根据 CPU 选择：Apple Silicon（ARM）或 Intel（x86） |
| Linux | Compressed Archive / DEB / RPM | 根据 CPU 架构选择 ARM 或 x86 |

---

## 3. 设置环境变量

安装完成后需要配置两个环境变量：

### JAVA_HOME

指向 JDK 的安装目录。

| 系统 | 配置方式 |
|------|----------|
| Windows | `JAVA_HOME = C:\Program Files\Java\jdk-25` |
| macOS | 在 `~/.zprofile` 中添加：`export JAVA_HOME=$(/usr/libexec/java_home -v 25)` |

### PATH

将 `JAVA_HOME/bin` 添加到 PATH，使 `java` 命令在任意目录可用。

| 系统 | 配置方式 |
|------|----------|
| Windows | `Path=%JAVA_HOME%\bin;<现有的其他路径>` |
| macOS | 在 `~/.zprofile` 中添加：`export PATH=$JAVA_HOME/bin:$PATH` |

---

## 4. 验证安装

终端输入：

```bash
java -version
```

**成功输出示例：**

```
java version "25" ...
Java(TM) SE Runtime Environment
Java HotSpot(TM) 64-Bit Server VM
```

### 常见问题排查

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 版本号显示 15、1.8 等旧版本 | 系统存在多个 JDK，默认不是 JDK 25 | 将 JDK 25 的路径提到 PATH 最前面 |
| 提示"无法识别 java 命令" | 系统找不到 `java.exe` | 检查 JAVA_HOME 和 PATH 配置是否正确 |

## 5. JDK bin 目录下的核心工具

| 工具 | 作用 | 说明 |
|------|------|------|
| `java` | 运行 Java 程序 | 本质就是 JVM，启动后执行编译好的字节码 |
| `javac` | 编译器 | 将 `.java` 源码编译为 `.class` 字节码文件 |
| `jar` | 打包工具 | 将一组 `.class` 文件打包成 `.jar` 文件便于发布 |
| `javadoc` | 文档生成器 | 从源码注释中自动提取并生成 API 文档 |
| `jdb` | 调试器 | 用于开发阶段的运行调试 |

### 编译与运行流程

```
Hello.java  ──javac──→  Hello.class  ──java──→  运行结果
 (源码)       编译        (字节码)      JVM执行
```

---

## 6. 关键总结

1. 开发 Java 必须安装 **JDK**（不是 JRE）
2. 设置 `JAVA_HOME` 指向安装目录，并将其 `bin` 目录加入 `PATH`
3. 用 `java -version` 验证安装是否成功
4. 多版本共存时，确保目标版本的路径在 PATH 最前面
5. `javac` 负责编译，`java` 负责运行，这是最基本的开发流程
