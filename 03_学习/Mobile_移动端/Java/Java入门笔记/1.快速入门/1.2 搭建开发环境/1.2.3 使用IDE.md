## 1. 什么是 IDE

**IDE**（Integrated Development Environment）= 集成开发环境

将编写代码、组织项目、编译、运行、调试集中在一个环境中，极大提高开发效率。

### IDE 提升效率的核心能力

| 能力 | 说明 |
|------|------|
| 自动提示 | 编辑器智能补全，提高编码速度 |
| 自动编译运行 | 代码修改后自动重新编译并运行 |
| 断点调试 | 方便地设置断点、单步执行、查看变量 |

## 2. 主流 Java IDE 对比

| IDE | 开发方 | 特点 | 费用 |
|-----|--------|------|------|
| Eclipse | IBM 捐赠给开源社区 | 基于插件架构，应用广泛，支持多语言 | 完全免费 |
| IntelliJ IDEA | JetBrains | 功能强大，分社区版和旗舰版 | 社区版免费，旗舰版付费 |
| NetBeans | SUN 开发 | 最早的开源 IDE，目前已不再流行 | 免费 |

## 3. Eclipse 安装

- **下载版本：** Eclipse IDE for Java Developers
- 根据操作系统（Windows / Mac / Linux）选择对应安装包

> 注意：不需要下载 Enterprise Java Developers 版本，标准 Java 开发版已完全够用。

## 4. Eclipse 基本配置

通过菜单 "Eclipse/Window" → "Preferences" 打开配置：

| 配置路径 | 设置项 | 操作 |
|----------|--------|------|
| General > Editors > Text Editors | Show line numbers | 勾选，显示行号 |
| General > Workspace | Refresh using native hooks or polling | 勾选，自动刷新文件改动 |
| General > Workspace | Text file encoding | 设为 **UTF-8** |
| General > Workspace | New text file line delimiter | 建议选 **Unix**（`\n`） |
| Java > Compiler | Compiler compliance level | 设为当前 JDK 版本 |
| Java > Compiler | Enable preview features | 勾选，启用预览功能 |
| Java > Installed JREs | 默认 JRE | 确保为当前安装的 JDK 版本 |

> 如果 Compiler compliance level 没有对应版本选项，更新 Eclipse 或在 Marketplace 搜索安装对应版本支持插件。

## 5. Eclipse IDE 界面结构

```
┌─────────────────────────────────────────────────┐
│  菜单栏 / 工具栏                     [Perspective]│
├────────┬──────────────────────┬─────────────────┤
│Package │                      │    Outline      │
│Explorer│      编辑器区域       │  (源码结构视图)  │
│(项目   │    (编写源码)         │                 │
│ 视图)  │                      │                 │
├────────┴──────────────────────┴─────────────────┤
│              Console (命令行输出)                  │
└─────────────────────────────────────────────────┘
```

| 区域 | 作用 |
|------|------|
| 编辑器（中间） | 编辑源码 |
| Package Explorer（左） | Java 项目文件结构视图 |
| Console（下方） | 程序输出、错误信息 |
| Outline（右） | 当前源码的类/方法结构 |
| Perspective（右上角） | 视图组合方案，如 Java、Debug |

## 6. 新建项目与运行

### 新建 Java 项目

1. 菜单 "File" → "New" → "Java Project"
2. 填入项目名（如 `HelloWorld`）
3. JRE 选择当前安装的 Java SE 版本
4. 暂不勾选 "Create module-info.java file"
5. 点击 "Finish"

### 新建 Java 文件

1. 展开项目，选中 `src` 目录
2. 右键 → "New" → "Class"
3. Name 填入 `Hello`，点击 "Finish"
4. 在生成的 `Hello.java` 中编写代码：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
```

### 运行

1. 选中 `Hello.java`，右键 → "Run As..." → "Java Application"
2. 在 Console 窗口查看输出结果

> 如果看不到 Console，通过 "Window" → "Show View" → "Console" 打开。

## 7. 关键总结

1. IDE 集编辑、编译、运行、调试于一体，是 Java 开发的标配工具
2. Eclipse 免费且功能完整，适合学习；IntelliJ IDEA 功能更强，业界主流
3. 配置重点：编码设为 UTF-8、Compiler level 与 JDK 版本一致
4. 在 IDE 中无需手动执行 `javac` 和 `java`，IDE 自动完成编译运行
5. 掌握 IDE 的项目结构和视图布局，有助于高效开发
