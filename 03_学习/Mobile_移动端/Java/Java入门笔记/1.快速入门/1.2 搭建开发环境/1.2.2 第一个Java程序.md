## 1. Hello World 源码

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
```

---

## 2. 代码结构解析

### 类（class）的定义

```java
public class Hello {
    ...
}
```

| 关键字/元素 | 含义 |
|------------|------|
| `public` | 访问修饰符，表示这个类是公开的 |
| `class` | 用来定义一个类 |
| `Hello` | 类名，首字母大写（习惯），大小写敏感 |
| `{}` | 花括号中间是类的定义内容 |

### main 方法（程序入口）

```java
public static void main(String[] args) {
    ...
}
```

| 组成部分 | 含义 |
|----------|------|
| `public` | 公开的 |
| `static` | 静态方法 |
| `void` | 返回类型，无返回值 |
| `main` | 方法名（固定入口） |
| `String[] args` | 参数类型为字符串数组，参数名为 args |

> **重要规则：** `public static void main(String[] args)` 是 Java 程序的固定入口，程序总是从 main 方法开始执行。

### 语句

```java
System.out.println("Hello, world!");
```

- 每行代码以 `;` 结束
- `System.out.println()` 用于打印字符串到屏幕

---

## 3. 编码规范

| 规范 | 说明 |
|------|------|
| 文件名 | 必须与 public class 名完全一致，如 `Hello.java` |
| 大小写 | 类名首字母大写，关键字必须小写 |
| 缩进 | 非必须，但推荐 4 个空格或 1 个 tab |
| 一个文件一个 public class | 一个 `.java` 文件只能定义一个 public 类 |

---

## 4. 编译与运行流程

```
Hello.java (源码)
     │  javac Hello.java（编译）
     ▼
Hello.class (字节码)
     │  java Hello（执行）
     ▼
输出: Hello, world!
```

### 具体步骤

**第一步：编译**

```bash
$ javac Hello.java
```

- 无报错则编译成功，当前目录生成 `Hello.class`

**第二步：运行**

```bash
$ java Hello
Hello, world!
```

- 注意：参数是**类名** `Hello`，不是 `Hello.class`

### 快捷方式（Java 11+）

```bash
$ java Hello.java
Hello, world!
```

- 可以直接运行单文件源码，无需先编译
- 仅适用于不依赖第三方库的单个源码文件，实际项目中很少用

---

## 5. 常见错误排查

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| `ClassNotFoundException: Hello` | 当前目录下没有 `Hello.class` | 切换到 `.class` 文件所在目录再执行 |
| 编译报错 | 源码有语法错误 | 检查拼写、分号、花括号是否匹配 |
| 文件名不匹配 | 文件名与类名不一致 | 确保文件名和 public class 名完全相同（含大小写） |

---

## 6. 关键总结

1. 一个 `.java` 文件只能定义**一个** public class，且类名与文件名必须一致
2. `public static void main(String[] args)` 是程序固定入口
3. `javac` 编译源码 → `.class` 字节码；`java` 执行字节码
4. 运行时传的是类名，不是文件名
5. Java 11+ 支持直接 `java Hello.java` 运行单文件，但实际项目中仍需先编译
