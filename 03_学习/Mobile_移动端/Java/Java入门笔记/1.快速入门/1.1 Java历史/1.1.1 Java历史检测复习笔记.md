### 5. Java 实现“一次编写，到处运行”的核心机制是？

A. 源码直接在所有平台运行  
B. Java 程序直接编译成 Windows 可执行文件  
C. 源码编译成字节码，再由不同平台的 JVM 执行  
D. Java 只能在 Oracle 系统上运行  

**我的答案：** C. 源码编译成字节码，再由不同平台的 JVM 执行  

**正确答案：** C. 源码编译成字节码，再由不同平台的 JVM 执行  

**解析：**  
Java 源代码不会直接变成某一个操作系统的机器码，而是先编译成统一的 **字节码**。  
不同操作系统安装对应的 **JVM**，由 JVM 来加载并执行字节码。

流程：

```text
源代码 .java → 编译器 javac → 字节码 .class → JVM → 机器码执行
```

A. 正确  
B. 错误  

**我的答案：** B. 错误  

**正确答案：** B. 错误  

**解析：**

```text
.java 源代码 → 编译 → .class 字节码 → JVM 解释/即时编译执行
```

### 13. 请用自己的话解释：为什么 Java 能跨平台？

**我的答案：** 不知道  

**参考答案：**  
Java 能跨平台，是因为 Java 源代码不会直接编译成某个操作系统专用的机器码，而是先编译成统一的 **字节码 `.class`**。  
不同操作系统上安装对应版本的 **JVM**，由 JVM 负责加载并执行这些字节码。

所以，只要不同平台都有 JVM，同一份 Java 字节码就可以运行。

流程：

```text
Java 源代码 .java
        ↓ 编译
Java 字节码 .class
        ↓ 不同平台的 JVM 执行
Windows / macOS / Linux 都可以运行
```

核心句：

> Java 通过“字节码 + JVM”实现跨平台。

---

### 14. 为什么学习 Java 要先学习 Java SE，而不是直接学习 Java EE 或 Android？

**我的答案：** 不知道  

**参考答案：**  
因为 **Java SE 是整个 Java 平台的基础和核心**。  
Java SE 包含语法基础、面向对象、常用类库、异常、集合、IO、多线程等基础内容。

Java EE、Android、大数据等方向都需要这些基础知识。  
如果不先掌握 Java SE，后面学习 Java EE 或 Android 会很吃力。

推荐学习路线：

```text
Java SE 基础
    ├── Java EE 方向：Spring、数据库、分布式架构
    ├── 大数据方向：Hadoop、Spark、Flink
    └── 移动开发方向：Android App 开发
```

核心句：

> Java SE 是基础，Java EE 和 Android 是建立在基础之上的应用方向。
