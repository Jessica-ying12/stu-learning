# break 和 continue 学习笔记

## 1. break 语句

**作用：** 跳出当前循环，整个循环立即结束。

```java
int sum = 0;
for (int i = 1; ; i++) {  // 没有设置结束条件
    sum = sum + i;
    if (i == 100) {
        break;  // 满足条件时跳出循环
    }
}
System.out.println(sum);  // 5050
```

### break 只跳出所在的那一层循环

```java
for (int i = 1; i <= 10; i++) {
    for (int j = 1; j <= 10; j++) {
        if (j >= i) {
            break;  // 只跳出内层 for 循环
        }
    }
    // break 跳到这里，外层循环继续执行
}
```

---

## 2. continue 语句

**作用：** 提前结束**本次**循环，直接进入**下次**循环。

```java
int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;  // 偶数跳过，不执行后面的语句
    }
    sum = sum + i;  // 只有奇数会执行到这里
}
System.out.println(sum);  // 25（1+3+5+7+9）
```

### 执行效果

| i 的值 | i % 2 == 0 | 执行情况 |
|--------|-----------|----------|
| 1 | false | 正常执行，sum += 1 |
| 2 | true | continue，跳过本次 |
| 3 | false | 正常执行，sum += 3 |
| 4 | true | continue，跳过本次 |
| ... | ... | ... |

---

## 3. break vs continue

| 对比 | break | continue |
|------|-------|----------|
| 作用 | 跳出整个循环 | 跳过本次，继续下次循环 |
| 循环是否继续 | ❌ 不再执行 | ✅ 继续下一轮 |
| 配合 | 通常配合 if 使用 | 通常配合 if 使用 |
| 嵌套循环 | 只跳出最近一层 | 只影响最近一层 |

**流程图对比：**

```
break:                          continue:
循环开始                         循环开始
  │                               │
  ├→ 执行                         ├→ 执行
  │   if 满足 → break → 跳出循环    │   if 满足 → continue → 回到循环开头
  │                               │
  └→ 循环结束                      └→ 正常执行剩余代码
```

---

## 4. 关键总结

| 要点 | 说明 |
|------|------|
| break | 跳出当前整个循环，后续循环不再执行 |
| continue | 结束本次循环，直接开始下一次 |
| 作用范围 | 都只影响最近的一层循环（嵌套时注意） |
| 使用场景 | 都通常配合 if 条件判断使用 |
| break 典型用法 | 找到目标后提前退出、防止无限循环 |
| continue 典型用法 | 跳过不需要处理的元素（如跳过偶数） |
