# 输入和输出学习笔记

## 1. 输出

### println vs print

| 方法 | 作用 |
|------|------|
| `System.out.println()` | 输出并换行（print line） |
| `System.out.print()` | 输出不换行 |

```java
System.out.print("A,");
System.out.print("B,");
System.out.print("C.");
System.out.println();    // 单独换行
System.out.println("END");
// 输出：A,B,C.
//       END
```

## 2. 格式化输出（printf）

使用 `System.out.printf()` 配合占位符 `%?` 进行格式化：

```java
double d = 3.1415926;
System.out.printf("%.2f\n", d);  // 3.14（保留2位小数）
System.out.printf("%.4f\n", d);  // 3.1416（保留4位小数）
```

### 常用占位符

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `%d` | 整数 | `printf("%d", 100)` → `100` |
| `%x` | 十六进制整数 | `printf("%x", 255)` → `ff` |
| `%f` | 浮点数 | `printf("%.2f", 3.14159)` → `3.14` |
| `%e` | 科学计数法浮点数 | `printf("%e", 12900000.0)` → `1.290000e+07` |
| `%s` | 字符串 | `printf("%s", "hello")` → `hello` |
| `%%` | 百分号本身 | `printf("%.1f%%", 21.7)` → `21.7%` |

### 格式化参数示例

```java
int n = 12345000;
System.out.printf("n=%d, hex=%08x", n, n);
// 输出：n=12345000, hex=00bc5a28
// %08x 表示十六进制，不足8位用0补齐
```

> 占位符数量必须和后面的参数数量一致。

## 3. 输入（Scanner）

### 基本用法

```java
import java.util.Scanner;  // 必须导入，放在源码开头

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Input your name: ");
        String name = scanner.nextLine();  // 读取字符串

        System.out.print("Input your age: ");
        int age = scanner.nextInt();       // 读取整数

        System.out.printf("Hi, %s, you are %d\n", name, age);
    }
}
```

### Scanner 常用方法

| 方法 | 读取类型 |
|------|----------|
| `scanner.nextLine()` | 一行字符串 |
| `scanner.nextInt()` | 整数 |
| `scanner.nextDouble()` | 浮点数 |
| `scanner.next()` | 单个单词（以空格分隔） |

### 关键点

| 要点 | 说明 |
|------|------|
| `import` | 导入 `java.util.Scanner`，放在源码最开头 |
| `System.in` | 标准输入流（对应 `System.out` 标准输出流） |
| 自动类型转换 | Scanner 自动将输入转换为对应类型 |
| 测试方式 | 必须从命令行运行，IDE 中也可在 Console 输入 |

## 4. 练习：计算成绩提高百分比

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Input last score: ");
        int last = scanner.nextInt();

        System.out.print("Input current score: ");
        int current = scanner.nextInt();

        double percent = (double) (current - last) / last * 100;
        System.out.printf("Score improved: %.2f%%\n", percent);
    }
}
```

> 注意：`(current - last) / last` 如果都是 int 会丢失小数，需强制转为 `double`。输出 `%` 符号用 `%%`。

---

## 5. 关键总结

| 要点 | 说明 |
|------|------|
| 输出三种方式 | `println`（换行）、`print`（不换行）、`printf`（格式化） |
| printf 占位符 | `%d` 整数、`%f` 浮点、`%s` 字符串、`%x` 十六进制 |
| `%%` | 输出百分号本身 |
| 输入用 Scanner | 创建对象后调用 `nextLine()` / `nextInt()` 等方法 |
| import 语句 | 使用非 `java.lang` 包的类时必须导入 |
