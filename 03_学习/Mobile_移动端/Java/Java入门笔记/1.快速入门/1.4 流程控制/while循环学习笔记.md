# while 循环学习笔记

## 1. 基本语法

```java
while (条件表达式) {
    循环语句
}
// 条件不满足时，跳出循环继续执行后续代码
```

**执行流程：**

```
判断条件 → true → 执行循环体 → 回到判断条件
    │
    └→ false → 跳出循环
```

> while 是**先判断后执行**，有可能一次循环都不做。

---

## 2. 典型示例：累加 1 到 100

```java
int sum = 0;
int n = 1;
while (n <= 100) {
    sum = sum + n;
    n++;
}
System.out.println(sum);  // 5050
```

**执行过程：**
- n=1 时，sum=1
- n=2 时，sum=3
- ...
- n=100 时，sum=5050
- n=101 时，条件 `101 <= 100` 为 false，退出循环

---

## 3. 边界条件陷阱

### 陷阱一：自增位置错误

```java
int sum = 0;
int n = 0;
while (n <= 100) {
    n++;           // 先自增，n 从 1 开始累加
    sum = sum + n; // 当 n=101 时仍会执行
}
// sum = 5151（多加了 101）
```

> 自增和累加的顺序不同，结果就不同。要仔细检查循环体内的逻辑顺序。

### 陷阱二：死循环

```java
while (true) {
    // 永远不会退出，CPU 占用 100%
}
```

### 陷阱三：溢出导致意外退出

```java
int n = 1;
int sum = 0;
while (n > 0) {  // 看似死循环
    sum = sum + n;
    n++;
}
// n 达到 int 最大值后溢出变为负数，意外退出循环
```

---

## 4. while 循环要点

| 要点 | 说明 |
|------|------|
| 先判断后执行 | 条件一开始就为 false 时，循环体一次不执行 |
| 初始化变量 | 循环前要正确初始化计数器和累加器 |
| 条件终止 | 确保循环条件最终会变为 false |
| 避免死循环 | 循环体内必须有改变条件的语句 |
| 边界值 | 仔细考虑第一次和最后一次的值是否正确 |

---

## 5. 练习：计算 m 到 n 的和

```java
int sum = 0;
int m = 20;
int n = 100;
while (m <= n) {
    sum = sum + m;
    m++;
}
System.out.println(sum);  // 4860
```

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| 语法 | `while (条件) { 循环体 }` |
| 执行特点 | 先判断，后执行；可能一次不执行 |
| 死循环 | 条件永远为 true 导致，要避免 |
| 边界条件 | 注意 `<` 和 `<=` 的区别，检查首尾值 |
| 自增位置 | 放在累加前还是后，结果不同 |
