# 遍历数组学习笔记

## 1. 两种遍历方式

### 方式一：for 循环（通过索引）

```java
int[] ns = { 1, 4, 9, 16, 25 };
for (int i = 0; i < ns.length; i++) {
    System.out.println(ns[i]);
}
```

### 方式二：for each 循环（直接获取元素）

```java
int[] ns = { 1, 4, 9, 16, 25 };
for (int n : ns) {
    System.out.println(n);
}
```

### 选择依据

| 需求 | 选择 |
|------|------|
| 需要索引（如倒序、跳步、修改元素） | for 循环 |
| 只需要元素值 | for each（更简洁） |

---

## 2. 打印数组内容

### 直接打印数组变量

```java
int[] ns = { 1, 1, 2, 3, 5, 8 };
System.out.println(ns);  // [I@7852e922（引用地址，没有意义）
```

### 使用 Arrays.toString()

```java
import java.util.Arrays;

int[] ns = { 1, 1, 2, 3, 5, 8 };
System.out.println(Arrays.toString(ns));  // [1, 1, 2, 3, 5, 8]
```

> 需要 `import java.util.Arrays`，这是打印数组内容最简便的方式。

---

## 3. 练习：倒序遍历

```java
int[] ns = { 1, 4, 9, 16, 25 };
for (int i = ns.length - 1; i >= 0; i--) {
    System.out.println(ns[i]);
}
// 输出：25, 16, 9, 4, 1
```

---

## 4. 关键总结

| 要点 | 说明 |
|------|------|
| for 循环遍历 | `for (int i=0; i<ns.length; i++)`，能访问索引 |
| for each 遍历 | `for (int n : ns)`，直接获取元素值，更简洁 |
| 打印数组 | 用 `Arrays.toString(ns)`，不要直接 `println(ns)` |
| 索引范围 | 0 到 `ns.length - 1` |
