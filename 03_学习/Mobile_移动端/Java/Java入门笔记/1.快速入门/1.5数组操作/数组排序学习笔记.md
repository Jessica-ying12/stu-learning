# 数组排序学习笔记

## 1. 冒泡排序算法

每一轮将最大的数"冒泡"到末尾，下一轮排除最后一个元素：

```java
int[] ns = { 28, 12, 89, 73, 65, 18, 96, 50, 8, 36 };
for (int i = 0; i < ns.length - 1; i++) {
    for (int j = 0; j < ns.length - i - 1; j++) {
        if (ns[j] > ns[j + 1]) {
            // 交换相邻元素
            int tmp = ns[j];
            ns[j] = ns[j + 1];
            ns[j + 1] = tmp;
        }
    }
}
```

### 冒泡排序特点

| 特点 | 说明 |
|------|------|
| 外层循环 | 控制轮数，共 `length - 1` 轮 |
| 内层循环 | 每轮比较相邻元素，范围逐轮缩小 |
| 每轮结果 | 最大值被交换到当前末尾 |

## 2. 交换两个变量

```java
// ❌ 错误写法
x = y;  // x 变成 y 的值
y = x;  // y 还是 y 的值（原 x 的值丢失了）

// ✅ 正确写法：借助临时变量
int tmp = x;
x = y;
y = tmp;
```

## 3. Arrays.sort() 标准库排序

```java
import java.util.Arrays;

int[] ns = { 28, 12, 89, 73, 65, 18, 96, 50, 8, 36 };
Arrays.sort(ns);
System.out.println(Arrays.toString(ns));
// [8, 12, 18, 28, 36, 50, 65, 73, 89, 96]
```

> 实际开发中直接用 `Arrays.sort()`，无需手写排序算法。

---

## 4. 排序修改的是数组本身

### 基本类型数组

排序直接改变数组元素的位置：

```
排序前：ns → [9, 3, 6, 5]
排序后：ns → [3, 5, 6, 9]  （同一个数组，内容被修改）
```

### 引用类型数组（如 String[]）

排序改变的是引用的指向，字符串对象本身不变：

```
排序前：ns[0]→"banana", ns[1]→"apple", ns[2]→"pear"
排序后：ns[0]→"apple",  ns[1]→"banana", ns[2]→"pear"
（三个字符串对象没变，只是数组元素的指向重新排列了）
```

## 5. 练习：降序排序

```java
int[] ns = { 28, 12, 89, 73, 65, 18, 96, 50, 8, 36 };
// 方法：冒泡排序，将比较条件改为 <
for (int i = 0; i < ns.length - 1; i++) {
    for (int j = 0; j < ns.length - i - 1; j++) {
        if (ns[j] < ns[j + 1]) {  // 改为 < 即可降序
            int tmp = ns[j];
            ns[j] = ns[j + 1];
            ns[j + 1] = tmp;
        }
    }
}
System.out.println(Arrays.toString(ns));
// [96, 89, 73, 65, 50, 36, 28, 18, 12, 8]
```

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| 冒泡排序 | 两层 for 循环，每轮将最大值冒泡到末尾 |
| 交换变量 | 必须借助临时变量 `tmp` |
| Arrays.sort() | 标准库方法，默认升序，实际开发首选 |
| 排序是原地修改 | 直接修改数组本身，不是返回新数组 |
| 升序 → 降序 | 把比较条件 `>` 改为 `<` |
