# 命令行参数学习笔记

## 1. 什么是命令行参数

`main` 方法的参数 `String[] args` 就是命令行参数，由 JVM 接收用户输入并传递给程序。

```java
public class Main {
    public static void main(String[] args) {
        for (String arg : args) {
            System.out.println(arg);
        }
    }
}
```

运行时传入参数：

```bash
$ javac Main.java
$ java Main hello world
hello
world
```

---

## 2. 实际应用示例

根据不同参数执行不同逻辑：

```java
public class Main {
    public static void main(String[] args) {
        for (String arg : args) {
            if ("-version".equals(arg)) {
                System.out.println("v 1.0");
                break;
            }
        }
    }
}
```

```bash
$ java Main -version
v 1.0
```

> 注意用 `"-version".equals(arg)` 而不是 `arg.equals("-version")`，避免 args 中某个元素为 null 时的 NPE。

---

## 3. 关键总结

| 要点 | 说明 |
|------|------|
| 类型 | `String[]` 数组 |
| 来源 | JVM 接收用户在命令行输入的参数 |
| 传递方式 | `java 类名 参数1 参数2 ...`，空格分隔 |
| 解析逻辑 | 需要程序自己实现（遍历、判断） |
| 无参数时 | args 是长度为 0 的空数组，不是 null |
