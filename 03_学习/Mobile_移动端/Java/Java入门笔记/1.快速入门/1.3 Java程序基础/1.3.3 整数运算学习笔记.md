## 1. 四则运算

```java
int i = (100 + 200) * (99 - 88); // 3300
int n = 7 * (5 + (i - 9));       // 23072
```

- 遵循数学四则运算规则，支持任意嵌套小括号
- 整数运算**永远是精确的**

### 除法与取余

```java
int x = 12345 / 67;   // 184（只保留整数部分）
int y = 12345 % 67;   // 17（取余数）
```

> ⚠️ 除数为 0 时**编译不报错**，但运行时会抛出 `ArithmeticException`。

## 2. 溢出

整数有范围限制，超出范围会溢出，**不报错但结果错误**。

```java
int x = 2147483640;
int y = 15;
int sum = x + y;  // -2147483641（溢出！）
```

**原理（二进制加法）：**

```
  0111 1111 1111 1111 1111 1111 1111 1000   (2147483640)
+ 0000 0000 0000 0000 0000 0000 0000 1111   (15)
= 1000 0000 0000 0000 0000 0000 0000 0111   (最高位变1，成为负数)
```

**解决方法：** 换用更大范围的类型

```java
long x = 2147483640L;
long y = 15;
long sum = x + y;  // 2147483655（正确）
```

## 3. 简写运算符与自增/自减

### 简写运算符

```java
n += 100;  // 等价于 n = n + 100
n -= 100;  // 等价于 n = n - 100
n *= 2;    // 等价于 n = n * 2
n /= 5;    // 等价于 n = n / 5
```

### 自增 / 自减

```java
n++;  // n = n + 1
n--;  // n = n - 1
```

| 写法 | 含义 |
|------|------|
| `++n` | 先加 1，再引用 n |
| `n++` | 先引用 n，再加 1 |

> ⚠️ 不建议将 `++` / `--` 混入复杂表达式，容易出错。

## 4. 移位运算

### 左移 `<<`（相当于 ×2）

```java
int n = 7;        // 00000000 00000000 00000000 00000111 = 7
int a = n << 1;   // 00000000 00000000 00000000 00001110 = 14
int b = n << 2;   // 00000000 00000000 00000000 00011100 = 28
```

### 右移 `>>`（相当于 ÷2，符号位不变）

```java
int n = 7;
int a = n >> 1;   // 3
int b = n >> 2;   // 1

// 负数右移，最高位保持 1
int m = -536870912;
int c = m >> 1;   // -268435456（仍是负数）
```

### 无符号右移 `>>>`（高位补 0）

```java
int n = -536870912;
int a = n >>> 1;  // 1879048192（变正数，因为最高位补0）
```

| 运算符 | 特点 |
|--------|------|
| `<<` | 左移，低位补 0 |
| `>>` | 右移，符号位不变（算术右移） |
| `>>>` | 右移，高位补 0（逻辑右移） |

> byte 和 short 移位时会先自动转为 int。

## 5. 位运算

| 运算 | 符号 | 规则 | 示例 |
|------|------|------|------|
| 与 | `&` | 两个都为 1 才为 1 | `1 & 1 = 1`，`1 & 0 = 0` |
| 或 | `\|` | 任意一个为 1 就为 1 | `0 \| 1 = 1`，`0 \| 0 = 0` |
| 非 | `~` | 0 和 1 互换 | `~0 = 1`，`~1 = 0` |
| 异或 | `^` | 不同为 1，相同为 0 | `1 ^ 0 = 1`，`1 ^ 1 = 0` |

**实际应用示例：** IP 地址与子网掩码

```java
int ip   = 167776589;  // 10.0.17.77
int mask = 167776512;  // 10.0.17.0
int net  = ip & mask;  // 判断 IP 是否在网段内
```

## 6. 运算优先级（从高到低）

| 优先级 | 运算符 |
|--------|--------|
| 最高 | `()` |
| | `!` `~` `++` `--` |
| | `*` `/` `%` |
| | `+` `-` |
| | `<<` `>>` `>>>` |
| | `&` |
| | `^` |
| | `\|` |
| 最低 | `+=` `-=` `*=` `/=` |

> 记不住就加括号，保证优先级正确。

## 7. 类型自动提升与强制转型

### 自动提升

小类型与大类型运算时，小类型**自动提升**为大类型：

```java
short s = 1234;
int i = 123456;
int x = s + i;      // ✅ s 自动转为 int
short y = s + i;    // ❌ 编译错误，结果是 int 不能赋给 short
```

### 强制转型

用 `(类型)` 将大范围转为小范围：

```java
int i = 12345;
short s = (short) i;  // 12345（范围内，正确）

int i2 = 1234567;
short s2 = (short) i2;  // -10617（超出范围，截断高位，结果错误！）
```

> ⚠️ 强制转型会丢弃高位字节，超出范围时结果不可预测。

## 8. 练习

计算前 N 个自然数的和：`sum = (1 + N) × N / 2`

```java
int n = 100;
int sum = (1 + n) * n / 2;  // 5050
```

## 9. 关键总结

| 要点 | 说明 |
|------|------|
| 精确性 | 整数运算永远精确（包括除法，只取整数部分） |
| 溢出 | 超出范围不报错但结果错误，用 long 解决 |
| 移位本质 | 左移 = ×2，右移 = ÷2 |
| 类型提升 | 小类型自动提升为大类型 |
| 强制转型 | 可能截断高位导致错误结果 |
| 类型选择 | 通常用 int 或 long，无需为省内存用 byte/short |
