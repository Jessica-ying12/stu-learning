## 1. 什么是数组

数组是**同一数据类型**的集合，用于存储一组类型相同的变量。

```java
// 不用数组：定义 5 个变量
int n1 = 68, n2 = 79, n3 = 91, n4 = 85, n5 = 62;

// 用数组：一个变量搞定
int[] ns = new int[5];
ns[0] = 68;
ns[1] = 79;
ns[2] = 91;
ns[3] = 85;
ns[4] = 62;
```

---

## 2. 数组的定义方式

```java
// 方式一：指定大小，逐个赋值
int[] ns = new int[5];

// 方式二：直接指定元素（编译器推算大小）
int[] ns = new int[] { 68, 79, 91, 85, 62 };

// 方式三：简写形式
int[] ns = { 68, 79, 91, 85, 62 };
```

---

## 3. 数组的特点

| 特点 | 说明 |
|------|------|
| 默认值初始化 | 整型为 `0`，浮点型为 `0.0`，布尔型为 `false`，引用类型为 `null` |
| 大小不可变 | 创建后长度固定 |
| 索引从 0 开始 | 5 个元素的索引范围：0~4 |
| 引用类型 | 数组变量存储的是"指向"数组对象的引用 |

---

## 4. 基本操作

### 访问元素

```java
int[] ns = { 68, 79, 91, 85, 62 };
System.out.println(ns[0]);  // 68（第一个元素）
System.out.println(ns[4]);  // 62（最后一个元素）
```

### 修改元素

```java
ns[1] = 100;  // 将第二个元素改为 100
```

### 获取数组长度

```java
System.out.println(ns.length);  // 5
```

### 索引越界

```java
int[] ns = new int[5];
System.out.println(ns[5]);  // ❌ 运行时报错：ArrayIndexOutOfBoundsException
```

> 编译不报错，运行时才报错。

---

## 5. 数组是引用类型

数组变量指向数组对象，重新赋值只是改变指向：

```java
int[] ns;
ns = new int[] { 68, 79, 91, 85, 62 };  // 指向 5 元素数组
System.out.println(ns.length);  // 5

ns = new int[] { 1, 2, 3 };  // 指向新的 3 元素数组
System.out.println(ns.length);  // 3
```

**内存示意：**

```
第一次赋值：ns → [68, 79, 91, 85, 62]
第二次赋值：ns → [1, 2, 3]    原数组 [68, 79, 91, 85, 62] 仍在内存中
```

> 数组大小并没有变，是变量 ns 指向了一个新数组。

## 6. 字符串数组（引用类型数组）

```java
String[] names = { "ABC", "XYZ", "zoo" };
```

**内存结构：** 数组每个元素存储的是引用（指向字符串对象的地址）。

```
names[0] → "ABC"
names[1] → "XYZ"
names[2] → "zoo"
```

### 修改元素的本质

```java
names[1] = "cat";
// names[1] 的引用从 "XYZ" 改为指向 "cat"
// "XYZ" 字符串本身没有改变，只是不再被 names[1] 引用
```

### 经典理解题

```java
String[] names = { "ABC", "XYZ", "zoo" };
String s = names[1];    // s 指向 "XYZ"
names[1] = "cat";       // names[1] 改为指向 "cat"
System.out.println(s);  // "XYZ"（s 仍指向原来的 "XYZ"）
```

> `s` 和 `names[1]` 是两个独立的引用变量，修改一个的指向不影响另一个。

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 定义语法 | `类型[] 变量名 = new 类型[大小]` 或 `{ 元素列表 }` |
| 大小固定 | 创建后不可改变长度 |
| 索引范围 | 0 到 `length - 1`，越界报 ArrayIndexOutOfBoundsException |
| 引用类型 | 数组变量存的是引用，赋值改变的是指向 |
| 值类型元素 | 直接存储值（如 int），修改互不影响 |
| 引用类型元素 | 存储引用（如 String），修改元素是改变指向，原对象不变 |
| `.length` | 获取数组长度 |
