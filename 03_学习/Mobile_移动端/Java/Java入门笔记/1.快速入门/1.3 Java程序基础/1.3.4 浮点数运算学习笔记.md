## 1. 浮点数的特点

- 浮点数只能进行**加减乘除**，不能做位运算和移位运算
- 浮点数表示范围大，但**常常无法精确表示**
- 遵循 **IEEE-754** 标准

### 精度问题

| 值 | 能否精确表示 | 原因 |
|----|-------------|------|
| `0.5` | ✅ 能 | 二进制可精确表示 |
| `0.1` | ❌ 不能 | 转二进制是无限循环小数 |

```java
double x = 1.0 / 10;      // 0.1
double y = 1 - 9.0 / 10;  // 0.09999999999999998（不是精确的 0.1）
```

---

## 2. 浮点数比较

由于精度误差，**不能直接用 `==` 比较两个浮点数**。

### 正确做法：判断差的绝对值

```java
double r = Math.abs(x - y);
if (r < 0.00001) {
    // 可以认为相等
} else {
    // 不相等
}
```

---

## 3. 类型提升

整型与浮点型运算时，整型**自动提升**为浮点型：

```java
int n = 5;
double d = 1.2 + 24.0 / n;  // 6.0（n 自动提升为 double）
```

### ⚠️ 陷阱：两个整数之间不会自动提升

```java
double d = 1.2 + 24 / 5;  // 5.2，不是 6.0！
// 24 / 5 按整数运算 = 4，然后 1.2 + 4 = 5.2
```

**修复方法：** 将其中一个写成浮点数

```java
double d = 1.2 + 24.0 / 5;  // 6.0（正确）
```

---

## 4. 浮点数除以 0（特殊值）

与整数不同，浮点数除以 0 **不报错**，而是返回特殊值：

| 表达式 | 结果 | 含义 |
|--------|------|------|
| `0.0 / 0` | `NaN` | Not a Number |
| `1.0 / 0` | `Infinity` | 正无穷大 |
| `-1.0 / 0` | `-Infinity` | 负无穷大 |

---

## 5. 强制转型（浮点 → 整数）

```java
int n1 = (int) 12.3;      // 12（直接丢弃小数部分）
int n2 = (int) 12.7;      // 12（不是四舍五入，是截断）
int n3 = (int) -12.7;     // -12
int n4 = (int) 1.2e20;    // 2147483647（超出范围，返回 int 最大值）
```

### 四舍五入技巧

```java
double d = 2.6;
int n = (int) (d + 0.5);  // 3（加 0.5 后截断 = 四舍五入）
```

## 6. 练习：一元二次方程求根

公式：`x = (-b ± √(b²-4ac)) / 2a`

```java
double a = 1.0;
double b = 3.0;
double c = -4.0;

double discriminant = b * b - 4 * a * c;
double r1 = (-b + Math.sqrt(discriminant)) / (2 * a);  // 1.0
double r2 = (-b - Math.sqrt(discriminant)) / (2 * a);  // -4.0
```

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 精度 | 浮点数运算可能有误差，不能直接用 `==` 比较 |
| 比较方法 | 判断差的绝对值是否小于一个极小值（如 0.00001） |
| 类型提升 | 整型与浮点型混合运算时，整型自动提升为浮点型 |
| 整数子表达式 | 两个整数运算不会自动提升，`24/5=4` 不是 `4.8` |
| 强制转型 | 浮点转整数直接截断小数，超范围返回最大值 |
| 四舍五入 | `(int)(d + 0.5)` |
| 除以 0 | 不报错，返回 NaN / Infinity / -Infinity |
