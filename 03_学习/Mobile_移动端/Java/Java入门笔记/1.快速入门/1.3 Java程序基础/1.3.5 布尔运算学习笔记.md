## 1. 布尔类型基础

`boolean` 类型只有两个值：`true` 和 `false`。

---

## 2. 布尔运算分类

### 比较运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `>` | 大于 | `5 > 3` → `true` |
| `>=` | 大于等于 | `age >= 18` |
| `<` | 小于 | `age < 6` |
| `<=` | 小于等于 | `score <= 60` |
| `==` | 等于 | `age == 0` → `false` |
| `!=` | 不等于 | `age != 0` → `true` |

### 逻辑运算符

| 运算符 | 含义 | 规则 |
|--------|------|------|
| `&&` | 与（AND） | 两个都为 true 才为 true |
| `\|\|` | 或（OR） | 任意一个为 true 就为 true |
| `!` | 非（NOT） | 取反，true 变 false |

### 综合示例

```java
int age = 12;
boolean isZero = age == 0;           // false
boolean isNonZero = !isZero;         // true
boolean isAdult = age >= 18;         // false
boolean isTeenager = age > 6 && age < 18;  // true
```

---

## 3. 运算优先级（从高到低）

| 优先级 | 运算符 |
|--------|--------|
| 最高 | `!` |
| | `>`  `>=`  `<`  `<=` |
| | `==`  `!=` |
| | `&&` |
| 最低 | `\|\|` |

---

## 4. 短路运算

布尔运算的重要特点：**如果能提前确定结果，后续计算不再执行。**

### `&&` 短路

```java
boolean b = 5 < 3;                    // false
boolean result = b && (5 / 0 > 0);   // false，不会报除以0的错
```

- `false && 任何表达式` → 直接返回 `false`，右边不执行

### `||` 短路

```java
boolean result = true || (5 / 0 > 0);  // true，不会报错
```

- `true || 任何表达式` → 直接返回 `true`，右边不执行

### 短路规则速记

| 表达式 | 结果 | 右边是否执行 |
|--------|------|-------------|
| `false && x` | `false` | ❌ 不执行 |
| `true && x` | 取决于 x | ✅ 执行 |
| `true \|\| x` | `true` | ❌ 不执行 |
| `false \|\| x` | 取决于 x | ✅ 执行 |

---

## 5. 三元运算符

语法：`条件 ? 表达式1 : 表达式2`

```java
int n = -100;
int x = n >= 0 ? n : -n;  // 100（求绝对值）
```

| 特点 | 说明 |
|------|------|
| 条件为 true | 返回表达式1，表达式2 不计算 |
| 条件为 false | 返回表达式2，表达式1 不计算 |
| 类型一致 | 表达式1 和表达式2 的类型必须相同 |
| 短路特性 | 只计算其中一个表达式 |

---

## 6. 练习：判断小学生

判断是否为小学生（6~12 岁）：

```java
int age = 7;
boolean isPrimaryStudent = age >= 6 && age <= 12;  // true
System.out.println(isPrimaryStudent ? "Yes" : "No");
```

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| boolean 值 | 只有 `true` 和 `false` |
| 短路运算 | `&&` 和 `\|\|` 会在确定结果后跳过后续计算 |
| 实际意义 | 短路可以避免不必要的计算和潜在的运行时错误 |
| 三元运算 | `b ? x : y`，x 和 y 类型必须一致，也是短路的 |
| 优先级 | `!` > 比较 > `&&` > `\|\|`，不确定就加括号 |
