## 1. 完整程序结构一览

```java
/**
 * 可以用来自动创建文档的注释
 */
public class Hello {
    public static void main(String[] args) {
        // 向屏幕输出文本:
        System.out.println("Hello, world!");
        /* 多行注释开始
        注释内容
        注释结束 */
    }
} // class定义结束
```

**结构层次：**

```
class（类）
 └── method（方法）
      └── statement（语句）
```

Java 是面向对象语言，程序的基本单位是 **class**。

---

## 2. 类（class）

```java
public class Hello {
    // ...
}
```

| 要素       | 说明             |
| -------- | -------------- |
| `public` | 访问修饰符，表示该类是公开的 |
| `class`  | 关键字，用于定义类      |
| `Hello`  | 类名             |
| `{}`     | 类体，包含方法和属性     |

> 不写 `public` 也能编译，但该类将无法从命令行执行。

### 类名命名规则

| 规则 | 说明 |
|------|------|
| 必须以英文字母开头 | 后接字母、数字、下划线 |
| 首字母大写 | 大驼峰命名法（PascalCase） |

| ✅ 好的命名 | ❌ 不好的命名 |
|------------|-------------|
| `Hello` | `hello`（首字母未大写） |
| `NoteBook` | `Good123`（无意义数字） |
| `VRPlayer` | `Note_Book`（不应用下划线） |

---

## 3. 方法（method）

```java
public static void main(String[] args) {
    // 方法代码...
}
```

| 要素 | 说明 |
|------|------|
| `public` | 公开的 |
| `static` | 静态方法 |
| `void` | 返回类型，无返回值 |
| `main` | 方法名 |
| `String[] args` | 参数 |

> **Java 入口规定：** 方法必须是 `public static void main(String[] args)`，缺一不可。

### 方法名命名规则

| 规则 | 说明 |
|------|------|
| 必须以英文字母开头 | 后接字母、数字、下划线 |
| 首字母小写 | 小驼峰命名法（camelCase） |

| ✅ 好的命名 | ❌ 不好的命名 |
|------------|-------------|
| `main` | `Main`（首字母不应大写） |
| `goodMorning` | `good123`（无意义数字） |
| `playVR` | `good_morning`（不应用下划线） |

---

## 4. 语句（statement）

```java
System.out.println("Hello, world!"); // 语句
```

- 方法内部的代码按**顺序**依次执行
- 每条语句必须以**分号 `;`** 结束

---

## 5. 三种注释

| 类型 | 语法 | 用途 |
|------|------|------|
| 单行注释 | `// 注释内容` | 行末简短说明 |
| 多行注释 | `/* 注释内容 */` | 大段说明 |
| 文档注释 | `/** 注释内容 */` | 写在类/方法定义处，用于自动生成文档 |

```java
// 单行注释

/* 多行注释
   可以跨行 */

/**
 * 文档注释
 * @author liaoxuefeng
 */
```

- 注释不是程序的一部分，编译器会自动忽略
- 文档注释可被 `javadoc` 工具提取生成 API 文档

---

## 6. 编码格式规范

- Java 对格式无强制要求，多余空格和回车不影响正确性
- 但应遵守 Java 社区约定的编码格式
- Eclipse 快捷键格式化代码：
  - Windows: `Ctrl + Shift + F`
  - macOS: `⌘ + ⇧ + F`
- 详细格式规则可在 Eclipse 的 Java → Code Style 中查看

---

## 7. 关键总结

| 概念 | 要点 |
|------|------|
| 程序基本单位 | class（类） |
| 程序入口 | `public static void main(String[] args)` |
| 类名命名 | 大驼峰：`NoteBook`、`VRPlayer` |
| 方法名命名 | 小驼峰：`goodMorning`、`playVR` |
| 语句结尾 | 必须加分号 `;` |
| 注释 | 单行 `//`、多行 `/* */`、文档 `/** */` |
