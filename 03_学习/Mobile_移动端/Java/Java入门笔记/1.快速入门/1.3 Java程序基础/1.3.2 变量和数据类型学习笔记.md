## 1. 变量

### 什么是变量

变量就是代数中的概念，可以存储一个值，并且可以重新赋值。

### 定义与使用规则

```java
int x = 100;    // 定义变量：类型 变量名 = 初始值;
x = 200;        // 重新赋值：不能再写类型
int y = x;      // 将变量赋值给另一个变量
```

- 变量必须**先定义后使用**
- 定义时可给初始值，不写则默认为 `0`
- 重新赋值时**不能重复声明类型**
- `=` 是赋值语句，不是数学等号（所以 `x = x + 100` 合法）

### 内存模型理解

```
int n = 100;      →  n 指向存储单元，值为 100
n = 200;          →  原值被覆盖，n 变为 200
int x = n;        →  新分配存储单元给 x，复制 n 的值 200
x = x + 100;     →  x 变为 300，n 仍为 200（互不影响）
```

> 基本类型赋值是**值拷贝**，修改一个不影响另一个。

## 2. 基本数据类型

### 总览

| 类型        | 字节数 | 范围 / 说明                                    |
| --------- | --- | ------------------------------------------ |
| `byte`    | 1   | -128 ~ 127                                 |
| `short`   | 2   | -32768 ~ 32767                             |
| `int`     | 4   | -2147483648 ~ 2147483647（约 ±21 亿）          |
| `long`    | 8   | -9223372036854775808 ~ 9223372036854775807 |
| `float`   | 4   | 最大 3.4×10³⁸                                |
| `double`  | 8   | 最大 1.79×10³⁰⁸                              |
| `char`    | 2   | 一个 Unicode 字符                              |
| `boolean` | -   | `true` 或 `false`（JVM 通常用 4 字节存储）           |

### 整型（byte / short / int / long）

```java
int i = 2147483647;
int i2 = 2_000_000_000;    // 下划线分隔，便于阅读
int i3 = 0xff0000;          // 十六进制
int i4 = 0b1000000000;      // 二进制

long n = 9000000000000000000L;  // long 必须加 L 后缀
```

| 要点                | 说明                      |
| ----------------- | ----------------------- |
| Java 整型都是**带符号**的 | 最高位为符号位                 |
| 不同进制表示同一个数        | `15` = `0xf` = `0b1111` |
| long 字面量加 `L`     | 不加默认为 int               |
| 不能将 long 赋给 int   | `int i = 900L;` ❌       |

### 浮点型（float / double）

```java
float f1 = 3.14f;          // float 必须加 f 后缀
float f2 = 3.14e38f;       // 科学计数法

double d = 1.79e308;
double d2 = 4.9e-324;
```

| 要点 | 说明 |
|------|------|
| 不带 `f` 后缀默认是 double | `float f = 1.0;` ❌ |
| 浮点数有精度问题 | 不能精确表示所有小数 |

### 布尔类型（boolean）

```java
boolean b1 = true;
boolean b2 = false;
boolean isAdult = age >= 18;  // 关系运算的结果
```

### 字符类型（char）

```java
char a = 'A';     // ASCII 字符
char zh = '中';   // Unicode 字符
```

- 使用**单引号** `'`，且只能有一个字符
- 与**双引号** `"` 的字符串（String）区分

---

## 3. 引用类型

```java
String s = "hello";
```

- 除基本类型外都是引用类型
- 引用变量存储的是"地址"，指向对象在内存中的位置
- 类似 C 语言的指针概念

---

## 4. 常量（final）

```java
final double PI = 3.14;
PI = 300;  // ❌ 编译错误，常量不可重新赋值
```

| 规则           | 说明                |
| ------------ | ----------------- |
| 用 `final` 修饰 | 初始化后不可再赋值         |
| 命名全部大写       | 如 `PI`、`MAX_SIZE` |
| 避免魔术数字       | 用有意义的常量名代替硬编码数字   |

---

## 5. var 关键字（Java 10+）

```java
var sb = new StringBuilder();
// 等价于
StringBuilder sb = new StringBuilder();
```

- 编译器自动推断变量类型
- 仅仅是省略了类型书写，本质不变
- 适用于类型名过长的场景

---

## 6. 变量作用域

```java
{
    int i = 0;          // i 从这里开始有效
    {
        int x = 1;      // x 从这里开始有效
    }                   // x 到此失效
}                       // i 到此失效
```

**原则：**
- 变量作用域从定义处开始，到所在 `{}` 结束
- 超出作用域引用变量，编译器报错
- 遵循**作用域最小化原则**：在尽可能小的范围内定义变量
- 不要重复使用变量名（即使作用域不同也应避免混淆）

---

## 7. 关键总结

| 概念 | 要点 |
|------|------|
| 两种变量类型 | 基本类型（8 种）和引用类型 |
| 基本类型分类 | 整型、浮点型、布尔型、字符型 |
| 赋值 | `=` 是赋值，不是等号；变量可反复赋值 |
| 常量 | `final` 修饰，初始化后不可变，命名全大写 |
| var | 类型推断语法糖，编译器自动推断类型 |
| 作用域 | `{}` 决定变量生命周期，越小越好 |
