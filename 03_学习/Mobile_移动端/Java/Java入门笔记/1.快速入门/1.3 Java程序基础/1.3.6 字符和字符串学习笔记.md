## 1. 字符类型（char）

`char` 是基本数据类型，占 2 字节，保存一个 Unicode 字符。

```java
char c1 = 'A';    // 英文字符
char c2 = '中';   // 中文字符（同样占 2 字节）
```

### char 与 Unicode 编码

```java
int n1 = 'A';     // 65（char 赋给 int 得到 Unicode 编码）
int n2 = '中';    // 20013

char c3 = 'A';  // 'A'（十六进制 0041 = 十进制 65）
char c4 = '中';  // '中'（十六进制 4e2d = 十进制 20013）
```

---

## 2. 字符串类型（String）

`String` 是**引用类型**，用双引号 `"..."` 表示，可存储 0 到任意个字符。

```java
String s = "";           // 空字符串，0 个字符
String s1 = "A";         // 1 个字符
String s2 = "ABC";       // 3 个字符
String s3 = "中文 ABC";  // 6 个字符（含一个空格）
```

### char 与 String 的区别

| 对比 | char | String |
|------|------|--------|
| 类型 | 基本类型 | 引用类型 |
| 引号 | 单引号 `'A'` | 双引号 `"A"` |
| 容量 | 只能一个字符 | 0 到任意个字符 |
| 变量含义 | "持有"一个值 | "指向"一个对象 |

---

## 3. 转义字符

| 转义符 | 含义 |
|--------|------|
| `\"` | 双引号字符 `"` |
| `\'` | 单引号字符 `'` |
| `\\` | 反斜杠字符 `\` |
| `\n` | 换行符 |
| `\r` | 回车符 |
| `\t` | Tab |
| `\u####` | Unicode 编码字符 |

```java
String s = "abc\"xyz";          // a, b, c, ", x, y, z（7个字符）
String s2 = "abc\\xyz";         // a, b, c, \, x, y, z（7个字符）
String s3 = "ABC\n中文"; // A, B, C, 换行, 中, 文（6个字符）
```

---

## 4. 字符串连接

用 `+` 连接字符串，其他类型会自动转为字符串：

```java
String s = "Hello" + " " + "world" + "!";  // "Hello world!"

int age = 25;
String info = "age is " + age;  // "age is 25"
```

---

## 5. 多行字符串（Java 13+）

使用 `"""..."""`（Text Blocks）：

```java
String s = """
           SELECT * FROM
             users
           WHERE id > 100
           ORDER BY name DESC
           """;
```

### 规则

| 规则 | 说明 |
|------|------|
| 共同前导空格 | 自动去掉所有行共有的行首空格 |
| 基准 | 以最短行首空格为基准 |
| 末尾换行 | `"""` 单独一行则末尾有 `\n`，紧跟内容则无 |

## 6. 字符串不可变特性

字符串内容一旦创建就**不可修改**，变的是变量的"指向"。

```java
String s = "hello";
s = "world";  // s 指向了新对象 "world"，"hello" 仍存在于内存中
```

**内存示意：**

```
执行 s = "hello" 后:     s → "hello"
执行 s = "world" 后:     s → "world"    "hello" 仍在内存（只是没有变量指向它）
```

### 理解引用赋值

```java
String s = "hello";
String t = s;       // t 和 s 都指向 "hello"
s = "world";        // s 指向新的 "world"
System.out.println(t);  // "hello"（t 仍指向原来的对象）
```

## 7. 空值 null

```java
String s1 = null;  // 不指向任何对象
String s2 = "";    // 指向一个空字符串对象
```

| 对比 | `null` | `""` |
|------|--------|------|
| 含义 | 不存在，不指向任何对象 | 有效对象，内容为空 |
| 调用方法 | 会抛出 NullPointerException | 正常调用 |

> ⚠️ `null` ≠ `""`，它们是完全不同的概念。

## 8. 练习：Unicode 拼接字符串

将 int 值视为 Unicode 编码，拼成字符串：

```java
int a = 72;
int b = 105;
int c = 65281;
// 先转为 char，再拼接
String s = "" + (char) a + (char) b + (char) c;
System.out.println(s);  // Hi！
```

> 注意：不能直接 `a + b + c`，那样是整数相加。需要先强制转为 `char`。

---

## 9. 关键总结

| 要点 | 说明 |
|------|------|
| char 是基本类型 | 单引号，1 个字符，2 字节，持有值 |
| String 是引用类型 | 双引号，任意长度，指向对象 |
| 字符串不可变 | 内容不可改，变量可以重新指向 |
| null vs "" | null 是空值（无对象），"" 是空字符串（有对象） |
| 转义字符 | `\"` `\\` `\n` `\t` `\u####` |
| 多行字符串 | Java 13+ 用 `"""..."""`，自动去除共同前导空格 |
