## 1. 多 catch 语句

JVM 从上到下匹配 catch，匹配到一个就执行，不再继续。

```java
try {
    process1();
    process2();
} catch (IOException e) {
    System.out.println("IO error");
} catch (NumberFormatException e) {
    System.out.println("Number format error");
}
```

### ⚠️ 子类必须写在前面

```java
// ❌ 错误：UnsupportedEncodingException 永远捕获不到
catch (IOException e) { ... }
catch (UnsupportedEncodingException e) { ... }  // 是 IOException 的子类

// ✅ 正确：子类在前，父类在后
catch (UnsupportedEncodingException e) { ... }
catch (IOException e) { ... }
```

## 2. finally 语句

无论是否发生异常，finally 块**始终执行**（用于清理资源等）。

```java
try {
    process1();
    process2();
} catch (UnsupportedEncodingException e) {
    System.out.println("Bad encoding");
} catch (IOException e) {
    System.out.println("IO error");
} finally {
    System.out.println("END");  // 无论如何都会执行
}
```

### finally 的特点

| 特点 | 说明 |
|------|------|
| 不是必须的 | 可写可不写 |
| 始终最后执行 | 无论有无异常、哪个 catch 被匹配 |
| 可以没有 catch | `try ... finally` 结构合法（方法用 throws 声明） |

```java
void process(String file) throws IOException {
    try {
        // ...
    } finally {
        System.out.println("END");  // 异常向上抛，但 finally 仍执行
    }
}
```

## 3. 合并多种异常（| 语法）

处理逻辑相同但无继承关系的异常，用 `|` 合并：

```java
try {
    process1();
    process2();
} catch (IOException | NumberFormatException e) {
    // 两种异常统一处理
    System.out.println("Bad input");
} catch (Exception e) {
    System.out.println("Unknown error");
}
```

---

## 4. 执行流程总结

```
try 块开始执行
  │
  ├─ 无异常 → 执行完 try → 跳过所有 catch → 执行 finally
  │
  └─ 有异常 → 中断 try → 匹配 catch（从上到下）→ 执行 finally
```

---

## 5. 关键总结

| 要点 | 说明 |
|------|------|
| catch 顺序 | 子类在前，父类在后 |
| 只匹配一个 | 多个 catch 只执行一个 |
| finally | 保证一定执行，用于清理资源 |
| `|` 合并 | 处理逻辑相同的非继承异常可合并 |
| try...finally | 可以没有 catch（配合 throws 使用） |
