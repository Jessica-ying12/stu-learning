## 1. Log4j 的定位

Commons Logging 是日志接口（门面），Log4j 是日志实现。两者配合使用：

```
代码 → Commons Logging（接口）→ Log4j（实现）→ 输出到各种目的地
```

> 代码中只写 Commons Logging 的 API，Log4j 通过配置文件控制输出行为。

---

## 2. Log4j 架构

```
log.info("msg")
 ├──▶ Appender → Filter → Layout → Console（屏幕）
 ├──▶ Appender → Filter → Layout → File（文件）
 └──▶ Appender → Filter → Layout → Socket（网络）
```

| 组件 | 作用 |
|------|------|
| Appender | 决定输出目的地（控制台、文件、网络、数据库） |
| Filter | 过滤哪些日志需要输出 |
| Layout | 格式化日志（添加时间、类名等） |

---

## 3. 配置文件（log4j2.xml）

放在 classpath 下，Log4j 自动读取：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Configuration>
    <Properties>
        <Property name="log.pattern">%d{MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36}%n%msg%n%n</Property>
        <Property name="file.err.filename">log/err.log</Property>
    </Properties>
    <Appenders>
        <!-- 输出到屏幕 -->
        <Console name="console" target="SYSTEM_OUT">
            <PatternLayout pattern="${log.pattern}" />
        </Console>
        <!-- 输出到文件，自动切割 -->
        <RollingFile name="err" fileName="${file.err.filename}">
            <PatternLayout pattern="${log.pattern}" />
            <Policies>
                <SizeBasedTriggeringPolicy size="1 MB" />
            </Policies>
            <DefaultRolloverStrategy max="10" />
        </RollingFile>
    </Appenders>
    <Loggers>
        <Root level="info">
            <AppenderRef ref="console" level="info" />
            <AppenderRef ref="err" level="error" />
        </Root>
    </Loggers>
</Configuration>
```

### 配置效果

| 级别 | 输出到控制台 | 输出到文件 |
|------|------------|-----------|
| INFO | ✅ | ❌ |
| WARNING | ✅ | ❌ |
| ERROR | ✅ | ✅ |

## 4. 需要的 jar 包

| jar 包 | 作用 |
|--------|------|
| commons-logging-1.2.jar | 日志接口 |
| log4j-api-2.x.jar | Log4j API |
| log4j-core-2.x.jar | Log4j 核心实现 |
| log4j-jcl-2.x.jar | Commons Logging 到 Log4j 的桥接 |

---

## 5. 最佳实践

| 阶段 | 做法 |
|------|------|
| 开发阶段 | 只用 Commons Logging 写代码，不引入 Log4j |
| 需要文件日志时 | 加入 log4j2.xml + jar 包，无需改代码 |
| 更换日志框架 | 移除 log4j2.xml 和 jar 包即可 |

```java
// 代码始终这样写，不依赖 Log4j 的 API
import org.apache.commons.logging.Log;
import org.apache.commons.logging.LogFactory;

Log log = LogFactory.getLog(Main.class);
log.info("Start process...");
log.error("Error!", e);
```

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| 接口与实现分离 | 代码用 Commons Logging，实现用 Log4j |
| 配置驱动 | 通过 log4j2.xml 控制输出目的地、级别、格式 |
| 自动切割 | RollingFile 按文件大小自动切割，保留指定份数 |
| 零代码修改 | 切换/移除 Log4j 无需改任何代码 |
| 组件化 | Appender + Filter + Layout 灵活组合 |
