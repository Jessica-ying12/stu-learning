## 1. 异常的传播

异常沿调用栈向上传播，直到被某个 try...catch 捕获：

```java
main() → process1() → process2() → Integer.parseInt(null)
                                     ↑ 抛出 NumberFormatException
```

### printStackTrace() 输出调用栈

```
java.lang.NumberFormatException: null
    at java.lang.Integer.parseInt(Integer.java:614)
    at Main.process2(Main.java:16)
    at Main.process1(Main.java:12)
    at Main.main(Main.java:5)
```

> 从下往上看：main → process1 → process2 → parseInt，逐层定位问题。

---

## 2. 抛出异常

两步：创建异常实例 + throw 抛出（通常合并写）：

```java
void process(String s) {
    if (s == null) {
        throw new NullPointerException("s is null");
    }
}
```

---

## 3. 异常转换（保留原始异常）

捕获异常后抛出新异常时，**必须传入原始异常**：

```java
// ❌ 丢失原始异常信息
catch (NullPointerException e) {
    throw new IllegalArgumentException();
}

// ✅ 保留原始异常
catch (NullPointerException e) {
    throw new IllegalArgumentException(e);  // 传入原始异常
}
```

保留后的异常栈会显示 `Caused by:`：

```
java.lang.IllegalArgumentException: java.lang.NullPointerException
    at Main.process1(Main.java:15)
Caused by: java.lang.NullPointerException
    at Main.process2(Main.java:20)
```

> 用 `getCause()` 获取原始异常，返回 null 说明是根异常。

## 4. finally 中的异常

### catch 中抛异常不影响 finally 执行

```java
try {
    Integer.parseInt("abc");
} catch (Exception e) {
    throw new RuntimeException(e);  // 抛出异常
} finally {
    System.out.println("finally");  // 仍然执行
}
// 输出: finally，然后抛出 RuntimeException
```

### 异常屏蔽（Suppressed Exception）

如果 finally 也抛出异常，catch 的异常会被"屏蔽"：

```java
catch (Exception e) {
    throw new RuntimeException(e);  // 被屏蔽
} finally {
    throw new IllegalArgumentException();  // 最终抛出这个
}
```

### 解决方案：addSuppressed()

```java
Exception origin = null;
try {
    // ...
} catch (Exception e) {
    origin = e;
    throw e;
} finally {
    Exception e = new IllegalArgumentException();
    if (origin != null) {
        e.addSuppressed(origin);  // 保存被屏蔽的异常
    }
    throw e;
}
```

> 通过 `getSuppressed()` 获取所有被屏蔽的异常。

---

## 5. 最佳实践

| 原则 | 说明 |
|------|------|
| 保留原始异常 | 转换异常时传入原始 exception |
| 不要在 finally 中抛异常 | 会屏蔽 catch 中的异常 |
| 提问要贴完整异常栈 | 包括 Caused by 信息 |
| printStackTrace() | 调试时快速定位问题 |

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| throw | 创建异常实例并抛出 |
| 异常传播 | 沿调用栈向上，直到被 catch |
| 异常转换 | `throw new XxxException(原始异常)` |
| Caused by | 异常栈中显示原始异常链 |
| finally 中抛异常 | 屏蔽 catch 的异常，用 addSuppressed 保存 |
