## 1. 什么是 Commons Logging

Apache 提供的第三方日志库，特点是**日志接口与实现分离**：

- 自动搜索并使用 Log4j（如果有）
- 找不到 Log4j 则使用 JDK Logging
- 通过配置文件切换日志实现，无需改代码

---

## 2. 基本用法（两步）

```java
import org.apache.commons.logging.Log;
import org.apache.commons.logging.LogFactory;

public class Main {
    public static void main(String[] args) {
        Log log = LogFactory.getLog(Main.class);  // 第一步：获取 Log 实例
        log.info("start...");                      // 第二步：打印日志
        log.warn("end.");
    }
}
```

---

## 3. 编译和运行（需要 jar 包）

```bash
# 编译（指定 classpath 包含 jar）
javac -cp commons-logging-1.2.jar Main.java

# 运行（classpath 包含当前目录 + jar）
java -cp .:commons-logging-1.2.jar Main     # Linux/macOS 用 :
java -cp .;commons-logging-1.2.jar Main     # Windows 用 ;
```

---

## 4. 日志级别（从高到低）

| 级别 | 说明 |
|------|------|
| FATAL | 致命错误 |
| ERROR | 错误 |
| WARNING | 警告 |
| **INFO** | **默认级别** |
| DEBUG | 调试 |
| TRACE | 最详细跟踪 |

## 5. 最佳实践

### 静态方法中使用

```java
public class Main {
    static final Log log = LogFactory.getLog(Main.class);

    static void foo() {
        log.info("foo");
    }
}
```

### 实例方法中使用（推荐 getClass()）

```java
public class Person {
    protected final Log log = LogFactory.getLog(getClass());

    void foo() {
        log.info("foo");
    }
}
```

> 用 `getClass()` 的好处：子类继承后，log 自动对应子类类名，无需修改代码。

```java
public class Student extends Person {
    void bar() {
        log.info("bar");  // 直接使用父类的 log，输出类名为 Student
    }
}
```

### 记录异常

```java
try {
    // ...
} catch (Exception e) {
    log.error("got exception!", e);  // 传入 Throwable，自动打印异常栈
}
```

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| 定位 | 日志接口层（门面），自动适配底层实现 |
| API | 只需 LogFactory + Log 两个类 |
| 获取方式 | `LogFactory.getLog(Xxx.class)` 或 `getLog(getClass())` |
| 记录异常 | `log.error("msg", e)` 传入 Throwable |
| 实际地位 | 使用最广泛的日志接口之一（后被 SLF4J 逐步取代） |
