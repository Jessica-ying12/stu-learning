## 1. 什么是 NPE

对 null 对象调用方法或访问字段时，JVM 抛出 NullPointerException：

```java
String s = null;
s.toLowerCase();  // NullPointerException!
```

> NPE 是代码逻辑错误，原则是**早暴露，早修复**。

---

## 2. 严禁用 catch 隐藏 NPE

```java
// ❌ 错误：吞掉 NPE，掩盖 bug
try {
    transferMoney(from, to, amount);
} catch (NullPointerException e) {
}
```

---

## 3. 预防 NPE 的编码习惯

| 习惯 | 示例 |
|------|------|
| 成员变量初始化 | `private String name = "";` |
| 返回空字符串/空数组而非 null | `return new String[0];` |
| 使用 Optional | `return Optional.empty();` |

### 返回空集合/数组

```java
public String[] readLines(String file) {
    if (getFileSize(file) == 0) {
        return new String[0];  // ✅ 不返回 null
    }
    // ...
}
```

### 使用 Optional

```java
public Optional<String> readFromFile(String file) {
    if (!fileExist(file)) {
        return Optional.empty();  // 调用方必须检查
    }
    // ...
}
```

---

## 4. 定位 NPE

### 链式调用难以定位

```java
a.b.c.x()  // NPE！到底 a、a.b 还是 a.b.c 是 null？
```

### Java 14+ 增强异常信息

```bash
java -XX:+ShowCodeDetailsInExceptionMessages Main.java
```

输出会明确告知哪个字段为 null：

```
... because "<local1>.address.city" is null
```

---

## 5. 关键总结

| 要点 | 说明 |
|------|------|
| NPE 是逻辑错误 | 不要 catch 隐藏，要修复代码 |
| 初始化字段 | 用 `""` 代替 null，用空数组代替 null |
| Optional | 明确表示"可能没有值"，强制调用方处理 |
| Java 14+ | 开启详细信息快速定位 null 对象 |
| 早暴露早修复 | NPE 的核心处理原则 |
