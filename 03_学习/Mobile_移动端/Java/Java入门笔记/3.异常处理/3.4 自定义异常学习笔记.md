## 1. JDK 常用异常体系

```
Exception
├─ RuntimeException
│  ├─ NullPointerException
│  ├─ IndexOutOfBoundsException
│  ├─ SecurityException
│  └─ IllegalArgumentException
│     └─ NumberFormatException
├─ IOException
│  ├─ FileNotFoundException
│  └─ SocketException
├─ ParseException
├─ SQLException
└─ TimeoutException
```

> 抛出异常时，优先使用 JDK 已定义的异常类型。

---

## 2. 自定义异常体系

大型项目中，自定义一个 **BaseException** 作为根异常，业务异常从它派生：

```java
public class BaseException extends RuntimeException {
    public BaseException() {
        super();
    }
    public BaseException(String message) {
        super(message);
    }
    public BaseException(String message, Throwable cause) {
        super(message, cause);
    }
    public BaseException(Throwable cause) {
        super(cause);
    }
}
```

### 派生业务异常

```java
public class UserNotFoundException extends BaseException {
    public UserNotFoundException() { super(); }
    public UserNotFoundException(String message) { super(message); }
    public UserNotFoundException(String message, Throwable cause) { super(message, cause); }
    public UserNotFoundException(Throwable cause) { super(cause); }
}

public class LoginFailedException extends BaseException { ... }
```

### 使用

```java
void findUser(String name) {
    if (name == null) {
        throw new UserNotFoundException("User not found: " + name);
    }
}
```

---

## 3. 为什么从 RuntimeException 派生

| 选择 | 效果 |
|------|------|
| 继承 RuntimeException | 不强制 try...catch，代码简洁 |
| 继承 Exception | 强制调用方处理，适合必须处理的场景 |

> 大多数业务异常建议继承 RuntimeException，减少样板代码。

---

## 4. 关键总结

| 要点 | 说明 |
|------|------|
| 优先用 JDK 异常 | 如 IllegalArgumentException、IOException |
| 自定义根异常 | BaseException extends RuntimeException |
| 业务异常派生 | UserNotFoundException、LoginFailedException 等 |
| 提供多种构造方法 | 无参、带 message、带 cause、带两者 |
| IDE 辅助 | 可根据父类快速生成子类构造方法 |
