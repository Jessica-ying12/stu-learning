## 1. 什么是面向对象编程

**OOP**（Object-Oriented Programming）= 面向对象编程

通过对象的方式，把现实世界映射到计算机模型的编程方法。

### 面向过程 vs 面向对象

| 对比 | 面向过程 | 面向对象 |
|------|----------|----------|
| 思路 | 把任务分解为一步步的过程 | 先定义对象，再通过对象交互 |
| 关注点 | 步骤（做什么） | 对象（谁来做） |
| 代码组织 | 函数/过程 | 类和对象 |

**面向过程示例：**

```
1. 读取文件
2. 编写 TODO
3. 保存文件
```

**面向对象示例：**

```java
GirlFriend gf = new GirlFriend();
gf.name = "Alice";
gf.send("flowers");
```

## 2. 本章学习路线

### 基本概念

| 概念 | 说明 |
|------|------|
| 类（class） | 对象的模板/蓝图 |
| 实例（instance） | 根据类创建的具体对象 |
| 方法（method） | 对象能执行的操作 |

### 面向对象三大特性

| 特性 | 说明 |
|------|------|
| 封装 | 将数据和操作封装在类内部，隐藏实现细节 |
| 继承 | 子类继承父类的属性和方法，实现代码复用 |
| 多态 | 同一方法在不同对象上有不同的行为 |

### Java 语言机制

| 机制 | 说明 |
|------|------|
| package | 包，用于组织类，避免命名冲突 |
| classpath | 类搜索路径，JVM 查找 class 文件的路径 |
| jar | 打包多个 class 文件的压缩包 |

### Java 核心类

| 核心类 | 说明 |
|--------|------|
| 字符串（String） | 不可变的字符序列 |
| 包装类型 | 基本类型的对象形式（Integer、Double 等） |
| JavaBean | 符合特定规范的类（getter/setter） |
| 枚举（enum） | 定义有限个常量的类型 |
| 常用工具类 | Math、Arrays、Collections 等 |

## 3. 关键总结

| 要点 | 说明 |
|------|------|
| OOP 核心思想 | 万物皆对象，通过对象交互完成任务 |
| 类是模板 | 定义对象有什么属性和行为 |
| 实例是具体对象 | 根据类 new 出来的真实存在 |
| 三大特性 | 封装、继承、多态 |
| Java 是纯 OOP 语言 | 所有代码都必须在类中 |
