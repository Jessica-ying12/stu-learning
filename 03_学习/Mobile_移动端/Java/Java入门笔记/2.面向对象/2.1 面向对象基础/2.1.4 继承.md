## 1. 什么是继承

继承是面向对象编程中的代码复用机制。子类通过 `extends` 获得父类的所有字段和方法，只需编写新增功能。

```java
class Person {
    private String name;
    private int age;
    public String getName() { ... }
    public void setName(String name) { ... }
}

class Student extends Person {
    // 自动获得 name、age 及相关方法
    // 只需定义新增部分
    private int score;
    public int getScore() { ... }
    public void setScore(int score) { ... }
}
```

> 子类自动获得父类所有字段，**严禁定义与父类重名的字段**。

---

## 2. 继承树

- Java 只允许**单继承**（一个类只能有一个父类）
- 所有类最终都继承自 `Object`
- 没写 `extends` 的类，编译器自动加 `extends Object`

```
       Object
         ▲
         │
       Person
        ▲  ▲
       /    \
  Student  Teacher
```

## 3. 访问权限：protected

| 修饰符 | 本类 | 子类 | 外部 |
|--------|------|------|------|
| `private` | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ |

```java
class Person {
    protected String name;  // 子类可以访问
}

class Student extends Person {
    public String hello() {
        return "Hello, " + name;  // OK
    }
}
```

## 4. super 关键字

### 访问父类字段

```java
super.name  // 效果等同于 this.name（无冲突时可省略）
```

### 调用父类构造方法（重点）

子类构造方法的**第一行**必须调用父类构造方法：

```java
class Person {
    protected String name;
    protected int age;
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

class Student extends Person {
    protected int score;
    public Student(String name, int age, int score) {
        super(name, age);  // 必须在第一行调用父类构造方法
        this.score = score;
    }
}
```

| 规则 | 说明 |
|------|------|
| 不写 super() | 编译器自动加 `super()`（调用无参构造） |
| 父类没有无参构造 | 必须显式写 `super(参数)` |
| 子类不继承构造方法 | 必须自己定义 |

## 5. 向上转型（upcasting）

子类可以安全地赋值给父类类型的变量：

```java
Student s = new Student();
Person p = s;         // OK：Student → Person
Object o = s;        // OK：Student → Object
```

> 向上转型始终安全，因为子类拥有父类的全部功能。

---

## 6. 向下转型（downcasting）

父类类型强制转为子类类型，**可能失败**：

```java
Person p1 = new Student();
Person p2 = new Person();

Student s1 = (Student) p1;  // ✅ 成功（p1 实际是 Student）
Student s2 = (Student) p2;  // ❌ 失败！ClassCastException
```

### 用 instanceof 安全判断

```java
if (p instanceof Student) {
    Student s = (Student) p;  // 安全转型
}

// Java 14+ 简写：
if (p instanceof Student s) {
    // 直接使用变量 s
    System.out.println(s.getScore());
}
```

| instanceof 规则 | 结果 |
|-----------------|------|
| 实例是指定类型或其子类 | `true` |
| 变量为 null | `false` |

## 7. sealed 类（Java 15+）

限制哪些类可以继承自己：

```java
public sealed class Shape permits Rect, Circle, Triangle { }

public final class Rect extends Shape { }     // ✅ 在 permits 列表中
public final class Ellipse extends Shape { }  // ❌ 编译错误
```

## 8. 继承 vs 组合

| 关系 | 用法 | 示例 |
|------|------|------|
| is（是一种） | 继承 | Student is a Person → `extends` |
| has（拥有） | 组合 | Student has a Book → 持有字段 |

```java
// ❌ 错误：Student 不是 Book
class Student extends Book { }

// ✅ 正确：Student 拥有 Book
class Student extends Person {
    protected Book book;  // 组合
}
```

## 9. 练习：PrimaryStudent

```java
class PrimaryStudent extends Student {
    protected int grade;

    public PrimaryStudent(String name, int age, int score, int grade) {
        super(name, age, score);
        this.grade = grade;
    }

    public int getGrade() {
        return grade;
    }
}
```

## 10. 关键总结

| 要点 | 说明 |
|------|------|
| extends | 实现继承，Java 只允许单继承 |
| protected | 允许子类访问父类字段/方法 |
| super() | 子类构造方法必须调用父类构造方法（第一行） |
| 向上转型 | 子类 → 父类，始终安全 |
| 向下转型 | 父类 → 子类，需 instanceof 判断 |
| is 关系 | 用继承 |
| has 关系 | 用组合（持有字段） |
| Object | 所有类的根类 |
