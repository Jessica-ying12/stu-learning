## 1. 为什么需要方法

直接用 `public` 暴露字段，外部可以随意赋值，破坏数据合法性：

```java
ming.age = -99;  // 不合理，但编译通过
```

**解决方案：** 字段用 `private`，通过方法间接访问，在方法内做参数检查。

---

## 2. private 字段 + public 方法 = 封装

```java
class Person {
    private String name;
    private int age;

    public String getName() {
        return this.name;
    }

    public void setName(String name) {
        if (name == null || name.isBlank()) {
            throw new IllegalArgumentException("invalid name");
        }
        this.name = name.strip();
    }

    public int getAge() {
        return this.age;
    }

    public void setAge(int age) {
        if (age < 0 || age > 100) {
            throw new IllegalArgumentException("invalid age value");
        }
        this.age = age;
    }
}
```

- 外部通过 `ming.setAge(12)` 间接修改
- 方法内部可以做合法性检查
- 外部无法设置不合理的值

---

## 3. 定义方法的语法

```java
修饰符 返回类型 方法名(参数列表) {
    方法体;
    return 返回值;
}
```

| 组成部分 | 说明 |
|----------|------|
| 修饰符 | `public`、`private` 等 |
| 返回类型 | 返回值的类型，无返回值用 `void` |
| 方法名 | 小驼峰命名 |
| 参数列表 | 0 个或多个，用逗号分隔 |
| return | 返回值并结束方法；`void` 方法可省略 |

---

## 4. private 方法

外部不能调用，但内部方法可以调用：

```java
class Person {
    private int birth;

    public int getAge() {
        return calcAge(2024);  // 内部调用 private 方法
    }

    private int calcAge(int currentYear) {
        return currentYear - this.birth;
    }
}
```

> 方法可以封装计算逻辑，调用方不需要知道内部是否有 age 字段。

---

## 5. this 变量

`this` 始终指向当前实例：

```java
class Person {
    private String name;

    // 无命名冲突时可省略 this
    public String getName() {
        return name;  // 等同于 this.name
    }

    // 参数名与字段名相同时必须用 this 区分
    public void setName(String name) {
        this.name = name;  // this.name 是字段，name 是参数
    }
}
```

## 6. 方法参数

### 普通参数

```java
public void setNameAndAge(String name, int age) { ... }

ming.setNameAndAge("Xiao Ming", 12);  // 必须严格匹配类型和数量
```

### 可变参数（类型...）

```java
class Group {
    private String[] names;

    public void setNames(String... names) {
        this.names = names;
    }
}

g.setNames("Ming", "Hong", "Jun");  // 传 3 个
g.setNames("Ming");                  // 传 1 个
g.setNames();                        // 传 0 个（接收空数组，不是 null）
```

| 对比 | `String... names` | `String[] names` |
|------|-------------------|------------------|
| 调用方式 | 直接传多个值 | 需手动构造数组 |
| 传入 0 个参数 | 接收空数组 | 可能传入 null |

## 7. 参数绑定

### 基本类型：值复制，互不影响

```java
int n = 15;
p.setAge(n);   // 复制 n 的值 15 给方法参数
n = 20;        // 修改 n 不影响 p.age
p.getAge();    // 仍然是 15
```

### 引用类型：传递引用，指向同一对象

```java
String[] fullname = { "Homer", "Simpson" };
p.setName(fullname);    // p.name 和 fullname 指向同一个数组
fullname[0] = "Bart";   // 修改数组内容
p.getName();            // "Bart Simpson"（受影响！）
```

### 特殊情况：String 的"不可变"

```java
String bob = "Bob";
p.setName(bob);    // p.name 指向 "Bob"
bob = "Alice";     // bob 指向新对象 "Alice"，p.name 仍指向 "Bob"
p.getName();       // "Bob"（不受影响）
```

> `bob = "Alice"` 是让变量指向新对象，不是修改原对象的内容。

### 参数绑定总结

| 类型 | 传递的是 | 后续修改是否互相影响 |
|------|----------|---------------------|
| 基本类型 | 值的复制 | ❌ 互不影响 |
| 引用类型（修改对象内容） | 引用的复制 | ✅ 影响（同一对象） |
| 引用类型（重新赋值变量） | 引用的复制 | ❌ 不影响（指向不同对象） |

---

## 8. 关键总结

| 要点 | 说明 |
|------|------|
| 封装 | private 字段 + public 方法，保证数据合法性 |
| 方法作用 | 安全访问字段、封装逻辑、对外暴露接口 |
| this | 指向当前实例，字段与参数同名时必须用 |
| private 方法 | 内部辅助方法，外部不可调用 |
| 可变参数 | `类型...` 定义，调用方便且不会传入 null |
| 参数绑定 | 基本类型传值，引用类型传引用（但重新赋值不影响） |
