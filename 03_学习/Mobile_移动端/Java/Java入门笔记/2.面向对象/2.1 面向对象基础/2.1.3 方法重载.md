## 1. 什么是方法重载（Overload）

方法名相同，但参数不同（数量、类型或顺序不同），称为方法重载。

```java
class Hello {
    public void hello() {
        System.out.println("Hello, world!");
    }

    public void hello(String name) {
        System.out.println("Hello, " + name + "!");
    }

    public void hello(String name, int age) {
        if (age < 18) {
            System.out.println("Hi, " + name + "!");
        } else {
            System.out.println("Hello, " + name + "!");
        }
    }
}
```

---

## 2. 重载的目的

功能类似的方法使用同一名字，调用时更容易记忆和使用。

### 实际案例：String.indexOf()

```java
String s = "Test string";
s.indexOf('t');          // 根据字符查找 → 3
s.indexOf("st");         // 根据字符串查找 → 2
s.indexOf("st", 4);     // 指定起始位置查找 → 5
```

| 重载方法 | 参数 |
|----------|------|
| `indexOf(int ch)` | 字符的 Unicode 码 |
| `indexOf(String str)` | 字符串 |
| `indexOf(int ch, int fromIndex)` | 字符 + 起始位置 |
| `indexOf(String str, int fromIndex)` | 字符串 + 起始位置 |

> 同一个方法名，不同参数组合，编译器自动匹配调用。

---

## 3. 重载的规则

| 规则 | 说明 |
|------|------|
| 方法名必须相同 | 这是重载的前提 |
| 参数必须不同 | 数量、类型或顺序至少有一项不同 |
| 返回值类型通常相同 | 不能仅靠返回值区分重载 |
| 编译器自动匹配 | 根据调用时传入的参数匹配对应方法 |

## 4. 练习：增加重载方法

```java
class Person {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    // 重载方法：接收 firstName 和 lastName
    public void setName(String firstName, String lastName) {
        this.name = firstName + " " + lastName;
    }
}
```

```java
ming.setName("Xiao Ming");       // 调用 setName(String)
hong.setName("Xiao", "Hong");    // 调用 setName(String, String)
```

---

## 5. 关键总结

| 要点 | 说明 |
|------|------|
| 定义 | 方法名相同，参数不同 |
| 目的 | 功能类似的方法统一命名，方便调用 |
| 匹配方式 | 编译器根据参数数量和类型自动匹配 |
| 返回值 | 通常相同，不能仅靠返回值不同来区分 |
| 与重写的区别 | 重载（Overload）是同一类中；重写（Override）是子类覆盖父类方法 |
