## 1. 静态字段（static field）

用 `static` 修饰的字段属于类本身，所有实例**共享同一份**数据。

```java
class Person {
    public String name;       // 实例字段：每个实例独立
    public static int number; // 静态字段：所有实例共享
}
```

### 内存模型

```
ming → Person instance (name="Xiao Ming") ──┐
                                             ├──▶ Person class: number = 99
hong → Person instance (name="Xiao Hong") ──┘
```

- 修改任何一个实例的静态字段，所有实例看到的都是同一个值
- 静态字段**不属于实例**，属于 class

### 访问方式

```java
// ❌ 不推荐：通过实例访问（会有编译警告）
ming.number = 99;

// ✅ 推荐：通过类名访问
Person.number = 99;
System.out.println(Person.number);
```

---

## 2. 静态方法（static method）

用 `static` 修饰的方法，通过类名直接调用，不需要实例。

```java
class Person {
    public static int number;

    public static void setNumber(int value) {
        number = value;
    }
}

// 调用
Person.setNumber(99);
```

### 静态方法的限制

| 能访问 | 不能访问 |
|--------|----------|
| 静态字段 | 实例字段 |
| 其他静态方法 | `this` 变量 |
| | 实例方法 |

> 因为静态方法属于 class，不属于实例，所以没有 `this`。

---

## 3. 实例 vs 静态 对比

| 对比 | 实例字段/方法 | 静态字段/方法 |
|------|-------------|-------------|
| 所属 | 属于实例 | 属于 class |
| 访问方式 | `实例.字段` / `实例.方法()` | `类名.字段` / `类名.方法()` |
| 数据独立性 | 每个实例各一份 | 所有实例共享一份 |
| 能否访问 this | ✅ | ❌ |
| 能否访问实例字段 | ✅ | ❌ |

---

## 4. 静态方法的常见用途

| 用途 | 示例 |
|------|------|
| 工具类方法 | `Arrays.sort()`、`Math.random()` |
| 辅助方法 | 不依赖实例状态的通用逻辑 |
| 程序入口 | `public static void main(String[] args)` |

---

## 5. 接口的静态字段

接口中只能有 `public static final` 类型的字段（常量）：

```java
public interface Person {
    // 完整写法
    public static final int MALE = 1;
    public static final int FEMALE = 2;

    // 简写（编译器自动加 public static final）
    int MALE = 1;
    int FEMALE = 2;
}
```

## 6. 练习：统计实例创建个数

```java
class Person {
    public String name;
    private static int count;  // 静态字段：统计创建次数

    public Person(String name) {
        this.name = name;
        count++;  // 每创建一个实例，计数加 1
    }

    public static int getCount() {
        return count;
    }
}
```

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 静态字段 | 属于 class，所有实例共享，用类名访问 |
| 静态方法 | 属于 class，不需要实例，不能访问 this 和实例字段 |
| 访问方式 | 统一用 `类名.字段` / `类名.方法()` |
| 接口常量 | 默认 `public static final`，可省略修饰符 |
| 典型用途 | 工具类、辅助方法、计数器、程序入口 main |
