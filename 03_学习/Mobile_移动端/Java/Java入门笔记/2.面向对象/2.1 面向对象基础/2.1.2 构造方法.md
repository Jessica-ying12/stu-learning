## 1. 为什么需要构造方法

创建实例时希望一次性完成初始化，而不是分多步调用 setter：

```java
// 没有构造方法：需要多步初始化，容易遗漏
Person ming = new Person();
ming.setName("小明");
ming.setAge(12);

// 有构造方法：一步到位
Person ming = new Person("小明", 12);
```

---

## 2. 定义构造方法

```java
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

### 构造方法的特点

| 特点 | 说明 |
|------|------|
| 方法名 = 类名 | `Person` 类的构造方法就叫 `Person` |
| 没有返回值 | 连 `void` 都不写 |
| 调用方式 | 必须通过 `new` 操作符调用 |
| 参数 | 无限制，可以有 0 到多个 |

---

## 3. 默认构造方法

| 情况 | 编译器行为 |
|------|-----------|
| 没有定义任何构造方法 | 自动生成一个无参的默认构造方法 |
| 自定义了构造方法 | **不再**自动生成默认构造方法 |

```java
class Person {
    public Person(String name, int age) { ... }
}

Person p = new Person();  // ❌ 编译错误！默认构造方法不存在了
```

> 如果两种调用方式都要支持，必须显式定义两个构造方法。

---

## 4. 字段初始化顺序

```java
class Person {
    private String name = "Unnamed";  // ① 字段初始化
    private int age = 10;

    public Person(String name, int age) {
        this.name = name;  // ② 构造方法执行
        this.age = age;
    }
}
```

**执行顺序：**

1. 先执行字段的默认值初始化
2. 再执行构造方法的代码

> 构造方法后执行，所以最终值由构造方法决定。

### 字段默认值（未初始化时）

| 类型 | 默认值 |
|------|--------|
| 引用类型（String 等） | `null` |
| int / long 等整型 | `0` |
| float / double | `0.0` |
| boolean | `false` |

---

## 5. 多个构造方法（重载）

编译器根据参数数量、类型自动匹配：

```java
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public Person(String name) {
        this.name = name;
        this.age = 12;  // 默认年龄
    }

    public Person() {
    }
}
```

```java
new Person("小明", 20);  // 匹配 Person(String, int)
new Person("小明");      // 匹配 Person(String)
new Person();            // 匹配 Person()
```

---

## 6. 构造方法互相调用（this(...)）

用 `this(...)` 调用同类中另一个构造方法，避免代码重复：

```java
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public Person(String name) {
        this(name, 18);  // 调用 Person(String, int)
    }

    public Person() {
        this("Unnamed");  // 调用 Person(String)
    }
}
```

> `this(...)` 必须是构造方法中的第一条语句。

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 作用 | 创建实例时初始化字段 |
| 命名 | 方法名 = 类名，无返回值 |
| 默认构造方法 | 没定义时编译器自动生成，自定义后就消失 |
| 初始化顺序 | 字段默认值 → 构造方法代码 |
| 多个构造方法 | 参数不同即可，编译器自动匹配（方法重载） |
| this(...) | 构造方法间互调，代码复用 |
