## 1. 四种访问权限

| 修饰符 | 本类 | 同包 | 子类 | 外部任何类 |
|--------|------|------|------|-----------|
| `public` | ✅ | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| 默认（包作用域） | ✅ | ✅ | ❌ | ❌ |
| `private` | ✅ | ❌ | ❌ | ❌ |

---

## 2. public

class、interface、field、method 都可以被其他任何类访问：

```java
package abc;
public class Hello {
    public void hi() { }
}

package xyz;
class Main {
    void foo() {
        Hello h = new Hello();  // ✅ 可以访问 public 类
        h.hi();                  // ✅ 可以访问 public 方法
    }
}
```

> 访问 public 方法的前提是先能访问其所在的 class。

---

## 3. private

只能在**本类内部**访问，与声明顺序无关：

```java
public class Hello {
    public void hello() {
        this.hi();  // ✅ 本类内可以调用 private 方法
    }

    private void hi() { }  // 外部不可调用
}
```

### 嵌套类可以访问外部类的 private

```java
public class Main {
    private static void hello() { }

    static class Inner {
        public void hi() {
            Main.hello();  // ✅ 嵌套类可以访问
        }
    }
}
```

### 建议

把 `public` 方法放前面（对外接口），`private` 方法放后面（内部实现）。

---

## 4. protected

作用于继承关系，子类及子类的子类可以访问：

```java
package abc;
public class Hello {
    protected void hi() { }
}

package xyz;
class Main extends Hello {
    void foo() {
        hi();  // ✅ 子类可以访问 protected 方法
    }
}
```

---

## 5. 包作用域（默认）

没有修饰符 = 包作用域，同一个包内的类可以访问：

```java
package abc;
class Hello {           // 包作用域的类
    void hi() { }       // 包作用域的方法
}

package abc;
class Main {
    void foo() {
        Hello h = new Hello();  // ✅ 同包可以访问
        h.hi();                  // ✅ 同包可以访问
    }
}
```

> 包名必须完全一致。`com.apache` 和 `com.apache.abc` 是不同的包。

---

## 6. 局部变量作用域

方法内定义的变量，作用域从声明处到所在块 `{}` 结束：

```java
void hi(String name) {       // name: 1~10
    String s = name.toLowerCase(); // s: 2~10
    int len = s.length();          // len: 3~10
    if (len < 10) {                
        int p = 10 - len;          // p: 5~9
        for (int i = 0; i < 10; i++) { // i: 6~8
            System.out.println();
        }
    }
}
```

**原则：** 尽可能缩小作用域，尽可能延后声明。

---

## 7. final 修饰符

final 不是访问权限，是一种"不可变"约束：

| 用法 | 效果 |
|------|------|
| `final class` | 不能被继承 |
| `final method` | 不能被子类覆写 |
| `final field` | 初始化后不能重新赋值 |
| `final 局部变量/参数` | 不能重新赋值 |

```java
public final class Hello { }          // 不能被继承
protected final void hi() { }        // 不能被覆写
private final int n = 0;             // 不能再赋值
protected void hi(final int t) { }   // 参数 t 不能被修改
```

## 8. 最佳实践

| 原则 | 说明 |
|------|------|
| 最小暴露 | 不确定是否需要 public，就不声明为 public |
| 包权限便于测试 | 测试类和被测试类放同一个包，可访问包权限方法 |
| 一个文件一个 public 类 | 文件名必须与 public 类名一致 |
| 可包含多个非 public 类 | 一个 `.java` 文件中允许 |

---

## 9. 关键总结

| 要点 | 说明 |
|------|------|
| 四种权限 | public > protected > 包作用域 > private |
| private | 本类内部，嵌套类也可访问 |
| protected | 继承链上的子类可访问 |
| 包作用域 | 同包可访问，包名必须完全一致 |
| 局部变量 | 从声明到块结束，越小越好 |
| final | 不可变约束，与访问权限不冲突 |
