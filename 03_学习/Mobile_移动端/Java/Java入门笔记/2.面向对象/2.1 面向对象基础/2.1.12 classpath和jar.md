## 1. classpath 是什么

classpath 是 JVM 搜索 `.class` 文件的路径集合。

当 JVM 要加载 `abc.xyz.Hello` 类时，会在 classpath 指定的每个目录下查找 `abc/xyz/Hello.class`。

### 不同系统的格式

| 系统 | 分隔符 | 示例 |
|------|--------|------|
| Windows | `;` | `.;C:\work\bin;C:\shared` |
| Linux/macOS | `:` | `.:/usr/shared:/home/user/bin` |

> `.` 代表当前目录。

### 搜索过程示例

classpath 为 `.;C:\work\project1\bin;C:\shared`，加载 `abc.xyz.Hello`：

1. `<当前目录>\abc\xyz\Hello.class`
2. `C:\work\project1\bin\abc\xyz\Hello.class`
3. `C:\shared\abc\xyz\Hello.class`

找到即停止，都没找到就报错。

---

## 2. 设置 classpath 的方式

| 方式 | 推荐 | 说明 |
|------|------|------|
| 系统环境变量 | ❌ 不推荐 | 污染全局环境 |
| `-cp` / `-classpath` 参数 | ✅ 推荐 | 启动时指定 |
| 不设置 | ✅ 可以 | 默认为 `.`（当前目录） |

```bash
# 推荐写法
java -cp .;C:\work\bin abc.xyz.Hello

# 不指定时默认 classpath 为当前目录
java abc.xyz.Hello
```

### 重要提醒

- **不要把 Java 核心库（rt.jar 等）加入 classpath**，JVM 自己知道核心库在哪
- IDE 自动传入 `-cp` 参数（当前工程 bin 目录 + 引入的 jar 包）

---

## 3. 目录结构必须与包名一致

```
C:\work/              ← 当前目录（classpath = .）
└── com/
    └── example/
        └── Hello.class    ← 包名 com.example
```

```bash
C:\work> java -cp . com.example.Hello
```

> 目录结构和包名对不上会报错。

---

## 4. jar 包

### 什么是 jar 包

- 本质是 **zip 格式**的压缩文件
- 把 package 目录结构打成一个文件，方便管理和分发
- 在 classpath 中相当于一个目录

### 使用 jar 包

```bash
java -cp ./hello.jar abc.xyz.Hello
```

### 创建 jar 包的注意事项

jar 包内**第一层目录必须是包名目录**，不能包含额外的父目录：

```
# ✅ 正确结构
hello.jar
├── hong/
│   └── Person.class
├── ming/
│   └── Person.class
└── mr/
    └── jun/
        └── Arrays.class

# ❌ 错误结构（多了 bin 目录）
hello.jar
└── bin/
    ├── hong/
    │   └── Person.class
    ...
```

---

## 5. MANIFEST.MF

jar 包可以包含 `/META-INF/MANIFEST.MF` 文件，指定入口类：

```
Main-Class: com.example.Hello
```

配置后可以直接运行：

```bash
java -jar hello.jar  # 不用指定类名
```

> 实际项目中用 Maven 等构建工具自动生成 jar 包和 MANIFEST.MF。

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| classpath | JVM 搜索 class 的路径集合 |
| 推荐做法 | 用 `-cp` 参数指定，不设系统环境变量 |
| 默认值 | `.`（当前目录） |
| 核心库 | 不需要加入 classpath，JVM 自己处理 |
| jar 包 | zip 格式，相当于目录，第一层必须是包名目录 |
| MANIFEST.MF | 指定 Main-Class 后可用 `java -jar` 直接运行 |
| 构建工具 | 实际项目用 Maven/Gradle 管理 jar 包 |
