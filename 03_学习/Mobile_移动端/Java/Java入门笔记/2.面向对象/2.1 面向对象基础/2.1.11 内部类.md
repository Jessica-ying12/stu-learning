## 1. 内部类分类

| 类型 | 定义方式 | 是否依附外部实例 | 编译后文件名 |
|------|----------|-----------------|-------------|
| Inner Class | 类内部定义 | ✅ 是 | `Outer$Inner.class` |
| Anonymous Class | 方法内部匿名定义 | ✅ 是 | `Outer$1.class` |
| Static Nested Class | `static` 修饰 | ❌ 否 | `Outer$StaticNested.class` |

---

## 2. Inner Class（内部类）

定义在另一个类内部，**必须依附于外部类实例**：

```java
class Outer {
    private String name;

    Outer(String name) {
        this.name = name;
    }

    class Inner {
        void hello() {
            System.out.println("Hello, " + Outer.this.name);  // 访问外部类字段
        }
    }
}
```

### 实例化方式

```java
Outer outer = new Outer("Nested");
Outer.Inner inner = outer.new Inner();  // 必须通过外部实例创建
inner.hello();
```

### 特点

| 特点 | 说明 |
|------|------|
| 持有外部实例 | 隐含持有 `Outer.this` |
| 访问权限 | 可以访问和修改外部类的 private 字段和方法 |
| 不能独立存在 | 必须先有外部类实例 |

---

## 3. Anonymous Class（匿名类）

不需要显式定义类名，在方法内部直接定义并实例化：

```java
class Outer {
    private String name;

    Outer(String name) {
        this.name = name;
    }

    void asyncHello() {
        Runnable r = new Runnable() {
            @Override
            public void run() {
                System.out.println("Hello, " + Outer.this.name);
            }
        };
        new Thread(r).start();
    }
}
```

### 语法格式

```java
接口或父类 变量 = new 接口或父类() {
    // 实现抽象方法或覆写方法
};  // 注意分号
```

### 特点

- 和 Inner Class 本质相同，持有 `Outer.this`
- 可以访问外部类的 private 字段和方法
- 不关心类名时使用，代码更简洁
- 也可以继承普通类：

```java
HashMap<String, String> map = new HashMap<>() {
    {
        put("A", "1");
        put("B", "2");
    }
};
```

---

## 4. Static Nested Class（静态内部类）

用 `static` 修饰，**不依附于外部实例**，是完全独立的类：

```java
class Outer {
    private static String NAME = "OUTER";
    private String name;

    static class StaticNested {
        void hello() {
            System.out.println("Hello, " + Outer.NAME);  // 只能访问静态成员
        }
    }
}
```

### 实例化方式

```java
Outer.StaticNested sn = new Outer.StaticNested();  // 不需要外部实例
sn.hello();
```

### 与 Inner Class 的区别

| 对比 | Inner Class | Static Nested Class |
|------|-------------|---------------------|
| 依附外部实例 | ✅ 是 | ❌ 否 |
| 访问 Outer.this | ✅ 可以 | ❌ 不可以 |
| 访问外部 private 实例字段 | ✅ | ❌ |
| 访问外部 private 静态字段 | ✅ | ✅ |
| 实例化方式 | `outer.new Inner()` | `new Outer.StaticNested()` |

---

## 5. 关键总结

| 要点 | 说明 |
|------|------|
| Inner Class | 依附外部实例，持有 Outer.this，可访问所有 private |
| Anonymous Class | 本质同 Inner Class，省去类名，代码更简洁 |
| Static Nested Class | 独立类，只能访问外部静态成员 |
| 使用场景 | Inner/Anonymous 用于紧密关联的逻辑；Static Nested 用于逻辑独立但组织上相关的类 |
| 编译结果 | 内部类编译为 `Outer$Inner.class`，匿名类为 `Outer$1.class` |
