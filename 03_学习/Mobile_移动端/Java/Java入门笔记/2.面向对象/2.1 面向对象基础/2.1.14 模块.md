## 1. 为什么需要模块

### Java 9 之前的问题

- jar 包只是 class 的容器，**不管理依赖关系**
- 漏写 jar 包只有运行时才会发现 `ClassNotFoundException`
- JDK 标准库 `rt.jar` 有 60+M，全部加载浪费资源

### 模块解决了什么

| 问题 | 模块的解决方案 |
|------|--------------|
| 依赖不明确 | module-info.java 声明依赖 |
| rt.jar 太大 | 拆分为几十个 .jmod，按需加载 |
| 访问权限粗糙 | 模块级别的导出控制 |
| 部署复杂 | 可打包精简版 JRE 一起分发 |

---

## 2. 模块基本概念

| 概念 | 说明 |
|------|------|
| 模块 | 自带依赖关系的 class 容器 |
| .jmod 文件 | 模块文件格式，位于 `$JAVA_HOME/jmods/` |
| module-info.java | 模块描述文件，声明依赖和导出 |
| java.base | 根模块，所有模块自动依赖它 |

---

## 3. 编写模块

### 目录结构

```
oop-module/
├── bin/                    # 编译输出
└── src/
    ├── com/itranswarp/sample/
    │   ├── Greeting.java
    │   └── Main.java
    └── module-info.java    # 模块描述文件
```

### module-info.java

```java
module hello.world {
    requires java.base;  // 可省略，自动引入
    requires java.xml;   // 声明依赖 java.xml 模块
    exports com.itranswarp.sample;  // 导出包，允许外部访问
}
```

| 关键字 | 作用 |
|--------|------|
| `module` | 声明模块名（命名规范同包名） |
| `requires` | 声明依赖的其他模块 |
| `exports` | 导出包，允许外部模块访问 |

---

## 4. 编译、打包、创建模块

```bash
# 1. 编译所有源码
javac -d bin src/module-info.java src/com/itranswarp/sample/*.java

# 2. 打包为 jar（指定 main class）
jar --create --file hello.jar --main-class com.itranswarp.sample.Main -C bin .

# 3. 转换为模块文件
jmod create --class-path hello.jar hello.jmod
```

---

## 5. 运行模块

```bash
# 用 jar 运行（推荐）
java --module-path hello.jar --module hello.world

# .jmod 不能直接运行
java --module-path hello.jmod --module hello.world  # ❌ 报错
```

> `.jmod` 文件用于打包 JRE，不能直接执行。

---

## 6. 打包精简版 JRE（jlink）

只打包用到的模块，生成独立可运行的 JRE：

```bash
jlink --module-path hello.jmod \
      --add-modules java.base,java.xml,hello.world \
      --output jre/

# 运行
jre/bin/java --module hello.world
```

**好处：**
- 不需要对方安装 JDK
- JRE 只包含必要模块，体积小
- 打包分发极其方便

---

## 7. 模块的访问权限

引入模块后，class 的访问权限增加了模块层面的控制：

```java
// java.xml 模块导出了这些包
module java.xml {
    exports java.xml;
    exports javax.xml.catalog;
    exports javax.xml.datatype;
}
```

- 模块内的 public class，外部模块**默认不能访问**
- 只有通过 `exports` 导出的包，外部才能使用
- 未导出的包即使是 public 的也不可访问

---

## 8. 关键总结

| 要点 | 说明 |
|------|------|
| 模块目的 | 管理依赖关系 + 按需打包 |
| module-info.java | 声明模块名、依赖（requires）、导出（exports） |
| java.base | 根模块，自动依赖，无需声明 |
| jlink | 打包精简 JRE，方便分发部署 |
| 访问控制 | 模块未导出的包，外部无法访问 |
| .jmod vs .jar | .jmod 用于打包 JRE，运行用 .jar |
