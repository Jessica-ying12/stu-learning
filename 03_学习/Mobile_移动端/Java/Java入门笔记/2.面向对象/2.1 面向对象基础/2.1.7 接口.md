## 1. 什么是接口

如果一个抽象类没有字段，所有方法都是抽象方法，就可以改写为接口（interface）。

```java
// 抽象类写法
abstract class Person {
    public abstract void run();
    public abstract String getName();
}

// 接口写法（更简洁）
interface Person {
    void run();
    String getName();
}
```

- 接口比抽象类更加抽象：**不能有实例字段**
- 接口中的方法默认是 `public abstract`，不需要写出来

---

## 2. 实现接口：implements

```java
class Student implements Person {
    private String name;

    public Student(String name) {
        this.name = name;
    }

    @Override
    public void run() {
        System.out.println(this.name + " run");
    }

    @Override
    public String getName() {
        return this.name;
    }
}
```

### 一个类可以实现多个接口

```java
class Student implements Person, Hello {
    // 必须实现 Person 和 Hello 的所有抽象方法
}
```

> 这是接口与抽象类的关键区别：Java 只能继承一个类，但可以实现多个接口。

---

## 3. 抽象类 vs 接口

| 对比 | abstract class | interface |
|------|---------------|-----------|
| 继承 | 只能 extends 一个 | 可以 implements 多个 |
| 字段 | 可以定义实例字段 | 不能定义实例字段 |
| 抽象方法 | ✅ | ✅ |
| 非抽象方法 | 普通方法（可访问字段） | default 方法（不能访问字段） |
| 构造方法 | 有 | 没有 |
| 设计定位 | 模板（部分实现 + 规范） | 纯规范（能力约定） |

---

## 4. 接口继承

接口可以继承另一个接口，用 `extends`：

```java
interface Hello {
    void hello();
}

interface Person extends Hello {
    void run();
    String getName();
}
// Person 接口实际上有 3 个抽象方法：hello()、run()、getName()
```

---

## 5. default 方法（Java 8+）

接口中可以定义有实现的 default 方法：

```java
interface Person {
    String getName();

    default void run() {
        System.out.println(getName() + " run");
    }
}

class Student implements Person {
    private String name;
    public Student(String name) { this.name = name; }
    public String getName() { return this.name; }
    // 不必覆写 run()，直接继承 default 实现
}
```

### default 方法的作用

| 场景 | 说明 |
|------|------|
| 接口新增方法 | 已有实现类不需要全部修改 |
| 提供默认实现 | 子类可以选择覆写或直接使用 |

### default 方法的限制

- 不能访问实例字段（接口没有字段）
- 只能调用接口中其他方法

## 6. 继承关系设计原则

```
接口层（纯规范）：    Iterable → Collection → List
抽象类层（公共逻辑）：Object → AbstractCollection → AbstractList
具体类（完整实现）：  ArrayList、LinkedList
```

**使用原则：**

```java
// 总是用接口类型引用具体实现
List list = new ArrayList();
Collection coll = list;    // 向上转型
Iterable it = coll;        // 继续向上转型
```

> 面向接口编程：实例化具体类，但用接口类型引用。

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| interface | 纯抽象规范，不能有字段，不能实例化 |
| implements | 类实现接口，必须实现所有抽象方法 |
| 多实现 | 一个类可以实现多个接口（弥补单继承限制） |
| default 方法 | 接口提供默认实现，子类可选择覆写 |
| 接口继承接口 | 用 extends，扩展方法签名 |
| 设计原则 | 接口定义规范，抽象类提供公共逻辑，具体类完成实现 |
