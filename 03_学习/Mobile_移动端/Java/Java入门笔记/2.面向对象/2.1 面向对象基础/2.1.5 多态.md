## 1. 覆写（Override）

子类定义了一个与父类**方法签名完全相同**的方法：

```java
class Person {
    public void run() {
        System.out.println("Person.run");
    }
}

class Student extends Person {
    @Override
    public void run() {
        System.out.println("Student.run");
    }
}
```

### Override vs Overload

| 对比 | Override（覆写） | Overload（重载） |
|------|-----------------|-----------------|
| 发生位置 | 子类与父类之间 | 同一个类中 |
| 方法名 | 相同 | 相同 |
| 参数 | 相同 | 不同 |
| 返回值 | 相同 | 通常相同 |
| 本质 | 覆盖父类行为 | 同名方法的不同版本 |

### @Override 注解

```java
@Override  // 让编译器检查覆写是否正确
public void run() { ... }
```

- 不是必须的，但强烈建议加上
- 写错方法签名时编译器会报错，帮助发现问题

## 2. 多态（Polymorphism）

**核心概念：** 方法调用基于运行时的**实际类型**，而非变量的声明类型。

```java
Person p = new Student();
p.run();  // 调用的是 Student.run()，不是 Person.run()
```

### 多态的意义

```java
public double totalTax(Income... incomes) {
    double total = 0;
    for (Income income : incomes) {
        total = total + income.getTax();  // 运行时决定调用哪个 getTax()
    }
    return total;
}
```

- `totalTax()` 只需要和 `Income` 类打交道
- 不需要知道具体子类（Salary、稿费等）的存在
- 新增收入类型只需继承 Income 并覆写 `getTax()`，无需修改已有代码

### 完整示例：报税计算

```java
class Income {
    protected double income;
    public Income(double income) { this.income = income; }
    public double getTax() {
        return income * 0.1;  // 默认税率 10%
    }
}

class Salary extends Income {
    public Salary(double income) { super(income); }
    @Override
    public double getTax() {
        if (income <= 5000) return 0;
        return (income - 5000) * 0.2;
    }
}

class StateCouncilSpecialAllowance extends Income {
    public StateCouncilSpecialAllowance(double income) { super(income); }
    @Override
    public double getTax() {
        return 0;  // 全部免税
    }
}
```

> 多态的强大之处：允许添加更多子类扩展功能，却不需要修改基于父类的代码。

## 3. 覆写 Object 方法

所有类最终继承自 Object，可以覆写其重要方法：

```java
class Person {
    private String name;

    @Override
    public String toString() {
        return "Person:name=" + name;
    }

    @Override
    public boolean equals(Object o) {
        if (o instanceof Person p) {
            return this.name.equals(p.name);
        }
        return false;
    }

    @Override
    public int hashCode() {
        return this.name.hashCode();
    }
}
```

| 方法 | 作用 |
|------|------|
| `toString()` | 将实例转为有意义的字符串 |
| `equals()` | 判断逻辑相等 |
| `hashCode()` | 计算哈希值（与 equals 配套） |

## 4. 调用父类方法：super

```java
class Student extends Person {
    @Override
    public String hello() {
        return super.hello() + "!";  // 先调用父类的 hello()，再追加内容
    }
}
```

## 5. final 修饰符

| 用法 | 效果 |
|------|------|
| `final` 修饰方法 | 不能被子类覆写 |
| `final` 修饰类 | 不能被继承 |
| `final` 修饰字段 | 初始化后不能修改 |

```java
// final 方法
class Person {
    public final String hello() { return "Hello"; }
}

// final 类
final class Person { }  // 无法被继承

// final 字段
class Person {
    public final String name;
    public Person(String name) {
        this.name = name;  // 只能在构造方法中初始化一次
    }
}
```

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| 覆写 | 子类重新定义父类的同签名方法 |
| 多态 | 方法调用基于运行时实际类型，非声明类型 |
| 多态的好处 | 扩展子类无需修改父类相关代码（开闭原则） |
| @Override | 建议始终加上，编译器帮助检查 |
| super | 子类中调用父类被覆写的方法 |
| final | 阻止覆写 / 阻止继承 / 阻止修改字段 |
