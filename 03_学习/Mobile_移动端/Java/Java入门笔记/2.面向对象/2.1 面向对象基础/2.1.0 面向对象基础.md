## 1. class 和 instance 的关系

| 概念 | 含义 | 类比 |
|------|------|------|
| class（类） | 对象模板，定义数据类型 | "人"这个抽象概念 |
| instance（实例） | 根据模板创建的具体对象 | "小明"、"小红"等具体的人 |

```
现实世界        计算机模型        Java 代码
人             类 / class       class Person { }
小明           实例 / ming      Person ming = new Person()
小红           实例 / hong      Person hong = new Person()
```

> 一个 class 可以创建多个 instance，每个 instance 类型相同，但各自属性可能不同。

---

## 2. 定义 class

```java
class Person {
    public String name;
    public int age;
}
```

- `class` 关键字定义一个类
- 类中包含多个**字段（field）**，描述对象的特征
- `public` 修饰字段，表示可被外部访问
- 通过 class 把一组数据汇集到一个对象上 = **数据封装**

### 另一个示例

```java
class Book {
    public String name;
    public String author;
    public String isbn;
    public double price;
}
```

---

## 3. 创建实例（new）

```java
Person ming = new Person();
```

| 部分 | 含义 |
|------|------|
| `Person ming` | 定义 Person 类型的引用变量 ming |
| `new Person()` | 创建 Person 类的一个实例 |
| `=` | 让变量 ming 指向这个实例 |

### 访问和修改字段

```java
ming.name = "Xiao Ming";  // 赋值
ming.age = 12;
System.out.println(ming.name);  // 访问
```

---

## 4. 多个实例互不干扰

```java
Person ming = new Person();
ming.name = "Xiao Ming";
ming.age = 12;

Person hong = new Person();
hong.name = "Xiao Hong";
hong.age = 15;
```

**内存结构：**

```
ming ──────▶ Person instance
             ├─ name = "Xiao Ming"
             └─ age = 12

hong ──────▶ Person instance
             ├─ name = "Xiao Hong"
             └─ age = 15
```

> 每个 instance 拥有独立的字段数据，修改一个不影响另一个。

## 5. 源文件规则

| 规则 | 说明 |
|------|------|
| 一个文件一个 public class | public 类名必须与文件名一致 |
| 可包含多个非 public 类 | 但建议一个文件一个类 |
| 多个 public 类 | 必须拆到多个 .java 文件中 |

## 6. 练习：定义 City 类

```java
public class Main {
    public static void main(String[] args) {
        City bj = new City();
        bj.name = "Beijing";
        bj.latitude = 39.903;
        bj.longitude = 116.401;
        System.out.println(bj.name);
        System.out.println("location: " + bj.latitude + ", " + bj.longitude);
    }
}

class City {
    public String name;
    public double latitude;
    public double longitude;
}
```

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| class | 对象模板，定义了字段（数据）和方法（行为） |
| instance | 通过 `new` 创建的具体对象 |
| 字段（field） | 类中定义的变量，每个实例各有一份 |
| 访问字段 | `变量名.字段名` |
| 引用变量 | 指向 instance 的变量都是引用类型 |
| 互不干扰 | 不同实例的字段数据独立 |
