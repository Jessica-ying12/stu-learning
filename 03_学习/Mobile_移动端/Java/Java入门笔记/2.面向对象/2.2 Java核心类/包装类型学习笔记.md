# 包装类型学习笔记

## 1. 什么是包装类型

将基本类型包装为引用类型（class），使基本类型可以赋值为 null、放入集合等。

| 基本类型 | 包装类型 |
|----------|----------|
| boolean | Boolean |
| byte | Byte |
| short | Short |
| int | **Integer** |
| long | Long |
| float | Float |
| double | Double |
| char | **Character** |

---

## 2. 自动装箱与拆箱（Auto Boxing / Unboxing）

编译器自动在基本类型和包装类型之间转换：

```java
Integer n = 100;    // 自动装箱：编译器变为 Integer.valueOf(100)
int x = n;          // 自动拆箱：编译器变为 n.intValue()
```

### ⚠️ 注意事项

| 问题 | 说明 |
|------|------|
| 性能 | 装箱/拆箱有开销，循环中要注意 |
| NPE 风险 | 拆箱时如果包装类型为 null，抛出 NullPointerException |

```java
Integer n = null;
int i = n;  // ❌ NullPointerException!
```

---

## 3. 包装类型的比较

**必须用 `equals()`，不能用 `==`！**

```java
Integer x = 127;
Integer y = 127;
Integer m = 99999;
Integer n = 99999;

x == y       // true（缓存优化，巧合！）
m == n       // false
x.equals(y)  // true（正确方式）
m.equals(n)  // true（正确方式）
```

> Integer.valueOf() 对 -128~127 的小数有缓存，但不能依赖这个优化。

---

## 4. 不变类

所有包装类型都是 **final + 不可变**：

```java
public final class Integer {
    private final int value;
}
```

- 一旦创建，值不可修改
- 推荐用 `Integer.valueOf()` 而非 `new Integer()`（静态工厂方法，可能复用缓存实例）

---

## 5. 常用方法

### 进制转换

```java
Integer.parseInt("100")         // 100
Integer.parseInt("100", 16)     // 256（十六进制解析）

Integer.toString(100)           // "100"
Integer.toHexString(100)        // "64"
Integer.toOctalString(100)      // "144"
Integer.toBinaryString(100)     // "1100100"
```

### 有用的静态常量

```java
Integer.MAX_VALUE   // 2147483647
Integer.MIN_VALUE   // -2147483648
Long.SIZE           // 64（bits）
Long.BYTES          // 8（bytes）
Boolean.TRUE        // true
Boolean.FALSE       // false
```

### Number 父类

所有整数和浮点数包装类都继承自 Number：

```java
Number num = Integer.valueOf(999);
int n = num.intValue();
double d = num.doubleValue();
long l = num.longValue();
```

### 无符号转换

```java
byte x = -1;
Byte.toUnsignedInt(x)   // 255（二进制 11111111 视为无符号）
```

---

## 6. 最佳实践

| 原则 | 说明 |
|------|------|
| 比较用 equals() | 不能用 ==，即使小数碰巧相等 |
| 创建用 valueOf() | 静态工厂方法，可利用缓存 |
| 注意 null | 拆箱前检查是否为 null |
| 按语义编程 | 不要针对缓存优化写 == |

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 包装类型 | 基本类型的 class 版本，可为 null |
| 自动装箱/拆箱 | 编译期自动转换，注意 NPE 和性能 |
| 不变类 | final class + final field |
| 比较 | 必须 equals()，不能 == |
| 继承 Number | 整数/浮点包装类可互转 |
| 进制转换 | parseInt / toHexString / toBinaryString |
