# 记录类（record）学习笔记

## 1. 不变类的痛点

定义一个不变类需要大量样板代码：

```java
public final class Point {
    private final int x;
    private final int y;

    public Point(int x, int y) { this.x = x; this.y = y; }
    public int x() { return this.x; }
    public int y() { return this.y; }
    // 还要覆写 equals()、hashCode()、toString()...
}
```

---

## 2. record 关键字（Java 14+）

一行定义不变类：

```java
record Point(int x, int y) {}
```

编译器自动生成：

| 自动生成内容 | 说明 |
|-------------|------|
| `private final` 字段 | x 和 y |
| 构造方法 | `Point(int x, int y)` |
| 访问方法 | `x()` 和 `y()`（不是 getX） |
| `toString()` | `Point[x=123, y=456]` |
| `equals()` | 按字段值比较 |
| `hashCode()` | 按字段值计算 |

### 使用

```java
Point p = new Point(123, 456);
System.out.println(p.x());    // 123
System.out.println(p.y());    // 456
System.out.println(p);        // Point[x=123, y=456]
```

---

## 3. record 的特点

| 特点 | 说明 |
|------|------|
| final class | 不能被继承 |
| final 字段 | 创建后不可修改 |
| 继承 Record | 自动继承，不能手动继承 |
| 不能自己派生 | 只能用 record 关键字定义 |

---

## 4. Compact Constructor（参数校验）

```java
public record Point(int x, int y) {
    public Point {  // 没有参数列表！
        if (x < 0 || y < 0) {
            throw new IllegalArgumentException();
        }
        // 编译器自动在后面加 this.x = x; this.y = y;
    }
}
```

> Compact Constructor 只写校验逻辑，赋值由编译器自动完成。

---

## 5. 添加静态方法

```java
public record Point(int x, int y) {
    public static Point of() {
        return new Point(0, 0);
    }
    public static Point of(int x, int y) {
        return new Point(x, y);
    }
}

// 使用
var z = Point.of();         // Point[x=0, y=0]
var p = Point.of(123, 456); // Point[x=123, y=456]
```

---

## 6. 关键总结

| 要点 | 说明 |
|------|------|
| 语法 | `record 类名(字段列表) {}` |
| 本质 | final class + final 字段 + 自动方法 |
| 访问方法 | 字段同名方法（`x()` 不是 `getX()`） |
| 参数校验 | Compact Constructor（无参数列表） |
| 静态方法 | 可以添加 of() 等工厂方法 |
| 适用场景 | 数据载体（DTO）、值对象、不变数据 |
