# 常用工具类学习笔记

## 1. Math 数学计算

所有方法都是静态方法，直接通过 `Math.xxx()` 调用。

### 常用方法

| 方法 | 作用 | 示例 |
|------|------|------|
| `abs(x)` | 绝对值 | `Math.abs(-100)` → 100 |
| `max(a, b)` | 最大值 | `Math.max(100, 99)` → 100 |
| `min(a, b)` | 最小值 | `Math.min(1.2, 2.3)` → 1.2 |
| `pow(x, y)` | x 的 y 次方 | `Math.pow(2, 10)` → 1024 |
| `sqrt(x)` | 平方根 | `Math.sqrt(2)` → 1.414... |
| `exp(x)` | e 的 x 次方 | `Math.exp(2)` → 7.389... |
| `log(x)` | 自然对数（ln） | `Math.log(4)` → 1.386... |
| `log10(x)` | 以 10 为底 | `Math.log10(100)` → 2 |
| `sin/cos/tan` | 三角函数 | `Math.sin(Math.PI/6)` → 0.5 |
| `random()` | [0, 1) 随机数 | `Math.random()` → 0.53... |

### 常量

```java
Math.PI  // 3.14159...
Math.E   // 2.71828...
```

### 生成指定范围的随机整数

```java
// 生成 [min, max) 范围的随机整数
double x = Math.random();
long n = (long) (x * (max - min) + min);
```

## 2. HexFormat（十六进制转换）

### byte[] → 十六进制字符串

```java
import java.util.HexFormat;

byte[] data = "Hello".getBytes();
String hex = HexFormat.of().formatHex(data);  // "48656c6c6f"
```

### 定制格式

```java
HexFormat hf = HexFormat.ofDelimiter(" ").withPrefix("0x").withUpperCase();
hf.formatHex("Hello".getBytes());  // "0x48 0x65 0x6C 0x6C 0x6F"
```

### 十六进制字符串 → byte[]

```java
byte[] bs = HexFormat.of().parseHex("48656c6c6f");
```

## 3. Random（伪随机数）

```java
import java.util.Random;

Random r = new Random();
r.nextInt()       // 随机 int
r.nextInt(10)     // [0, 10) 的 int
r.nextLong()      // 随机 long
r.nextFloat()     // [0, 1) 的 float
r.nextDouble()    // [0, 1) 的 double
```

### 伪随机的含义

- 相同种子 → 相同序列
- 不指定种子时用当前时间戳，所以每次运行结果不同

```java
Random r = new Random(12345);  // 固定种子，每次运行结果相同
```

## 4. SecureRandom（安全随机数）

```java
import java.security.SecureRandom;

SecureRandom sr = new SecureRandom();
sr.nextInt(100);  // 安全的随机数

// 获取高强度生成器
try {
    sr = SecureRandom.getInstanceStrong();
} catch (NoSuchAlgorithmException e) {
    sr = new SecureRandom();
}

byte[] buffer = new byte[16];
sr.nextBytes(buffer);  // 用安全随机数填充
```

### Random vs SecureRandom

| 对比 | Random | SecureRandom |
|------|--------|-------------|
| 类型 | 伪随机 | 安全随机 |
| 可预测性 | 种子确定则可预测 | 不可预测 |
| 种子来源 | 时间戳或手动指定 | 操作系统熵（CPU 热噪声等） |
| 性能 | 快 | 较慢 |
| 用途 | 普通场景 | 密码学、安全相关 |

> ⚠️ 涉及安全的场景（加密、令牌生成等）**必须用 SecureRandom**，绝不能用 Random。

## 5. 关键总结

| 工具类 | 用途 |
|--------|------|
| Math | 数学计算（abs、pow、sqrt、random 等） |
| HexFormat | byte[] 与十六进制字符串互转 |
