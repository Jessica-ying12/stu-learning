# 字符串和编码学习笔记

## 1. String 基础

String 是引用类型，内部用 `char[]`（或新版 JDK 用 `byte[]`）存储，**不可变**。

```java
String s1 = "Hello!";
String s2 = new String(new char[] {'H', 'e', 'l', 'l', 'o', '!'});
```

### 不可变性

```java
String s = "Hello";
s = s.toUpperCase();  // s 指向新对象 "HELLO"，原 "Hello" 未改变
```

> 字符串操作不改变原内容，而是返回新字符串。

---

## 2. 字符串比较

```java
String s1 = "hello";
String s2 = "HELLO".toLowerCase();

s1 == s2          // false（不同对象）
s1.equals(s2)     // true（内容相同）
s1.equalsIgnoreCase("HELLO")  // true（忽略大小写）
```

> **必须用 `equals()` 比较内容**，`==` 比较的是引用。

---

## 3. 常用方法速查

### 搜索

```java
"Hello".contains("ll")       // true
"Hello".indexOf("l")         // 2
"Hello".lastIndexOf("l")     // 3
"Hello".startsWith("He")     // true
"Hello".endsWith("lo")       // true
```

### 提取子串

```java
"Hello".substring(2)         // "llo"
"Hello".substring(2, 4)      // "ll"（左闭右开）
```

### 去除空白

| 方法 | 作用 |
|------|------|
| `trim()` | 去除首尾空白（空格、\t、\r、\n） |
| `strip()` | 同上 + 中文空格 　 |
| `stripLeading()` | 只去前面 |
| `stripTrailing()` | 只去后面 |

### 判空

```java
"".isEmpty()       // true（长度为 0）
"  ".isEmpty()     // false（长度不为 0）
"  \n".isBlank()   // true（只有空白字符）
" Hi".isBlank()    // false
```

### 替换

```java
"hello".replace('l', 'w')                    // "hewwo"
"hello".replace("ll", "~~")                  // "he~~o"
"A,,B;C ,D".replaceAll("[\\,\\;\\s]+", ",")  // "A,B,C,D"（正则）
```

### 分割与拼接

```java
"A,B,C,D".split("\\,")           // {"A", "B", "C", "D"}
String.join("***", "A", "B", "C") // "A***B***C"
```

### 格式化

```java
"Hi %s, score is %d!".formatted("Alice", 80)
String.format("Hi %s, score is %.2f!", "Bob", 59.5)
```

| 占位符 | 类型 |
|--------|------|
| `%s` | 字符串（任何类型都可用） |
| `%d` | 整数 |
| `%f` | 浮点数 |
| `%x` | 十六进制 |

## 4. 类型转换

### 其他类型 → String

```java
String.valueOf(123)        // "123"
String.valueOf(45.67)      // "45.67"
String.valueOf(true)       // "true"
```

### String → 其他类型

```java
Integer.parseInt("123")         // 123
Integer.parseInt("ff", 16)      // 255（十六进制）
Boolean.parseBoolean("true")    // true
```

> ⚠️ `Integer.getInteger("xxx")` 是读系统变量，不是类型转换！

### String ↔ char[]

```java
char[] cs = "Hello".toCharArray();  // String → char[]
String s = new String(cs);          // char[] → String
```

> `new String(char[])` 会复制数组，修改原 char[] 不影响 String。

## 5. 字符编码

### 编码发展

| 编码 | 说明 |
|------|------|
| ASCII | 1 字节，英文字母 + 数字 + 符号（0~127） |
| GB2312 | 2 字节，中文编码 |
| Unicode | 统一全球语言，固定 2+ 字节 |
| UTF-8 | 变长编码（1~4 字节），兼容 ASCII，传输首选 |

### 编码示例

| 字符 | ASCII | Unicode | UTF-8 |
|------|-------|---------|-------|
| 'A' | 0x41 | 0x0041 | 0x41（1字节） |
| '中' | - | 0x4E2D | 0xE4B8AD（3字节） |

### Java 中的编码转换

```java
// String → byte[]
byte[] b = "Hello".getBytes(StandardCharsets.UTF_8);

// byte[] → String
String s = new String(b, StandardCharsets.UTF_8);
```

> **Java 的 String 和 char 在内存中总是 Unicode 编码。**

## 6. 设计启示：防御性复制

String 通过复制 char[] 保证不可变。自己设计类时也应如此：

```java
class Score {
    private int[] scores;
    public Score(int[] scores) {
        this.scores = scores.clone();  // 复制，不直接引用外部数组
    }
}
```

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 不可变 | 操作返回新字符串，原字符串不变 |
| 比较 | 必须用 `equals()`，不能用 `==` |
| 常用方法 | contains、indexOf、substring、replace、split、join |
| 格式化 | `formatted()` 或 `String.format()` |
| 编码 | 内存中是 Unicode，传输/存储推荐 UTF-8 |
| 类型转换 | `valueOf()` 转为 String，`parseXxx()` 从 String 转出 |
