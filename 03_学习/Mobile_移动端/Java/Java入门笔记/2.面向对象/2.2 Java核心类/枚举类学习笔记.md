# 枚举类学习笔记

## 1. 为什么需要枚举

用 `static final int` 定义常量的问题：

```java
public static final int SUN = 0;
public static final int MON = 1;
```

- 编译器无法检查值是否合法（如传入 7）
- 不同用途的常量可以混用（如星期和颜色比较不报错）

**enum 解决了这些问题：** 类型安全 + 编译器自动检查。

---

## 2. 定义枚举

```java
enum Weekday {
    SUN, MON, TUE, WED, THU, FRI, SAT;
}
```

### 使用

```java
Weekday day = Weekday.SUN;
if (day == Weekday.SAT || day == Weekday.SUN) {
    System.out.println("Work at home!");
}
```

### enum 的优势

| 优势 | 说明 |
|------|------|
| 类型安全 | `Weekday` 类型不能与 int 或其他枚举比较 |
| 值受限 | 不可能引用到非枚举的值 |
| 不能混用 | 不同枚举类型不能互相赋值 |

---

## 3. enum 的本质

enum 就是 class，编译器编译后等价于：

```java
public final class Color extends Enum {
    public static final Color RED = new Color();
    public static final Color GREEN = new Color();
    public static final Color BLUE = new Color();
    private Color() {}  // 外部无法 new
}
```

| 特点 | 说明 |
|------|------|
| 继承 Enum | 自动继承，不能再继承其他类 |
| final | 不能被继承 |
| 实例唯一 | 每个常量在 JVM 中只有一个实例 |
| 可用 == 比较 | 因为实例唯一，== 和 equals() 结果相同 |

---

## 4. 常用方法

```java
Weekday day = Weekday.MON;
day.name()      // "MON"（常量名字符串）
day.ordinal()   // 1（定义顺序，从 0 开始）
```

| 方法 | 作用 | 注意 |
|------|------|------|
| `name()` | 返回常量名 | 始终用这个判断名字 |
| `ordinal()` | 返回定义顺序 | 不要依赖，顺序可能变 |
| `toString()` | 默认同 name()，可覆写 | 不能用来判断名字 |

---

## 5. 给枚举添加字段和构造方法

```java
enum Weekday {
    MON(1, "星期一"), TUE(2, "星期二"), WED(3, "星期三"),
    THU(4, "星期四"), FRI(5, "星期五"), SAT(6, "星期六"), SUN(0, "星期日");

    public final int dayValue;
    private final String chinese;

    private Weekday(int dayValue, String chinese) {
        this.dayValue = dayValue;
        this.chinese = chinese;
    }

    @Override
    public String toString() {
        return this.chinese;
    }
}
```

| 规范 | 说明 |
|------|------|
| 构造方法必须 private | 防止外部 new |
| 字段建议 final | 枚举值应该不可变 |
| 可覆写 toString() | 提高输出可读性 |

---

## 6. 在 switch 中使用

```java
switch (day) {
case MON:
case TUE:
case WED:
case THU:
case FRI:
    System.out.println("Work at office!");
    break;
case SAT:
case SUN:
    System.out.println("Work at home!");
    break;
default:
    throw new RuntimeException("cannot process " + day);
}
```

> 加 default 可以在漏写某个常量时及时发现错误。

---

## 7. 关键总结

| 要点 | 说明 |
|------|------|
| 定义 | `enum Name { 常量1, 常量2, ... }` |
| 本质 | `final class extends Enum`，每个常量是唯一实例 |
| 比较 | 可以用 `==`（实例唯一） |
| name() | 获取常量名（用于判断） |
| ordinal() | 不要依赖（顺序可能变） |
| 自定义字段 | private 构造方法 + final 字段 |
| switch | 枚举天然适合 switch |
