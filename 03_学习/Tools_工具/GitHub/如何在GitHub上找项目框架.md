## 七、如何在 GitHub 上搜索这些框架

### 搜索技巧示例

#### 1. 基础搜索

```
react typescript starter
```

#### 2. 高级过滤搜索

```
react template stars:>1000 language:TypeScript pushed:>2024-01-01
```

解释：

- `stars:>1000` - 超过 1000 星
- `language:TypeScript` - 限定 TypeScript
- `pushed:>2024-01-01` - 2024 年后更新

#### 3. 使用 Topics 搜索

```
topic:react-starter topic:typescript
```

#### 4. 搜索特定组织的项目

```
org:facebook react
org:vercel next
```

## 九、评估项目质量的检查清单

找到项目后，检查这些指标：

✅ **Stars 数量**

- 1k-5k：小众但可能很好
- 5k-20k：比较流行
- 20k+：非常成熟

✅ **最后更新时间**

- 3 个月内：活跃维护
- 6 个月-1 年：可能还在维护
- 1 年以上：可能已废弃

✅ **Issues 和 PR**

- Open issues < 100：维护良好
- 有活跃的 PR 合并：社区活跃

✅ **文档质量**

- 有详细的 README
- 有使用示例
- 有在线文档站点

✅ **License**

- MIT、Apache 2.0：可商用
- GPL：需要开源

✅ **依赖更新**

- 查看 `package.json` 的依赖是否过时
- 使用 `npm outdated` 检查

## 十一、常见问题

### Q1: 模板太复杂，看不懂怎么办？

A: 从最简单的开始，比如官方的 `create-vite`，然后逐步学习

### Q2: 如何知道模板用了哪些技术？

A: 查看项目的 `package.json` 文件，里面列出了所有依赖

### Q3: 模板可以商用吗？

A: 查看项目的 LICENSE 文件，MIT 和 Apache 2.0 通常可以商用

### Q4: 模板太老了，依赖过时怎么办？

A: 可以用 `npm outdated` 检查，然后用 `npm update` 更新
