### 知识点（极度详细，按顺序学）

#### A. 基础语法（第1-2周）

1. JDK 安装与环境变量配置（JAVA_HOME、PATH）
2. 第一个程序：Hello World
   - `public static void main(String[] args)` 的含义
   - javac 编译与 java 运行
3. 数据类型
   - 基本类型：byte(1字节)、short(2)、int(4)、long(8)、float(4)、double(8)、char(2)、boolean
   - 包装类：Integer、Long、Double、Boolean 等
   - 自动装箱/拆箱（Autoboxing）
   - 类型转换（隐式/显式、精度丢失）
4. 变量与常量
   - 局部变量、成员变量、静态变量
   - final 常量
   - 变量作用域
5. 运算符
   - 算术：+、-、*、/、%
   - 关系：==、!=、>、<、>=、<=
   - 逻辑：&&、||、!
   - 位运算：&、|、^、~、<<、>>、>>>
   - 三元运算符：condition ? a : b
   - instanceof
6. 字符串
   - String 不可变性
   - 字符串拼接（+、StringBuilder、StringBuffer）
   - 常用方法：length()、charAt()、substring()、indexOf()、split()、trim()、replace()
   - String.format()
   - 字符串比较：equals() vs ==
7. 数组
   - 一维数组声明与初始化
   - 多维数组
   - 数组遍历（for、for-each）
   - Arrays 工具类：sort()、binarySearch()、copyOf()、fill()

#### B. 流程控制（第2周）

8. 条件语句
   - if / else if / else
   - switch（支持的类型：int、char、String、枚举）
   - switch 穿透问题（break 的重要性）
9. 循环
   - for 循环
   - while 循环
   - do-while 循环
   - for-each 增强循环
   - break 与 continue
   - 标签（labeled break/continue）
10. 方法（函数）
    - 方法定义：访问修饰符、返回类型、方法名、参数列表
    - 方法重载（Overload）：同名不同参数
    - 可变参数（varargs）：int... args
    - 递归
    - 方法调用栈

#### C. 面向对象编程（第3-4周，重点中的重点）

11. 类与对象
    - class 定义
    - 构造方法（无参/有参）
    - this 关键字
    - 对象创建与引用
    - null 与 NullPointerException
12. 封装
    - 访问修饰符：private、默认（package）、protected、public
    - getter / setter
    - JavaBean 规范
13. 继承
    - extends 关键字
    - 方法重写（Override）与 @Override 注解
    - super 关键字
    - 构造方法链
    - Object 类（toString()、equals()、hashCode()）
14. 多态
    - 向上转型与向下转型
    - instanceof 判断
    - 动态绑定（运行时多态）
15. 抽象类与接口
    - abstract class：抽象方法、模板方法模式
    - interface：接口定义、默认方法（Java 8+）、静态方法
    - 接口 vs 抽象类 的选择
    - 多接口实现
16. 枚举（enum）
    - 枚举定义
    - 枚举方法
    - 枚举配合 switch
17. 内部类
    - 成员内部类
    - 静态内部类
    - 匿名内部类
    - 局部内部类

#### D. 核心 API（第5-6周）

18. 集合框架（极其重要）
    - Collection 接口体系
      - List：ArrayList（数组实现，查询快）、LinkedList（链表实现，增删快）
      - Set：HashSet（无序不重复）、LinkedHashSet（有序）、TreeSet（排序）
      - Queue：LinkedList、PriorityQueue、Deque
    - Map 接口体系
      - HashMap（哈希表，最常用）
      - LinkedHashMap（保持插入顺序）
      - TreeMap（按 key 排序）
      - ConcurrentHashMap（线程安全）
    - 遍历方式：Iterator、for-each、forEach()
    - Collections 工具类：sort()、reverse()、shuffle()、unmodifiableList()
    - 泛型在集合中的应用
19. 泛型
    - 泛型类：`class Box<T>`
    - 泛型方法：`<T> T getFirst(List<T> list)`
    - 泛型通配符：?、? extends T、? super T
    - 类型擦除原理
20. 异常处理
    - 异常体系：Throwable → Error / Exception
    - 受检异常（Checked）vs 非受检异常（Unchecked/RuntimeException）
    - try / catch / finally
    - throw 与 throws
    - 自定义异常
    - try-with-resources（Java 7+）
21. IO 流
    - 字节流：InputStream、OutputStream、FileInputStream、BufferedInputStream
    - 字符流：Reader、Writer、FileReader、BufferedReader
    - 转换流：InputStreamReader、OutputStreamWriter
    - 对象序列化：Serializable、ObjectInputStream、ObjectOutputStream
    - NIO（New IO）：Channel、Buffer、Selector（了解）
    - Files 工具类（Java 7+）
22. 多线程与并发
    - Thread 类与 Runnable 接口
    - 线程生命周期（NEW、RUNNABLE、BLOCKED、WAITING、TERMINATED）
    - synchronized 关键字
    - volatile 关键字
    - wait() / notify() / notifyAll()
    - Lock 接口与 ReentrantLock
    - 线程池：ExecutorService、ThreadPoolExecutor
    - Callable 与 Future
    - CountDownLatch、CyclicBarrier、Semaphore
    - 并发集合：ConcurrentHashMap、CopyOnWriteArrayList
23. Lambda 与 Stream（Java 8+）
    - Lambda 表达式语法
    - 函数式接口（@FunctionalInterface）
    - 内置函数式接口：Predicate、Function、Consumer、Supplier
    - Stream API：filter()、map()、flatMap()、reduce()、collect()
    - Optional 类（避免 null）
24. 反射
    - Class 对象获取
    - 获取构造方法、字段、方法
    - 动态创建对象、调用方法
    - 注解（Annotation）的定义与读取
25. 网络编程（了解）
    - Socket 编程
    - URL / HttpURLConnection

#### E. Java 进阶（Android 面试高频）

26. JVM 基础
    - 内存模型：堆、栈、方法区、程序计数器
    - 垃圾回收（GC）算法：标记-清除、复制、标记-整理、分代收集
    - 类加载机制：双亲委派模型
27. 设计模式（用 Java 实现）
    - 单例模式（懒汉、饿汉、双重检查锁、枚举）
    - 工厂模式（简单工厂、工厂方法、抽象工厂）
    - 观察者模式
    - 建造者模式（Builder）
    - 适配器模式
    - 代理模式（静态/动态代理）
    - 策略模式
    - 模板方法模式
