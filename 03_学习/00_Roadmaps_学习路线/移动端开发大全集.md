# 0. 总体路线图

```
共同基础底座
  ↓
前端路线 / 后端路线 / App路线
  ↓
调试、测试、性能、工程化、上线、监控
  ↓
架构、分布式、安全、源码阅读
  ↓
横向补语言：Go / Python / Java / Kotlin / Swift / Dart / C++ / Rust / C#
```

最重要的结论：

- 想就业快：**前端 TypeScript + React/Vue + Java Spring Boot + SQL + Flutter**
- 想后端强：**Java + Go + MySQL + Redis + Linux + 网络 + 分布式**
- 想 App 强：**Kotlin Android + Swift iOS + Flutter**
- 想长期精进：**数据结构、网络、操作系统、数据库、计算机系统、调试能力一定要补**

# 12. 你应该怎么练“修 Bug”

每个项目都按这个流程练：

1. **复现 Bug**：能稳定复现才好修。
2. **记录环境**：系统、浏览器、App版本、接口参数、数据库状态。
3. **缩小范围**：前端问题、后端问题、网络问题、数据库问题、缓存问题。
4. **不要猜，要观察**：看日志、断点、请求、SQL、性能曲线。
5. **最小复现**：把问题缩小成最小 demo。
6. **一次只改一个地方**。
7. **写测试锁住 Bug**：先写失败测试，再修复。
8. **回归验证**：确认没引入新问题。
9. **写复盘**：原因、修复、预防方式。

# 12. 你应该怎么练“修 Bug”

每个项目都按这个流程练：

1. **复现 Bug**：能稳定复现才好修。
2. **记录环境**：系统、浏览器、App版本、接口参数、数据库状态。
3. **缩小范围**：前端问题、后端问题、网络问题、数据库问题、缓存问题。
4. **不要猜，要观察**：看日志、断点、请求、SQL、性能曲线。
5. **最小复现**：把问题缩小成最小 demo。
6. **一次只改一个地方**。
7. **写测试锁住 Bug**：先写失败测试，再修复。
8. **回归验证**：确认没引入新问题。
9. **写复盘**：原因、修复、预防方式。

# 13. AI、大模型、智能体 Agent 路线大全集

> 这一章用于补齐 AI 时代必须掌握的能力。优先推荐**中文书 / 中文译本**；但 Agent、MCP、A2A、LangGraph、推理模型发展很快，部分高质量资料目前仍以英文原版为主，中文纸书会慢半拍。

推荐主线：

```
Python 基础
  ↓
机器学习 / 深度学习基础
  ↓

  ↓
```

- 不建议买：**ChatGPT办公一本通、提示词大全、10分钟学会AI、纯低代码扣子小白书、只教复制粘贴提示词的书**

## 14.7 最终建议：不要盲目买全套

真正建议的购买策略：

1. **先买主线，不买摆设**：每个方向 3～5 本足够，读完做项目比囤书重要。
2. **AI / Agent 方向优先买新书**：2024 年以前的 Agent 书很容易过时。
3. **移动端优先看官方文档 + 新版英文书**：Android、iOS、Flutter 更新太快，中文书容易滞后。
4. **架构和系统类书可以长期读**：DDIA、软件架构、分布式架构这类不过时。
5. **不要买“提示词大全”**：真正有用的是评估、工具调用、RAG、权限、安全、部署。

```
生产化能力：
《大语言模型工程师手册》 + 《大语言模型安全》 + 《机器学习系统设计》
```
