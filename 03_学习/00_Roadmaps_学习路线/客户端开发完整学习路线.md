## 推荐学习顺序

```
阶段一（1-2个月）：编程基础 + Git
         ↓
阶段二（2-3个月）：选一个原生平台深入
    ├── Android: Kotlin → Compose → 架构
    └── iOS: Swift → SwiftUI → 架构
         ↓
阶段三（2-3个月）：跨端框架
    ├── Flutter（推荐，性能更好）
    └── React Native（已有 Web 经验选这个）
         ↓
阶段四（1-2个月）：第二个原生平台
         ↓
阶段五（持续）：架构、性能优化、发布流程
```

---

## 练习建议

每个阶段完成以下练习项目：

1. **入门项目**：计算器 / Todo App
2. **网络项目**：天气 App（调用公开 API）
3. **综合项目**：新闻/博客 App（列表、详情、收藏、搜索）
4. **进阶项目**：聊天 App（实时通信、本地缓存、推送通知）
5. **完整项目**：电商/社交 App（完整架构、多模块、测试覆盖）
