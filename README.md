## 重点内容

### 📱 移动端（186 篇，核心方向）

以 **Flutter** 为主线，从零到完整应用开发：

- **Dart 语言**：基础语法 → 面向对象 → 异步编程（Future / Stream）→ 并发与 Isolate
- **Flutter 框架**：入门 → 常用 Widget → 布局与状态管理
- **跨端技术**：Java（Android 原生）、React Native

### 🖥 计算机基础（26 篇）

- **C 语言**：22 个章节的系统学习，从语法到指针、内存管理、多文件项目
- **Linux 命令**、**CLI 命令行**、**嵌入式开发**

### ⚙️ 后端（9 篇）

- **FastAPI** 快速上手实战
- **Supabase** 全套笔记（含 Flutter 集成）

### 🧭 学习路线与项目实践

- 客户端 / 移动端完整学习路线图、书籍阅读索引
- 「情绪日记 App」完整 PRD 与设计规格书（产品思维训练）
